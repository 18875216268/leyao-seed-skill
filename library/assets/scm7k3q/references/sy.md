# SCM 接口文档总索引（含账号-板块路由 · 唯一事实源）

> 本目录是 SCM 接口的**唯一维护源**。统一结构：每个板块 `sy.md`（索引）+ `zddz.md`（字段对照）+ `api_<子板块>.md`（接口）。
> 路径基准：`references/…` 相对技能包根（本资产根）。
>
> **§0 是「账号 → 板块 → 文档」路由的唯一事实源**：`app.md`、`AGENT_GUIDE.md`、各板块 `sy.md` 都只保留一句指向本文的引导，不复制地图。Agent **第 0 步先读 §0**，再进入板块。
> **自营与摇钱树是两套独立权限体系**，系统天然按账号隔离板块与权限；文档只负责路由，不判断"可读/可写/可访问"。越界板块不猜测、不试探、不调用，如实告知"该账号无此板块"。

### 0.3 通用 / 独有判定

- **通用** = 两账号体系下都存在、且本技能文档对两账号均适用的能力。
- **独有（自营专属 / 摇钱树专属）** = 仅该账号体系可路由到。
- 判定**只由 §0.4 文档归属表 + 各板块 `sy.md` 的归属标记**给出；Agent 不自行从菜单名称推断。

### 0.5 Agent 路由流程（务必按序）

1. **判定账号**：`python scm.py status` **只给账号名/providerId，不含体系标签**；自营/摇钱树由**用户明确告知**或按 §0.2 板块地图确认。无信息先问，**不猜**。
2. **选板块**：在 §0.2 对应账号的地图里找目标板块；**不在该地图内** → 如实告知"当前账号无此板块"，**不猜测端点、不发请求**。
3. **进板块 `sy.md`**：读其头部的**一行归属标记**（通用 / 自营专属 / 摇钱树专属），指回本文 §0.4。
4. **选文档**：按 §0.4 挑 `api_*.md`；标"自营专属"的不用于摇钱树账号，反之亦然；"通用"两账号皆可。
5. **权限交给系统**：能否读/写、能访问哪些字段由系统在账号会话内天然隔离；**Agent 不预判、不越权试探**。接口报错按 `通用/api_认证与公共约定.md` 错误码如实反馈。
6. **未交付板块**：`references/` 无对应文档时，走 `modules/<id>/GUIDE.md` 端点清单或按 `AGENT_GUIDE.md §4` 的 `MODULE_TODO` 如实告知。

| 认证 | `token` + Cookie（含 `cmsToken`）+ 请求头 `provideridm = md5(providerId)` |
| 公共参数 | `token` `platform="scm-admin"` `version` `ua` `ex` `lastBuildTime` |
| 成功码 | `code == "40001"`（HTTP 恒 200） |
| 导出文件（**仅商品异步三段式**） | CSV，**GBK** 编码；列数随账号动态变化。数据板块是同步 xlsx、客户黑名单直接 xlsx、店铺流量前端生成，均非此列 |
| 限流 | 导出提交 `40003`（1 分钟 / 10 分钟窗口） |

## 5. 术语

| 术语 | 含义 |
|---|---|
| 板块 / 子板块 | 左侧菜单一级 / 二级 |
| 自营 / 摇钱树 | 两套独立的**账号权限体系**（非具体账号，账号由凭证动态取得） |
| 活动 | 商品上架后的销售活动（一口价/特价/拼团/批购包邮等） |
| `wholesaleId` | 活动 ID |
| `drugId` | 商品 ID |
| 导出任务 | 提交后生成的异步任务，在「导出列表」统一查看与下载 |
