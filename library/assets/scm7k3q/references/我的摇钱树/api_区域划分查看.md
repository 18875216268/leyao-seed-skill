# 区域划分查看（API）

> 子板块：我的摇钱树 → **区域划分查看**（页面 `#/my-cashcow-management/region-division`，菜单 menuId 1015）。
> **账号归属：② 仅摇钱树**（自营账号无此子板块，越界不调用；归属唯一事实源 `references/sy.md §0.4`）。
> 请求约定见 `sy.md §3`：`POST` + JSON；**`ex` = `RegionDivision`**（实测 2026-11-16 抓包确证，非空串）。
> 参数与字段来自真实抓包：采集 2026-11-16（登录摇钱树账号，只读导航，零业务影响）；两接口业务码均 `40001` 可达。

## 1. 总览

| 界面 | 后端 | 说明 |
|---|---|---|
| 筛选项「选择配送商」下拉 | `getProviderDelivers` | 配送商列表数据源（21 条实测） |
| 区域划分结果列表（价格类型 / 区域 / 适用药店类型） | `getAreaPriceList` | 按所选配送商查询（6 条实测） |

> 两个接口同在 `/scm-base/provider/` 前缀；**均无分页**。

## 2. 读取

### 2.1 读取接口总表

| # | 接口 | 用途 | 业务参数 |
|---|---|---|---|
| R1 | `POST /scm-base/provider/getProviderDelivers` | 配送商下拉数据源 | 无 |
| R2 | `POST /scm-base/provider/getAreaPriceList` | 区域价格列表（按配送商） | 1 个（§2.3） |

### 2.2 R1 配送商列表 `getProviderDelivers`

```json
{}   // 仅公共参数；ex = RegionDivision
```

**实测响应**：

```json
{"code":"40001","message":"获取成功","data":{
  "providerNames": [
    {"498": "采药易(广东东健医药有限公司)"},
    {"3364": "央拓医药(重庆央拓医药有限公司)"},
    {"23919": "小药桂(广西乐药医药有限公司)"}
    /* … 实测共 21 条，每项为 {配送商id: 名称} 的单键对象 … */
  ]}}
```

| 字段 | 含义 | 备注 |
|---|---|---|
| `providerNames` | 配送商数组 | 每项是**单键对象**，键 = `deliveryProviderId`（数字字符串），值 = 名称 |

> ✅ **旧推测已确证**：数字键即配送商 id（如 `498`→「采药易…」），R2 的 `deliveryProviderId` 就取自这里。解析：`[{str(id): name}, ...]` 展平成 id→名称映射。

### 2.3 R2 区域价格列表 `getAreaPriceList`

**实测请求体**：`{ "deliveryProviderId": 498 }`（`ex` = `RegionDivision`）

| 参数 | 说明 |
|---|---|
| `deliveryProviderId` | 配送商ID（数据源见 R1） |

**实测响应**（`data` 为数组，每个价格类型一条）：

```json
{"code":"40001","message":"返回成功","data":[
  {"priceType":"单体周边价","subType":"零售单体,第三终端,连锁总部（批零一体）,连锁加盟",
   "areaList":[11,12,13,14,31,32,33,34,35,36,37,41,42,43,45,46,50,51,61],"areaName":"周边"},
  {"priceType":"连锁周边价","subType":"连锁总部（批零一体）,连锁总部（纯连锁）,商业公司",
   "areaList":[/* 同上周边 */],"areaName":"周边"}
  /* … 偏远价 / 超偏远价各一对，实测共 6 条 … */
]}
```

| 界面结果项 | 字段 | 说明 |
|---|---|---|
| 价格类型 | `priceType` | 枚举见 §3.1（6 种，单体/连锁 × 周边/偏远/超偏远） |
| 区域（查看） | `areaName` + `areaList` | `areaName` = 区域分组名（周边/偏远/超偏远）；`areaList[]` = 该组包含的区域 `areaCode` 数组 |
| 适用药店类型 | `subType` | **逗号分隔字符串**，枚举见 §3.2 |

## 3. 枚举（实测确证）

### 3.1 价格类型 `priceType`（6 种，单体/连锁成对）

| 值 | 区域分组 |
|---|---|
| 单体周边价 / 连锁周边价 | 周边 |
| 单体偏远价 / 连锁偏远价 | 偏远 |
| 单体超偏远价 / 连锁超偏远价 | 超偏远 |

### 3.2 适用药店类型 `subType`（逗号分隔）

实测出现：`零售单体`、`第三终端`、`连锁总部（批零一体）`、`连锁总部（纯连锁）`、`连锁加盟`、`商业公司`。

> 典型组合：单体价 → `零售单体,第三终端,连锁总部（批零一体）,连锁加盟`；连锁价 → `连锁总部（批零一体）,连锁总部（纯连锁）,商业公司`。

### 3.3 区域分组 `areaName`

`周边` / `偏远` / `超偏远`（各自对应一组 `areaCode`）。

> `areaList` 的区域码与 `areaGroup/getAreaCodeWithoutLimit`（销售流水 R3）同源，可直接用该级联接口取中文名。

---

## 4. 已知坑与待确认

1. **`ex` 必须传 `RegionDivision`**（非空串、非默认 `goodsOnShelves`）。
2. **先 R1 后 R2**：页面动线「先选配送商 → 再看区域划分」；R2 的 `deliveryProviderId` 来源是 R1。
3. **`areaList` 是 code 数组**：与销售流水的 `province`/`city`/`district` 同源，取中文名用级联接口。
4. **`subType` 是逗号分隔字符串**（非数组）：解析需 `split(',')`。
5. **R2 数据随配送商不同**：不同配送商的 `areaList` 划分不同（实测同一价格类型下区域集合有差异）；不要缓存跨配送商复用。
6. **仅摇钱树账号可达**：自营凭证会因体系隔离失败；先确认账号归属，无信息先问、不猜。
