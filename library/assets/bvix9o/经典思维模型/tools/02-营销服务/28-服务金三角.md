# 服务金三角

> 编号 #28 ｜ 篇：二·营销服务 ｜ 源：`TOOL` P0493–P0504
> 又称：服务金三角模型（卡尔·艾伯修特 1985《服务经济》） ｜ 类型：服务管理框架

**一句话**：服务企业成功需要三角协同——**服务策略（顶）· 服务系统（左）· 服务人员（右）**，三者围绕中心**顾客**相互作用；缺一角都难以提供杰出服务。

## 什么时候用

- 服务管理体系搭建与诊断（策略/系统/人员三个切入点）；
- 服务营销整合设计（内部营销/外部营销/互动营销）；
- 组织改进路线（测量 → 沟通 → 业绩衡量 → 反馈 → 改革）。

**不适用**：纯制造交付问题；单点客服话术（那是人员侧的局部）。

## 来源与四特点

1985 年卡尔·艾伯修特《服务经济》总结杰出服务公司四特点：① 了解**关键时刻**（Moment of Truth）的意义；② 精心设计的服务**战略**；③ 体贴顾客的**系统**；④ 顾客导向的一线**员工**——由此提出服务金三角。**前提认知**：若核心服务/产品在设计上未将顾客服务纳入考虑，则绝无可能提供杰出服务。

## 三角三要素

**① 服务策略（顶点）**：阐明企业价值观、体现顾客需要、明确服务目标——**指导一切服务活动的纲领**；
- 三层要求：高层能制定/修改/指导控制；中层须联系实际使部门服从整体；**一线员工必须知晓并理解**（否则无法提供超值服务）；
- 也是让顾客了解经营理念最直接有效的途径（顾客关心"产品之外的附加价值"——如海尔"忠诚到永远"）；
- 优秀服务企业的核心价值：**卓越**（异乎寻常的标准）/ **创新** / **愉悦**（让客户高兴、员工开心）/ **协作** / **尊重** / **正直**（遵守承诺）/ **公益**；
- 动态过程：内部上下循环（上级传达解释、下级反馈、中高层据反馈修改）+ 外部顾客信息（一线收集）。

**② 服务系统（左边）**：服务的有形物质载体（设备 + 直接提供的一系列产品）；
- 两个易忽视点：服务于**内部员工**的设备（它确保员工以最佳状态服务顾客）；顾客对产品的**潜在需求**；
- 唯一原则"**用户（包括顾客和内部员工）至上**"，兼顾三点：系统是否完善**不以高级昂贵为标准**（汽车旅馆不必按五星级配置——否则失去现有忠诚顾客）；必须让使用者**方便地享受**（关注日常运转、使用说明、操作培训）；必须**消除运作瓶颈**（如已装声讯系统却仍按旧速度响应 = 白装）；
- 良好系统涵盖：服务设备/服务流程/服务方式/服务沟通；涉及**前台与后台**；既防范风险又兼顾效率；**差别化服务**——客户细分为特别优质/优质/目标/大众客户，分别采取不同服务方式。

**③ 服务人员（右边）**：决策人、管理人、员工的总和——确保优质服务的关键；
- 两方面作用：向顾客**传递服务理念**（生动形象）；获得顾客反馈**最迅速直接的信息**（经营者控制调整必须依赖的及时反馈）；
- 建队伍四要点：① 树立正确观念（理解"优质服务—顾客忠诚—企业生存"的关系）；② 贯彻服务策略（策略必须被员工认识接受）；③ **培训**（观念培训 + 服务技术培训——礼貌友善、主动了解需求、捕捉信息及时反应）；④ **鼓励信息反馈**（员工最直接接触顾客、最频繁使用系统——他们的建议最有意义）。

**④ 顾客（中心）**：其余三要素都服务于它；围绕中心相互沟通、共同发展，日复一日保持服务。

## 基本内容（模型揭示的两点）

- **明确服务理念**：把顾客作为核心 = 服务建立在最大限度满足顾客需求基础上——"从顾客立场出发，换位思考"；充分满足需求既是出发点也是归宿，须贯彻到每个环节与每个人；
- **成功服务三关键要素**：**策略**（明确目标：市场定位/形象/服务标准，体现顾客至上与人性化）；**人员**（调动积极性主动性创造性 + 培训 + 沟通手段——内部沟通 + 与顾客沟通）；**组织**（仅靠微笑与态度不够——需内部各种资源有效配合：工作流程/服务规范/考核手段/管理体系；**从服务设计一开始就考虑顾客需要**）。

## 应用：加强服务金三角效力（五阶段）

1. **因素测量**（企业声望、专有技术/服务、品牌优势、交易支持系统、工作环境、报酬、信任水平、服务过程灵活性——指标须符合特定企业）；
2. **沟通结果交流**（分析因素间相关性，把结果反馈员工、取得支持）；
3. **建立有效业绩衡量系统**（改革传统财务指标为主——纳入人力资源管理、技术创新、顾客满意度、员工满意度等非财务指标，如平衡记分卡）；
4. **建立有效信息反馈系统**（员工 + 顾客两方面，及时收集与反应）；
5. **制定改革措施**（改进人力管理、开发新技术等）。

## 三种营销整合（模型另一视角）

- **外部营销**：设定顾客期望、做出承诺（广告/推销；服务人员、设施、过程本身也在传达承诺）——"服务营销活动的正确开始"；
- **内部营销**：保证员工**有履行承诺的能力**（挑选、培训、技术设施、制度、激励——"只有这样才能保持和实现承诺"）；
- **互动营销**：顾客与组织相互作用、服务被生产与消费的**一瞬间**信守承诺——**从顾客角度看最关键**；
- 关系：互动营销能否成功取决于内部营销是否做好；内部与外部营销只有相互配合才能实现承诺、实现顾客满意。

## 案例锚点（原文）

某购物中心（1985 年成立，26000 ㎡，5 万种高档品牌；从亏损到连续 10 年稳定增长）：
- 服务策略——"以客户满意为中心"；贵宾卡从几百张到四万多张、五种卡型；2003 年与中国银行推出"银通卡"（零首付免存息）；2004 年起追求精致全方位贴身服务；
- 服务系统——独创**《四星级商场标准》**（九大方面 82 条，量化商场面积/照明/温湿度/品牌规模/服务时效）；投资 600 万建地下停车库；156 个柜组按国际标准改造；
- 服务人员——从"微笑服务"升级到"**知识型服务**"与"**个性化服务**"（商品知识培训考试、个性化专人服务用情感打动顾客）。
