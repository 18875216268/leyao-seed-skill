# 营销战略新三角模型

> 编号 #31 ｜ 篇：二·营销服务 ｜ 源：`TOOL` P0560–P0569
> 又称：战略业务三角模型（科特勒 & 卡塔加亚《亚洲重定位：从经济泡沫到持续发展》） ｜ 类型：战略业务架构分析工具

**一句话**：营销战略由**三个维度九要素**构成——**公司战略**（细分/目标/定位）赢"心智份额"、**公司战术**（差异化/营销组合/销售）赢"市场份额"、**公司价值**（品牌/服务/流程）赢"心理份额"。

## 什么时候用

- 经营环境不确定时的**系统性业务架构梳理**（从战略到战术到价值的完整链条）；
- 营销战略诊断（九个要素逐一排查短板）；
- 网络营销/新兴业务模式的战略设计（原文以旅游业网络营销为例）。

**不适用**：单一战术问题（如只调价格）；无战略层诉求的短期活动。

## 来源与三份额

- 背景：1997 亚洲金融危机后，科特勒与卡塔加亚（亚太营销联盟主席）合著《亚洲重定位》，提出此模型以解决持续发展问题；
- **三个核心要素的相互支持**：定位是**企业对顾客做出的承诺** → 这个承诺应当具有**差异性** → 差异性为顾客带来价值 → 产生**强势品牌** → 强势品牌又**支持了定位**（整合关系）；
- 对应三种份额：**心智份额**（战略/定位）→ **市场份额**（战术/差异化）→ **心理份额**（价值/品牌）。

## 维度一：公司战略（三要素 · 赢心智份额）

- 理论依据：波特"战略不是要做什么，而是**限制不能做什么**"；哈姆林"集中和核心竞争力是竞争战略的核心"→ 营销在战略层面的主要任务就是**定位**；
- **市场细分**：资源有限 → 识别不同需求群体；四种常见变量——地理/人口/心理（生活方式）/行为（地理人口便于操作，心理行为能清楚描绘特定购买群）；
- **目标市场**：四个选择标准——细分市场**大小** / **成长潜力** / 公司**竞争优势** / 公司**竞争地位**（以求目标与资源匹配）；
- **市场定位**：四点注意——定位应与公司优势匹配 / 应被顾客**正面接受**（喜欢和信任）/ 应**持续一段时间** / **定位是承诺**——因此首先应具备履行承诺的能力。

## 维度二：公司战术（三要素 · 赢市场份额）

- **差异化 = "核心"战术**（吸引顾客购买的基础）——三层实施：
  - **内容**（提供什么——核心部分）、**背景**（如何提供——帮助顾客"感受"差异性的努力）、**基础设施**（技术或人——支持前两者）；
  - 例（网上购书）：书 = 内容；送书上门 = 背景；送书人 = 基础设施；
- **营销组合 = "创意"战术**：可创造性调整 4Ps——**产品与价格 = 价值提供部分；渠道与促销 = 价值传递部分**；为使组合有效，两大部分必须**整合设计**；
- **销售 = "获取"战术**（唯一可通过交易从市场实现利润的要素）——按目标市场类型选择技巧：
  - **质量导向型** → **解决方案法**（主动识别顾客难题并提供解决方案）；
  - **价值导向型** → **利益销售法**（以有竞争力的价格提供高质量产品）；
  - **价格导向型** → 尽可能最低价格提供版本较低的产品。

## 维度三：公司价值（三要素 · 赢心理份额）

- **价值衡量（顾客角度）**：价值 = **总收入 ÷ 总支出**（总收入 = 顾客获得的所有利益——功能利益/方便性等；总支出 = 为获利益必须付出的——价格/运费等）；
- **五种价值战略**：**多对少**（更多利益、更少成本——与竞对相比，下同）/ **多对同**（更多利益、相同成本）/ **同对少**（相同利益、更少成本）/ **多对多**（更多利益、更多成本）/ **少对少**（更少利益、更少成本）；
- **价值三要素**：
  - **品牌 = 价值指示器**（显示公司属性/利益/价值/文化/个性；创建维护需持续巨额投资——美国公司品牌广告年花 1-3 亿美元；是系统工程，需适当服务与流程支持）；
  - **服务 = 价值提升器**（已不仅指售前售后——"每项业务都是一个服务过程"，应大写 S）；
  - **流程 = 价值助能器**（最重要三种：**供应链管理**（成本最小化）/ **基于市场的资本管理**（市场资本最优化——业务环境掌握、利益相关者关系）/ **新产品开发**（革新产品 + 流程最高效率））。

## 案例锚点（原文 · 旅游业网络营销）

战略层：细分补充新变量（是否上网/上网能力/时间/兴趣/语言）→ 目标锁定"白领中青年 + 管理层 + 在校大学生"（豪华团 vs 背包经济团）→ 定位四注意（实事求是承诺）；战术层：差异化（网络本身既是产品又是背景与基础设施）→ 营销组合（网页策略/定价策略（差别定价/投其所好/降低买方采购成本/收益最大化而非价格最大化——航空公司最后一分钟定价）/方便性（BtoB+BtoC）/沟通策略（标牌广告/E-coupons/邮件营销/网上新闻））→ 销售（德鲁克："营销的目的就是要使推销成为多余"）；价值层：品牌/服务（微笑服务/细微服务/金钥匙）/网站（价值助能器）。
