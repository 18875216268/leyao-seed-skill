# STP 分析

> 编号 #21 ｜ 篇：二·营销服务 ｜ 源：`TOOL` P0363–P0382 ｜ 同源：`PPT`（P1-25 / P2-82，页码锚点见 index.md）
> 全称：市场细分（Segmentation）→ 目标市场选择（Targeting）→ 定位（Positioning） ｜ 类型：营销战略核心工具

**一句话**：**细分**市场（按需求差异划分子市场）→ 选定**目标**市场（最有利的细分市场）→ 在目标市场**定位**（确立产品或服务的竞争地位）——现代营销战略的核心三步。

## 什么时候用

- 营销战略制定的主干流程（新品上市、市场进入、品牌重塑）；
- 市场机会发现与产品/价格/渠道策略的起点；
- 诊断"营销无效"：细分是否有效、目标是否对、定位是否鲜明。

**不适用**：完全无差异的大宗商品市场；个性化定制场景（STP 面向群体而非个体——须向"定制营销"演进）。

## 一、市场细分战略（S）

- **概念**：按某种标准（人口/心理等）把市场划分为若干顾客群（子市场）——**同一细分内需求高度相似，不同细分间需求明显差别**；
- **细分对象**（任何层次都可细分）：产品大类（健康美容辅助产品）→ 产品类型（剃须用品）→ 替代品层次（电动剃须刀）——不同层次顾客需要不同；
- **步骤（3 步）**：① 根据市场格局和消费者需求确定细分标准与方法 → ② 确定子市场 → ③ 描述各子市场特点；
- **细分标准**（工业品视角的 5 类变量）：**人口变量**（行业/公司规模/地理位置）、**经营变量**（技术/使用者情况/顾客能力）、**采购方法**（采购职能组织/权利结构/与用户关系/总采购政策/购买标准）、**情况因素**（紧急/特别用途/订货量）、**个性特征**（购销双方相似点/对待风险态度/忠诚度）——每类都配"我们应把重点放在……"式的定位问句；
- **细分方法（3 种）**：单一变量因素法（服装按年龄/气候）、多变量因素组合法（锅炉按企业规模+地理位置+最终用途+潜在规模）、系列变量因素法（自行车按地理→性别→年龄→收入→职业→动机，由粗到细）；
- **注意问题（3 条）**：恰当选择细分标准（需求差异小用单一变量、大用多变量）；**细分要适度**（变量越多越好会致子市场过小、营销低效）；**把握动态性**（需求与竞争不断变化，须调整；静态细分的后果 → 客户忠诚度低 → 只能打价格战/加广告，"动态深度细分"才是竞争中后期企业的必然选择）；
- **意义（5 条）**：发现市场机会 / 掌握目标市场特点 / 有利于营销组合策略制定 / 集中人财物投入 / 提高竞争力。

## 二、选择目标市场战略（T）

- 步骤（6 步）：确定并界定待细分的整体市场 → 确定细分标准 → 分割市场 → 评价细分市场 → 选择和确定目标市场 → 目标市场的**重新界定**；
- **选择标准（4 条）**：① 存在潜在需求、有规模和发展潜力；② 市场有一定购买力（有需求无购买力 = 非现实目标市场）；③ 竞争者尚未完全控制（进入成本可控）；④ 符合企业目标和能力；
- **影响因素（4 个）**：企业资源实力（强 → 差异化/无差异；弱 → 集中性营销）、产品同质性、市场同质性、产品生命周期阶段（投入期可无差异；成长/成熟期竞争加剧 → 差异化）；
- **五种进入模式**：① **产品-市场集中化**（单细分市场，了解深、地位稳，但风险大）；② **产品专业化**（一类产品卖各类顾客——显微镜商）；③ **市场专业化**（服务一个顾客群的各种需要——大学实验室全套，客户预算削减即危机）；④ **选择性专业化**（选若干有吸引力的细分市场，分散风险）；⑤ **完全涵盖**（各种产品满足各种顾客——只有大公司才做）。

## 三、市场定位战略（P）

- **概念**：据目标市场竞争状况、针对顾客对某些特征或属性的重视程度，为企业形象和产品**塑造鲜明个性**并传递给顾客——实质是**使本企业与其他企业严格区分开来**（有效定位留深刻印象、失败定位可能一败涂地）；市场定位决策是营销组合策略的基础；
- **定位依据（4 点）**：A 具体产品特点（"七喜=非可乐"、"泰宁诺=非阿司匹林止痛药"）；B 特定使用场合及用途（小苏打 → 冰箱除臭剂/调味配料/感冒饮料）；C 顾客得到的利益（米勒 LITE 低热量啤酒"喝了不会发胖"；劳斯莱斯豪华/丰田物美价廉/沃尔沃结实耐用）；D 顾客类型（米勒"高生"：先定位"啤酒中的香槟"吸引高收入妇女，后转向狂饮者市场"精力充沛的形象"——占领该市场 10 年）——**多数企业多依据同时使用**；
- **定位步骤（3 步）**：① 调查研究影响定位的因素（竞争者定位状况/目标顾客评价标准/目标市场潜在竞争优势）→ ② 选择竞争优势和定位战略（7 方法：特色/功效/质量/利益/使用者/竞争/价格定位）→ ③ 准确传播定位观念（广告宣传）；
- **定位策略（3 种）**：**避强定位**（避开强敌置于市场"空隙"）；**迎强定位**（与支配者"对着干"——百事可乐"你是可乐我也是可乐"；前提是必须比对手有**明显优势**，否则非常危险）；**重新定位**（二次定位——销路差/竞对跟进致份额下降/顾客偏好转移时；也可主动为之：发现新市场范围，如青年产品在中老年流行）；
- **关键因素 4C**：**竞争性**（差别化优势有足够吸引力且竞对难复制）、**可信性**（不能与长期认知相悖、不能脱离现实太远）、**简明性**（简单明了易记）、**一致性**（长期时间上保持一致——今年讲高科技明年讲服务只会造成困惑与不信任）；
- **注意问题**：勿混淆市场定位与产品差异化（差异化是**手段**，定位是通过差异建立**独特市场形象**）；勿定位不明显甚至矛盾。

## 局限（4 条 · 原文）

① **忽略自身资源与能力分析**（目标市场再有潜力，缺人才/技术/资金也难成功——巨人集团反例）；② 未充分考虑市场容量与竞争对手状况（好市场早被对手看好——知己知彼）；③ 对顾客的分析是**静态**的（顾客需求瞬息万变且顾客未必知道自己要什么）；④ 难以满足**个性化需求**（针对群体而非个体）→ 需向**定制营销**（为每个消费者"量身定做"）转变。

## 案例锚点（原文）

某洗涤用品公司（专业去除蔬果内外残余农药，19.8 元 vs 洗洁精 10 元以下）：按教育程度+收入细分 → 目标市场定为大中城市居民（以知识分子家庭为切入点）→ 定位"专业性功效 + 中高档" → 营销计划采用高价撇脂 + 强化差异化 + 聚资源形成局部优势。
