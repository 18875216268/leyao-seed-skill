# 推销方格理论

> 编号 #26 ｜ 篇：二·营销服务 ｜ 源：`TOOL` P0467–P0480
> 又称：销售方格 + 顾客方格（布莱克 & 莫顿 1970，基于"管理方格论"） ｜ 类型：销售心理与人际关系分析工具

**一句话**：用两张 9×9 方格分别描绘**销售人员心态**（对销售的关心 × 对顾客的关心）与**顾客购买心态**（对购买的关心 × 对销售人员的关心），帮助识别各 5 种典型类型并寻找**最佳搭配**。

## 什么时候用

- 销售人员自我诊断与培训（认知自己的销售心态位置）；
- 顾客心理分析（识别顾客类型并调整沟通策略）；
- 销售团队管理（岗位-心态匹配、针对性训练）。

**不适用**：非面对面销售场景（电商/自助）；纯产品策略问题。

## 理论要点

以心理学与行为科学为基础，研究销售人员与顾客之间的**人际关系与交换关系**；出发点是"商品销售是面对面的双向交流过程"——双方立场不同、角度各异，产生的不同认识直接影响推销效果。目的：知己知彼、掌握主动权、实现与顾客的**最佳配合**。

## 一、销售方格（销售人员心态 · 81 种，5 种典型）

纵轴 = 对**顾客**的关心程度（1~9）；横轴 = 对**销售任务**的关心程度（1~9）：

| 位置 | 类型 | 特征 |
|---|---|---|
| (1,1) | **事不关己型** | 对顾客与销售都漠不关心；无责任心、缺成就感；成因：自身无进取心或企业无严格制度 |
| (1,9) | **顾客导向型** | 只关心顾客、处处迁就（可牺牲企业利益）；是"人际关系专家"而非成功销售员 |
| (9,1) | **强销导向型** | 只关心销售结果、施加压力（甚至倾力销售）；"可能成功一时，以后顾客难再登门" |
| (5,5) | **推销技巧导向型** | 兼顾销售与人际关系，但只注重购买心理、不考虑顾客实际需要；折衷立场、四平八稳；业绩优于前三类但非专家（有时说服顾客买了并不需要的商品） |
| (9,9) | **解决问题导向型** | 既关心顾客购买心理**也关心实际需要**——先提出解决方法再完成销售；积极主动但不强加于人；**推销专家、最佳推销员** |

**应用**：诊断企业/个人在方格中的位置 → 找准偏移方向（例：与顾客关系融洽但不主动推销 = 偏向顾客导向 → 需向 X 轴销售导向偏移）；理想态是 (9,9)——销售员与顾客是"咨询与被咨询"的关系；也可用于培训参照（如"推销之神"原一平大致处于 (5,5) 与 (9,9) 之间、偏 (5,5)）。

## 二、顾客方格（顾客购买心态 · 81 种，5 种典型）

纵轴 = 对**销售人员**的关心程度；横轴 = 对**购买活动**的关心程度：

| 位置 | 类型 | 特征与应对 |
|---|---|---|
| (1,1) | **漠不关心型** | 既不关心购买也不关心销售员、逃避或敌视登门销售；通常没有购买决策权、受命于人 |
| (1,9) | **软心肠型** | 对销售员极为同情关心、对购买不关心；极易被说服、感情重于理智、喜欢良好推销氛围 |
| (9,1) | **防卫保守型** | 只关心购买、对销售员有戒心甚至敌视（源于偏见或受过骗）；本能防卫、态度冷淡 |
| (5,5) | **干练型** | 购买冷静理智也重视感情、有自信、爱受时尚影响、"勇敢类购买者"（购买为抬高身价）；**应对：摆事实、及时出示证据，但让顾客自己决策** |
| (9,9) | **寻求答案型** | 最理想——既关心购买也关心销售员工作，把购买视为"解决困难的过程"；掌握较高购买技术、非常理智、了解行情；欢迎能解决实际问题的销售员（成熟型消费者） |

## 三、两方格的关系（搭配成败）

- **关键结论**：销售成功与否**不仅取决于销售员心态，还取决于双方心态是否协调**：
  - **(9,9) 销售员无论遇到哪种顾客都能成功**；**(1,1) 销售员遇到任何顾客都失败**；其他类型视搭配而定（如强销导向 vs 防卫型必败，vs 干练型可能成功；顾客导向 vs 软心肠容易成交，vs 防卫型很难）；
  - **业绩倍数**：据研究，(9,9) 心态销售员的业绩是 (1,1) 的 **75~300 倍**、是 (1,9) 的 **9 倍**、是 (5,5) 的 **3 倍**；
- **管理启示**：企业选择与培训推销员不能只用单一标准——应据各自特点针对性训练，培养各具特点的推销员以适应不同心态顾客；但应**竭力推崇和培养 (9,9) 心态**。

## 销售心态测试（工具自带）

- **培养销售心态七条**：提高思想业务素质 / 正确指导思想与基本原则 / 良好推销道德 / 熟悉并善用环境 / 确定正确推销目标 / 丰富的商品知识 / 掌握消费心理；
- **测试法**：六部分试题（每部分 5 个方案按适合度赋 5~1 分）→ 填"销售心态得分核对表"（1,1 / 1,9 / 5,5 / 9,1 / 9,9 五列）→ 纵向相加、总分最高列即所属心态；
- **测试五步骤**（培训流程）：理解方格原理并自测 → 学习 (9,9) 行为规范并设想不利因素 → 确定具体工作目标 → 讨论目标与行动计划 → 过程中评估检查、纠偏巩固，最终达到 (9,9) 规范。
