# 植田T理论

> 编号 #35 ｜ 篇：二·营销服务 ｜ 源：`TOOL` P0626–P0632
> 又称：植田 T 形借势理论（日本东洋企画株式会社长植田康创立，"智神"） ｜ 类型：竞争性广告/事件营销策略工具

**一句话**：利用两个事物间的**悬殊差距**，借助一个高势能事物（名人/名物/名事件）的影响力，把弱小的企业或产品"**借势**"推高——以**最小投入**（q）获取**最大传播效果**（BH）。

## 什么时候用

- 小企业/弱品牌以小博大（预算有限、常规广告打不动）；
- **事件营销**策划（借名事件/名人/热点时刻）；
- 新品一夜成名的传播设计（争"广告沸点"）。

**不适用**：品牌资产本身较强（常规营销更稳）；无法找到匹配借势物/风险不可控的场景（此理论风险与收益都极致，须评估法律与社会属性风险）。

## 基本原理与图示符号

- 原理：**H 借助 T 实现由 B 到 A 的提升**（借助物影响力 → 提升目标物）；
- "**T**"两层含义：① **Top（制高点）**；② 图中 A、B 与 T、H 恰构成"T"形；
- 符号：**h** = 广告对象宣传前所处状态；**T** = 能利用的名人 / 名物 / 名事件所处状态；**A / B** = 借助物在广告中出现时可能达到的**偏离常态的正负两极**；**-t / +t** = 常态与偏离态之间的距离（**t** = 绝对值）；**q** = 广告投入金额；**h** = t 与 h 之间的距离。
- **两条原理**：① **q 与 t 成反比**（偏离常态越极致、越出圈，所需投入越小）；② **t、h 与 BH（广告效果）分别成正比** → 想以最小 q 求最大 BH，**h 与 t 是至关重要的**。

## 理论要点（四条）

1. **广告沸点**：企业或产品必须达到一定知名度水平才能对销售产生效果——这个水平就是"广告沸点"；
2. 为达到该水平，必须寻找一个**远远超出所期望知名度的借助物**，并将其与自己的企业/产品连接；
3. 观察研究该借助物，**在它出现偏态（非正常状态）时**完成连接；
4. 选择广告受众**最易接受的媒体**——最关键的是"怎样抓住借助物出现偏态这一点"。

## 注意三要素

**① 品牌与事件的关联**
- **品牌与顾客认知的关联**：营销不是产品之争、而是**顾客认知之争**（顾客心智的认知 = 产品的事实）；须让品牌与所关联事件有密切联系；从心理角度，人们更关注隐私、八卦或负面消息 → 容易产生极致效果（配套风险自负）；
- **品牌与社会属性的关联**：反例——湖南某企业请刘翔代言，其"鹤舞白沙，我心飞翔"与刘翔（社会属性=健康向上）本是不错关联，但**白沙做的是烟广告**——社会属性不关联，效果就不会太好。

**② 抓准机会**
- **时效机会**："任何机会都是有时效的"——把握瞬间。**统一润滑油案例**：2003 年 3 月 21 日伊拉克战争爆发，统一（当时的二线品牌）抓住央视前所未有的大规模直播报道机会，迅速推出"**多一些润滑，少一些摩擦**"经典广告 → 通过事件营销品牌知名度与形象迅速提升，从不知名品牌成长为**润滑油消费者第一提及品牌**（加油站出现司机点名加统一的现象）→ 销量扶摇直上成为行业第一品牌；"巧妙借助事件营销，将人们对事件的关注度嫁接到品牌上"；
- **抢先机会**："机不可失失不再来"——商战机会稍纵即逝，**领先一步就会领先一路**（比竞争对手更快更有胜机——如战争抢先占领制高点）。

**③ 匹配的措施**
- **关联资源的匹配**：整个策划（前中后期）以**事件行销、软文操作、公关为主线**，广告、促销为辅——最快速经济地提高知名度；但企业**绝对要在渠道建设、销售团队打造、销售政策制定、产品制造、产品定价、促销手段设定等方面做好匹配**，否则整个策划变成无本之源，陷入"**雷声大、雨点小**"的传播误区；
- **持续跟进的匹配**：战胜后不能乘胜追击将无意义——根据前期效应与反应，一定要配套跟进。

## 案例锚点（原文 · 山树内衣 "3000 万日元背水一战"）

背景：山树内衣制作株式会社裤头大量积压，账上只剩 3000 万日元（常规广告"像泥牛投海连浪花都掀不起"）。植田闭门两周，动用植田 T 理论：
1. **选准 T**：飞美国，以 500 万日元雇《读卖新闻》驻纽约记者站摄影记者（植田学生）追踪采访美国第一夫人希拉里 → 抓到其坐沙发时双腿姿势的出格瞬间；
2. **找准 A 与 B**：3 个月后克林顿夫妇访日、抵达东京当天，各大报纸整版登出该照片，广告词仅一句——"告诉日本男人一个秘密：希拉里穿的是山树内衣制作株式会社的内裤……" → 广告连同山树内裤成为克林顿访日报道战中的一匹"黑马"，沸沸扬扬的报道把山树狂炒，积压内裤顿开销路；
3. **双重偏离常态**：名人的出格状态 = 负向偏离（-t）；希拉里与克林顿访日的重要性 = 正向偏离（+t）——**两者绝对值 t 因双重偏离常态而伸向极致**；"找准了借助物和切入点，广告从死拼硬打幻化成闪烁着智者光芒的点子艺术"，"四两拨千斤"。
- （后续：克林顿夫妇恼火、国务院考虑告状，因高级顾问劝阻（"无论官司谁输谁赢，得分的都只将是山树公司"）不了了之——**注意其中隐含的法律与品牌社会属性风险**。）
