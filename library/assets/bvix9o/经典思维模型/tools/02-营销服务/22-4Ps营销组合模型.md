# 4Ps 营销组合模型

> 编号 #22 ｜ 篇：二·营销服务 ｜ 源：`TOOL` P0383–P0404 ｜ 同源：`PPT`（P1-28 市场营销4P / P2-75，页码锚点见 index.md）
> 全称：产品 Product · 价格 Price · 分销 Place · 促销 Promotion（麦卡锡 1960《基础营销》） ｜ 类型：营销组合基础框架

**一句话**：把纷繁的营销手段归纳为**产品、价格、分销、促销**四个可控要素——企业用内部可控因素（4P）积极适应外部不可控环境，促成交易实现目标。

## 什么时候用

- 营销方案制定的**基础清单**（四个问题：提供什么产品/如何定价/什么渠道/怎样促销）；
- 营销诊断（哪个 P 是短板——产品力/价格力/渠道力/传播力）；
- 制造业消费品营销的标准框架（其他领域需注意其局限，见下）。

**不适用**（原文明确）：工业品营销、国际营销、服务营销（→ 加 3P 变 7Ps）；零售/金融/公共事业（4P 难以容纳店址、采购、企业形象等关键可控因素）。

## 四要素含义

- **产品 Product**：不止产品本身，而是**产品体系**——三层次（核心产品 = 顾客真正购买的核心利益与服务；有形产品 = 核心利益的载体；无形产品 = 附加服务）；系列组合（广度/长度/深度/相关性）；品牌/特色/质量/售后；要求独特卖点、功能诉求第一；
- **价格 Price**：**价格体系**（出厂价/经销商出货价/零售价 + 折扣返利）；按不同市场定位制定定价策略，定价依据是品牌战略（含金量）；
- **分销 Place**：**渠道战略**——自建 vs 总经销、总经销 vs 小区域独家代理 vs 密集分销；终端选择与策略、渠道链规划、客户管理与维护、渠道切换；
- **促销 Promotion**：**促销组合**（对消费者/员工/终端/经销商，不只促销活动本身）；包括广告、人员推销、营业推广、公共关系。

## 最佳实践对照表（原文精华 · 定价）

| 最佳做法 | 常见错误 |
|---|---|
| 价格由**提供给消费者的价值**决定 | 价格 = 成本 + 标准毛利 |
| 在市场限制范围内**灵活管理价格** | 价格由市场设定（听天由命） |
| 竞对定价只是影响因素**之一** | 价格由竞争对手决定 |
| 定价目的 = 对自己最有利的订单 + 有助于行业价格水平 | 定价目的 = 得到每笔订单 |
| 客户需要**高价值**（利益减价格） | 客户只关心低价 |
| 多形式价格区别是合法的、价格针对具体顾客 | 认为价格区别非法、人人同价 |
| 不积极实时管理价格就不会有利润 | 认为提价会丢业务 |

## 渠道管理最佳策略（原文表 · 三模式）

- **广度覆盖**（大量分销商、无独家代理——如燕京：大众市场占领者，最大范围覆盖，厂商强势可控分销商）；
- **重点覆盖**（少量分销商 2-4 家、可能有独家代理——如宝洁：中高档/竞争强细分市场，集中少量网点；独家代理能建立强关系但除非产品吸引力强否则难谈判）；
- **独家代理**（每城一个分销商——如和路雪：竞争强细分市场，集中于对高质量服务有特殊需求的网点；增强分销商对厂商影响力）。

## 促销管理升级对照（原文表 · 从旧做法到系统流程）

从"缺详细年度计划/预算自上而下/缺数据支撑/方案无产品针对性/缺效果评估/缺跟踪机制/销市部门协调不力"→ 升级为"全面详细计划（预算+活动方案）/上下结合制定/严格信息收集分析/产品经理推动/明确预期效果与评估标准/定期系统跟踪/明确职责与流程"。

## 意义与缺陷（评价）

- **意义**：奠定管理营销的基础理论框架；把错综复杂的营销现象概括为 4 大因素、简明易把握，因而被普遍接受；科特勒："如果公司生产出适当的产品，定出适当的价格，利用适当的分销渠道，并辅之以适当的促销活动，那么该公司就会获得成功"；
- **缺陷（3 条）**：① 简单要素清单不足以涵盖所有营销变量（工业品/国际/服务营销差异大）；② 把 4P 从其他部门工作中分离、只由营销部门负责，**违背营销组合原意**（营销涉及企业每个环节——生产线工人也要"心里装着顾客"）；③ 只适用于**制造业消费品**（零售业的产品无法按 4P 理解、店址/采购/企业形象等重要因素无处安放）。

## 演进谱系（原文完整梳理）

- **6Ps**（1986 科特勒）：4Ps + **权力 Power** + **公共关系 Public Relations**——大市场营销（Mega Marketing）：企业应影响营销环境而非单纯适应，用政治力量与公关打破贸易壁垒；
- **7Ps**（1981 布姆斯+比特纳，服务营销）：4Ps + **人 People / 过程 Process / 物质环境 Physical Evidence**（物证）；核心：员工参与的意义（每个员工做的每件事都是客户服务感受的一部分）+ 关注服务全过程与部门分工合作；
- **10Ps**（科特勒）：6Ps + **战略营销 4P**——探查 Probing（市场调研）、划分 Partitioning（市场细分）、优先 Prioritizing（目标市场选择）、定位 Positioning；战略要素（4P）决定战术要素（6P）；
- **11Ps**：10Ps + **人 People**——科特勒称其"或许是所有 P 中最基本和最重要的"；企业营销分**外部营销**（满足顾客）与**内部营销**（满足员工）；成长与利润还应使股东等利益相关者满意。

## 相关模型：4Cs 与 4Rs

- **4Cs**（1990 劳特朋）：顾客 Customer / 成本 Cost / 便捷 Convenience / 沟通 Communication——以消费者需求为中心（成本上限 = 顾客支付价格 − 适当利润）；不足 5 条：以消费者为导向而非**竞争**导向；易同质化无营销个性；忽视需求的合理性/双赢；未体现关系营销；被动适应消费者色彩浓；
- **4Rs**（舒尔茨）营销：关联 Relevance（与顾客建立互助互求互需关系）/ 反应 Reaction（及时倾听并响应需求——"不在于如何制定实施计划，而在于如何及时聆听"）/ 关系 Relationship（长期稳固互动）/ 回报 Reward（追求市场回报是动力也是维持市场关系的必要条件）；特点：竞争导向、落实关系营销、互动双赢、兼顾成本；**应用数据**：维持客户忠诚可使利润增加 25%~85%；**固定客户数每增长 5%，企业利润增加 25%**（丰田美国分公司用软件系统追踪客户服务/二次免费检测案例）；
- **三者关系（原文结论）**：**4Ps 是基础**；4Ps → 4Cs → 4Rs 是营销理论发展的必然趋势，但**不是后者取代前者**——4Rs 是在 4Ps/4Cs 基础上的创新与发展，不可割裂甚至对立。比较：4Ps 关注企业产品（60 年代）、4Cs 关注市场顾客（90 年代）、4Rs 关注双赢/关系/竞争（90 年代）。
