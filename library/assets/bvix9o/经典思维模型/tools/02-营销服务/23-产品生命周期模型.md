# 产品生命周期模型

> 编号 #23 ｜ 篇：二·营销服务 ｜ 源：`TOOL` P0405–P0431 ｜ 同源：`PPT`（P1-31 产品生命周期 / P2-23，页码锚点见 index.md）
> 全称：Product Life Cycle（PLC；莱维特 1965《开发产品生命周期》） ｜ 类型：营销规划工具

**一句话**：产品像生物一样有**引入期 → 成长期 → 成熟期 → 衰退期**的"市场寿命"（非使用寿命）；各阶段需要不同的营销组合策略。

## 什么时候用

- 营销策略随产品阶段调整（定价/促销/渠道/产品改进）；
- 新品预测（扩散模型）、产品线老化诊断、生命周期延长规划；
- 判断"该继续投入还是撤退"的阶段依据。

**不适用**：风格型/时尚型/热潮型/扇贝型产品（曲线并非 S 型）；把 PLC 当"必由之路"教条使用（见局限）。

## 四阶段特征（原文）

| 阶段 | 特征 | 利润 |
|---|---|---|
| **引入期** | 品种少、顾客不了解、促销费用大、批量小成本高、价格偏高、销量有限 | 通常不获利甚至亏损 |
| **成长期** | 试销成功、需求与销售迅速上升、成本大降、竞对纷纷进入、价格下降 | 迅速增长至最高点 |
| **成熟期** | 大批量稳定销售、需求饱和、产品标准化、销售增速放缓转降、竞争加剧（质量/花色/规格/包装投入加大） | 达顶点后下坡 |
| **衰退期** | 产品老化、销量利润持续下降、竞品性能更好价格更低、成本高的企业陆续停产退出 | 大幅滑落 |

**概念四要素**：产品有有限生命；各阶段对销售者提出不同挑战；各阶段利润有高有低；各阶段需要不同的营销、财务、制造、购买和人事战略。

**两个"≠"提醒**：① **生命周期 ≠ 使用寿命**（社会经济寿命 vs 自然寿命——流行时装使用寿命长但市场寿命短；鞭炮寿命短但市场寿命长）；② **产品种类 / 产品形式 / 品牌** 生命周期各不相同——**种类最长**（钢铁/汽车受人口经济影响难预测）、**形式最典型**（彩电按四阶段规律走）、**品牌不规则**（受环境/决策/知名度影响，可能从成熟期突然转入迅速成长期）。

## 特殊曲线（四种）

- **风格 Style**（延续数代、循环再循环——时而流行时而不流行）；
- **时尚 Fashion**（独特阶段 → 模仿阶段 → 大量流行 → 衰退；"某一领域目前被接受且欢迎的风格"）；
- **热潮 Fad**（来势汹汹、快速成长快速衰退——只满足一时好奇心，无法满足更强烈需求）；
- **扇贝型**（不断延伸再延伸——产品创新或不断发现新用途，如尼龙：衬衫/袜子/地毯/降落伞）。

## 作为预测模式

可基于早期销售量 + 典型 S 型曲线预测后续销量；常用**扩散型新产品模式**（布雷迪 Brady—亚当斯 Adams 模型：rt = S[1−(1−b)^(2t−1)]，S=购买率极限、b=新产品购买系数，b 越小越接近 S 形）。
**四个注意条件**：① 销量上限非常数（随企业/竞争/环境变化——应以类似产品销售历史为基础 + 敏感性分析）；② 曲线未必是 S 形（发现异变型须重建模式）；③ **消费者同质假设**（实际应至少区分革新者/模仿者——PLC 概念本身以"消费者异质"为前提）；④ 忽视**企业营销努力**对销量的影响（须用系数修正法调整）。

## 作为营销策略指导（各阶段打法）

**导入期四战略**（价格 × 促销组合）：
- **高价快速**（高价格+高促销）：先声夺人、抢先占市场、趁竞争未起收回成本——适用：潜在需求大 + 品质特别高难替代 + 面临潜在竞争者想快速建品牌；
- **选择渗透**（高价格+低促销）：及时收回投资+减少销售成本——适用：市场固定明确 + 顾客已熟悉愿出高价 + 生产难度高使竞争不迫切；
- **低价快速**（低价格+高促销）：迅速进入市场、有效限制竞对、带来大份额——适用：市场容量大（可随量降本）+ 顾客不了解且价格敏感 + 潜在竞争激烈；
- **缓慢渗透**（低价格+低促销）：低价助市场快速接受+低促销减少费用——适用：市场容量大 + 顾客了解且价格敏感 + 存在某种竞争。

**成长期六条**：① 筹措人财物扩产；② 改进质量/新特色（商标包装款式规格定价）；③ 进一步细分、开拓新市场创造新用户；④ 疏通增加新渠道；⑤ 促销重点从介绍产品转为建立形象；⑥ 适时降价（以竞争力换长期利润）。注意增速由递增转递减时须调整策略。

**成熟期三策略**：① **市场修正**（找未开发部分/促使更频繁使用或增量/细分化打入新市场/赢取竞对顾客）；② **产品改良**（品质/特性/式样）；③ **营销组合调整**（降价/改广告/多促销方式/扩渠道改服务）。
> 观念：成熟期是大多数产品所处阶段；"一种优越的攻击往往是最佳的防卫"；弱势产品应放弃，但有些产品可通过新用途/新功能**重新进入新生命周期**。

**衰退期三战略**：① **维持**（维持现状——很多竞对退出后，有条件的企业反而可能不减少销量）+ 延长寿命四法（价值分析降本/科研增功能新用途/开拓新市场/改进设计实现再循环）；② **缩减**（规模收缩、力量集中到少数细分市场以增利润）；③ **撤退**（转入新市场新产品需考虑：可复用什么资源/残余资源转让/保留多少零件存货服务老顾客）。

**各阶段营销组合对照（原文表）**：
- 产品：投入期"确保基本消费利益" → 成长期"提高质量增加服务扩大产品改进工艺降本扩大用途" → 成熟期"延伸利益" → 衰退期"有计划淘汰滞销品种"；
- 促销：介绍产品 → 宣传品牌 → 突出企业形象 → 维护声誉；
- 分销：开始建立中间商联系 → 选择有利渠道 → 充分利用扩大分销网 → 处理好淘汰品存货保证协作；
- 价格：撇油或渗透定价 → 适当调价 → 价格竞争 → 削价或大幅削价。

## 品牌机会矩阵（马可斯）

产品类别（成长/成熟/衰退）× 品牌地位（成长/成熟/衰退）→ 9 种品牌机会（如类别成长×品牌成长=扩展市场创造需求；类别衰退×品牌成长=品牌再定位；双衰退=淘汰/自然发展）。

## 判断阶段五法

① 类比法（参照类似产品历史资料，如彩电参照黑白电视）；② 增长率法（销售增长率/时间增长率比值）；③ 曲线判断法（与典型曲线比对）；④ 经验判断法（高档耐用品）；⑤ 产品普及率判断法。

**影响因素**：产品性质用途/消费需求变化/社会生产技术进步/市场竞争。**延长方法**：促使习惯使用/改变设计增功能（一用变多用）/开拓新市场新顾客/发现新使用领域。

## 优缺点与作用

- **优点**：提供适用的营销规划观点（分阶段采取不同组合）；只考虑销售与时间两变量，简单易懂；
- **缺点（6 条）**：各阶段起止点划分标准不易确认；并非都是标准 S 型；适用层次难定（单一产品项目 vs 产品集合）；只考虑销售与时间、未涉及成本价格等变量；易造成"**营销近视症**"（过早剔除仍有市场价值的好产品）；衰退并不表示无法再生；
- **作用**：揭示"无产品能永远畅销"→ 居安思危、不断开发新品（"生产一批、试制一批、设想一批"）；判断阶段 → 采取相应组合策略；通过营销努力可延长生命周期；应用须谨慎（有批评认为 PLC 不是"必由之路"而是"营销策略选择的结果"——判断失误会过早扼杀产品）。

## 相关工具

- **需求/技术生命周期**（五阶段：出现期 E → 加速成长期 G1 → 缓慢增长期 G2 → 成熟期 M → 衰退期 D）——PLC 是它的"镜子"：同一需求下会有多代技术/产品形式（计算能力需求：算盘→计算器→计算机）；
- **客户生命周期**（四阶段：考察期（孕育/相互了解不足）→ 形成期（快速发展/开始盈利）→ 稳定期（理想阶段/大量交易/低投入高贡献）→ 退化期（交易量下降/可能任何阶段发生））；关系发展**不可跳跃**；**客户成熟期的长度可反映企业盈利能力**。

## 案例锚点（原文）

图书产品 PLC：投入期四策略对应（大型典籍=双高；中小学教辅=快速渗透；科技专业书=选择性渗透；大中专教材=缓慢渗透）；成熟期三策略对应（修订=产品改良；销售区域转移=市场改良；营销组合调整）。
