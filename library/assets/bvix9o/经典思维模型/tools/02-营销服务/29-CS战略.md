# CS 战略（顾客满意战略）

> 编号 #29 ｜ 篇：二·营销服务 ｜ 源：`TOOL` P0505–P0541
> 全称：Customer Satisfaction（TCS 顾客完全满意） ｜ 类型：经营管理战略（附 CI 战略）

**一句话**：以**顾客满意**为核心、以信息技术为基础，用顾客满意需求（CSD）/ 指标（CSI）/ 程度（CSM）做工具——整个经营管理活动都以**顾客满意度为指针**（顾客 = 外部顾客 + 内部顾客（员工/股东））。

## 什么时候用

- 服务型/零售型企业的经营战略设计（从产品导向转向顾客满意导向）；
- 顾客满意度体系建设（指标体系 + 测量 + 改进闭环）；
- 与 CI（企业形象）战略配合的"双 C"模式。

**不适用**：短期促销活动设计；与企业利益严重冲突场景需警惕（见局限）。

## 核心概念

- **顾客满意**：企业提供的产品或服务**符合或超过顾客事前期待**的状态；事前期待与实际体验的**差距**决定满意程度；
- 边界：建立在道德、法律和社会责任基础上（有背于此的"满意"不是本意）；内容随时代动态变化（相对性）；有鲜明**个体差异**（应提供差异化满意服务）；
- **指导思想**：组织应从顾客角度、用顾客观点分析需求，据此设计生产提供产品；
- **基本方法**：把顾客需求（含潜在需求）作为产品开发源头 → 以便利顾客为原则 → 全程跟踪满意度、依此调节经营环节 → 抓住老顾客、通过口碑扩大顾客队伍。

## 满意五系统（CS 内容）

① **理念满意 MS**（经营宗旨/哲学/价值观——思想保障）；② **行为满意 BS**（行为机制/规则/模式）；③ **视听满意 VS**（名称/标志/标准色/标准字/应用系统）；④ **产品满意 PS**（质量/功能/设计/包装/品位/价格）；⑤ **服务满意 SS**（绩效/保证体系/完整性/方便性/情绪环境）。

**满意三层次（递进）**：**物质满意层**（产品核心层消费——功能/质量/设计/包装；最基本）→ **精神满意层**（形式层与外延层——外观/色彩/装潢品位/服务）→ **社会满意层**（社会利益维护——产品的道德价值/政治价值/生态价值）。

## 提出背景与发展

**三个背景**：① 经营与竞争环境变化（买方市场——"好商品"也可能卖不出去；斯堪的纳维亚航空 1985"服务与管理"：竞争由生产率转向服务质量）；② 质量观念与服务方式变化（新质量观：不仅符合用户要求还要**比竞对更好**；现代产品 = 核心/有形/附加三层——李维特："新的竞争不在于工厂里制造出来的产品，而在于能否给产品加上……顾客认为有价值的其他东西"）；③ 消费观念形态变化（理性消费"好与坏"→ 感情时代"喜欢与不喜欢"——"当顾客的汽车出了毛病，你也应当为他难过"）。

**发展历程**：1985 斯航 → 1986 美国心理学家定义 CS 概念 + 汽车满意度排行榜 → 1989 瑞典 CSI → 1990 日本丰田/日产 → 1992 德国 DK → 1995 新西兰/加拿大/台湾 → 1998 韩国/马来 → 2000 欧盟 → 2001 中国"全国质量管理奖"。

## 战略内容（七条）

① 站在顾客立场研究和设计产品（预先把"不满意"从产品本身去除；发现潜在需要）；② 完善服务系统（速度/质量——让顾客安心便利）；③ **重视顾客意见、让用户参与决策**（美国斯隆管理学院：成功的技术革新与民用新产品 **60~80% 来自用户建议**）；④ 千方百计留住老顾客（满意顾客引发 8 笔潜在生意、不满意影响 25 人购买欲；**争取新客成本是保住老客的 6 倍**）；⑤ 创造厂商与顾客友好忠诚的界面（IBM 例）；⑥ 建立以顾客为中心的组织（快速反应/鼓励创新/上下沟通顺畅）；⑦ **分级授权**（没有处理决定权则无法保证满意）。

## 实施（条件 · 措施 · 原则 · 注意）

- **七条件**：真正需求 + 领导全面参与 / 较强经济实力 / 独特企业定位 / 明确理念与一致行为 / 产品品质优良 / 适宜时机（一鼓作气）/ 复合型设计群与推广机构（需多学科融汇）；
- **五措施**：树立 CS 观念（一切观念的总纲）/ 加强顾客研究建立关系（含内部员工）/ 提高质量改进服务（大质量观 + 售前售中售后全过程）/ 强化公关（含妥善处理投诉）/ **强化内部营销使员工满意**（内部满意才能外部满意——共同价值观/最佳人事环境/员工情感与凝聚力）；
- **七原则**：高层坚定承诺并经常强化 / 重大决定问"对顾客来讲什么最好？" / 多渠道获取满意信息并做趋势图表 / 有基于衡量的决策体系 / 全员明白"为顾客服务"是主要任务 / 报酬奖励与满意度挂钩 / 持久稳定提供完善服务；
- **途径（按五系统落地）**：理念满意（从顾客需求/行业实际/时代社会出发设计理念）；行为满意（四机制：激励/约束/监督/发展；五系统：信息调研/信息传入/决策中枢/信息效应/信息反馈）；视听满意（名称个性文化味、标志四标准（简洁明快/寓意典型/新颖独特/巧妙精致）、标准字/标准色）；产品满意（功能满意三法：细分市场研发/量身定做/直接反馈改进——海尔"顾客的难题，我们的课题"、宝马"顾客设计宝马制造"）；服务满意（完善服务系统/服务文化/站在顾客角度的服务质量四步管理）；
- **注意三问题**：放宽时间期限（切忌急功近利——成功会产生巨大无形资产）/ 多种营销策略配合（价格/竞争/服务综合）/ 树立动态理念（CS 是动态战略——顾客满意不等于永远满意，须不断开发新产品）。

## 局限（内在矛盾 + 三缺陷）

**内在矛盾**：当顾客满意与企业自身利益冲突时（中短期尤明显）——企业宣称以顾客满意为目的，却要处理利益矛盾。
由此导致：① **企业无差别化**（一味讨好顾客 → 个性丧失）；② **主体性弱化**（消极适应、缺前瞻）；③ **发展战略与销售战略混淆**（只把 CS 当销售策略/包装，只在少数部门起作用——真正 CS 应是长期追求）。

## 案例锚点（原文 · 戴尔）

戴尔成功的核心是"顾客至上、让顾客满意"（直销只是表象）：
- **产品满意系统**：顾客细分持续深化（1994 两类 → 1996 三块 → 1997 六块；另分"交易型/关系型/混合"40%/30%/30%——交易型关注购买经济性、关系型关注总成本与服务可信度）；按需配置按单生产（量身定做）；据顾客直接反馈改进产品；
- **质量价格满意**：供应商从 140 多家精简到 50 多家（长期技术质量领先者）；超常效率供应链 + 零库存 + 直销；
- **服务系统**：Dell Plus（硬件软件一体化安装"一次性"方法）；
- **生产系统**：大规模定制（计算机控制装配线/条码追踪/数据库打印/供货软件协调——福特汽车个性化配置案例）；
- **组织结构**：顾客服务部 + 800 专线 + "CE"（Customer Experience）小组每周例会影响顾客体验的诸因素。

## 相关工具：CI 战略（企业形象战略）

- **涵义**：CI（Corporate Identity：识别/同一性/持恒性）= 企业统一化或同一化战略；CIS = CI 的实施系统（可规范可控的具体操作系统）；
- **产生背景四方面**：信息化社会到来 / 企业双重社会身份（经济效益 + 社会效益创造者）/ 社会价值观多元化 / 竞争导向变化（70 年代质量 → 80 年代营销服务 → **90 年代企业形象**；商品力/营销力/形象力平衡）；
- **三构成**：**MI 理念识别**（思想灵魂、最高决策层、CI 核心与动力）/ **BI 行为识别**（动态识别——对内：管理规范/研发/教育培训/环境；对外：市场调研/营销/公关/广告/公益）/ **VI 视觉识别**（静态符号——基本要素（标志/标准字/标准色 + 象征物/图案）+ 应用要素（办公用品/招牌/制服/车辆/建筑/包装/展示））；
- **两模式**：美国式（重 VI 的标准化系统化设计）/ 日本式（MI/BI/VI 整体性、以理念为中心、上升到经营管理与企业文化高度）；
- **八特点**：系统性 / 统一性 / 差异性（个性化是 CI 的灵魂和生命）/ 传播性 / 稳定性 / 长期性 / 操作性 / 动态性；
- **六功能**：识别 / 管理 / 传播 / 应变 / 协调 / 文化教育；
- **五作用**：改善企业体质 / 统一提升形象（"汽车旅馆"统一标志案例）/ 加强内部凝聚力 / 创造消费信心（"用钞票作选票"/市场"信用卡"）/ 创造适宜外部经营环境（可口可乐"大火烧毁也能靠声誉重建"）；
- **局限**：只重形象塑造、缺乏及时适应环境变化的机制——在个性化需求时代逐渐落伍；
- **四实施原则**：战略性（10-20 年）/ 民族性（愈是民族的愈是世界的）/ 个性化 / 整体性（BI、VI 为 MI 服务）。

## CS 与 CI 的关系

- **比较**：CI——价值观以企业为中心（企业利益为重）、指导思想"企业主导、从内向外"、战略关键"提高企业业绩（识别）"、方法"名牌战略（产品）"；CS——以顾客为中心（以客为尊）、"顾客主导、从外向内"、"达成顾客满意（情感）"、"高品质服务（服务）"；
- **结合运用**：CI 属"外延"拓展、CS 属"内涵"提高（相辅相成——企业"经营战略的两个轮子"）；但二者是不同战略（CI 重外在形象、CS 重客户实质满意；CI 起点是企业本身、CS 是客户；CI 建形象、CS 建服务满意系统）→ **以 CI 为手段、以 CS 为目的，内外同步，协调耦合**；相互渗透（把"客户满意"贯穿进 CI 的理念/行为/视觉识别；把优质服务融合进形象传播）。

## 关联模型

- 配套：`服务质量差距模型`（满意 = 感知-期望的差距视角）、`服务金三角`、`服务利润链`、`满意镜`
- 同族：`顾客金字塔模型`（顾客分层管理）、`客户生命周期`
