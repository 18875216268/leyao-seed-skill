# 服务利润链

> 编号 #32 ｜ 篇：二·营销服务 ｜ 源：`TOOL` P0570–P0592
> 又称：Service Profit Chain（赫斯克特 · 萨塞 · 施莱辛格，哈佛，1994 提出"服务价值链"、1997 正式提出本理论） ｜ 类型：服务管理经典分析工具

**一句话**：一条**闭合循环链**——内部服务质量 → 员工满意 → 员工忠诚 → 员工效率 → **顾客价值** → 顾客满意 → 顾客忠诚 → 企业盈利（又反哺内部质量）；**客户的满意度最终由员工的满意度决定**。

## 什么时候用

- 服务企业管理体系设计与诊断（从"员工侧"找顾客满意的根因）；
- 顾客忠诚/盈利关系论证（把营销管理重点从市场份额规模转向**份额质量**）；
- 内部营销、员工满意度体系的建立依据。

**不适用**：纯交易型业务（无服务环节）；只做外部营销不管内部的短期方案。

## 理论来源（三支研究）

① **萨塞与顾客忠诚**：传统认为市场份额决定利润；数据发现**顾客忠诚度比市场份额对经营能力与成长影响更大**；
② **赫斯克特与战略服务观**（80 年代中期）：四基本因素——**目标市场细分 / 服务概念 / 经营战略 / 服务提供系统**（各含关键问题清单）；
③ **施莱辛格与员工及顾客忠诚**：低工资低培训 → 员工离职率高、忠诚度低 → 顾客忠诚度低 → 利润下降 = **"失败循环"**；发现**过程质量**是价值决定因素之一（人们重结果轻过程）；**价格与顾客成本**——低价格不必然高价值；顾客成本 = 取得产品及服务的难易程度（易得性强 → 顾客成本低 → 对价格不敏感 → 利润增加）。

## 含义与核心

- 含义：表明**利润、顾客、员工、企业**四者关系、由若干链环组成的**循环闭合链**（每一环节实施质量直接影响其后环节，最终目标 = 企业盈利）；
- **基本逻辑**：获利强弱由**顾客忠诚**决定 → 顾客忠诚由**顾客满意**决定 → 顾客满意由**顾客认为的价值**决定 → 价值由**高效忠诚的员工**创造 → 员工忠诚取决于**满意** → 满意取决于公司内部的**高质量内在服务**；
- **核心 = 顾客价值方程式**：服务产品的价值 = **结果与提供结果的过程的质量 ÷ 价格与顾客成本**（从顾客角度看价值，直接影响购买决策）。

## 七环节逆向关系（要素内容）

1. **内部服务质量 → 员工满意**：内部质量以员工对工作/同事/公司的感受衡量；分外在（薪水/福利/环境）与内在（培训开发/奖励认可/信息沟通/技术和工作设计）；员工最看重的内部三因素：**完成目标所需的知识和能力 / 被授予的权力 / 行动自由**；
2. **员工满意 → 员工忠诚**（满意者更愿留下、为创造价值而自豪）；
3. **员工忠诚 → 员工效率**（忠诚意味着对企业未来有信心、把个人命运与企业连在一起——有经验且忠诚的员工更懂得识别、招揽最有价值顾客）；
4. **员工效率 → 顾客所获价值**（价值由人创造；**顾客让渡价值 = 顾客总价值 − 顾客总成本**——总价值：产品/服务/人员/形象价值；总成本：货币/时间/精力/体力成本）；
5. **顾客价值 → 顾客满意**（感知效果 vs 期望：低于 = 不满意、匹配 = 满意、超过 = 高度满意；只有比竞对具有更高顾客价值才能赢得满意）；
6. **顾客满意 → 顾客忠诚**（重复购买 + 推荐他人 + 视为最佳唯一选择；几次满意后忠诚度提高）；
7. **顾客忠诚 → 获利能力**（美国学者调查：**忠诚顾客每增加 50%，利润增加 25%~85%**；忠诚顾客增加还能弥补非忠诚顾客交易的损失）。
- 强调：服务营销除 4P 外部营销外，还需**内部营销**与**相互作用营销**。

## 作用意义（三条）

① 明确**顾客忠诚与企业盈利能力**的相关关系 → 营销重点从"份额规模"转向"**份额质量**"；② 提供实现满意与忠诚的**思路途径**（提高总价值 / 降低总成本两入手）；③ 提出"**公司内部服务质量**"概念——服务好外部顾客，先服务好"内部顾客"（员工）。

## 工具应用（七步）

1. **因素测定**：顾客忠诚度（问卷 / 购买占比 / 购买频率）；顾客满意度（总体印象 + 有形产品满意指标）；员工忠诚度（**离职率**——须区分**自愿/非自愿离职**，非自愿属招聘失误）；员工满意度（定期问卷）；测定后做**相关性分析** + 反馈员工；
2. **建立业绩衡量系统**：不只财务指标——纳入人力资源管理、技术创新、顾客满意与忠诚；考核结果**承认和奖励** + 全公司公布（内部竞争与学习氛围）；
3. **提高服务质量、完善服务管理**（全面服务质量管理——从构思设计阶段就考虑顾客需求；关系营销——重新设计顾客关系生命周期）；
4. **实施内部营销**（五措施：树立内部营销观念（经营哲学）/ 营造内部营销大环境（管理层是轴心——"你希望员工怎样对待顾客，你就怎样对待员工"）/ 寻求内部与外部营销最佳结合点 / 定期员工满意度调查 / 投入财力精力培训员工（三任务：认识服务战略与自身位置/树立顾客意识/提高沟通销售服务技巧））；
5. **提高顾客让渡价值**（提高总价值：产品/服务/人员/形象价值；降低总成本：货币 + 非货币（简化流程、节省时间精力体力——货币成本不变也能降低总成本））；
6. **提高员工满意度、达到员工忠诚**；
7. **加强信息沟通、提高企业形象**（"口碑"是最有效的沟通工具——正负口碑都会加倍影响潜在顾客期望）。

## 案例锚点（原文 · 沃尔玛）

**三项基本信仰 = 服务利润链中心思想的体现**：
- **尊重员工**：只有一位老板 = 顾客；最接近顾客的是一线员工（选人重于培训——找本性热情/智慧/同情心/认真者）；100 多万美国员工、离职率同类最低（工资仅一般水平）；充足岗位培训 + 参与商店事务；销售竞赛奖/地区明星奖（照片橱窗展示）；员工不叫"雇员"而是"伙伴/同事"；利润分享计划 + 购股计划（**50% 员工参与**、扣薪以低于市价 15% 购买）；耗损奖励计划（损耗率 **1.1% vs 同行 2%**）；巡视制度（管理职位一周出差四天、至少要为一个顾客做点什么）；高管参与商品促销设计与竞赛；
- **服务顾客**：为顾客提供超常价值（品种齐全/可能最低价格/满意承诺/亲切专业服务/免费停车/愉快经历）；"为顾客节省每一美元"是经营哲学（一般零售商利润率 45%、沃尔玛 30% 即可——顾客忠诚不可靠，价格更低他就走）；供应链合作降成本（2002 年在华采购 120 亿美元）；"天天平价"形象；**"第一条，顾客永远是对的。第二条，如果对此有疑义请参照第一条"**；**"十步微笑原则"**；服务超出期望（带顾客到商品处并介绍知识 > 仅告知位置）；美国无条件退款（毋须理由甚至没有收据）；
- **追求卓越**：人均销售额比 Kmart 高 17%、比 Target 高 21%；单位面积销售额高 29%/34%；近十年销售年均增长 16%、利润增长 15%；2004 财年总收入 2563 亿美元。

## 相关工具：服务价值链（八环节正向表述）

内部服务品质 → 员工满意 → 员工忠诚 → 员工生产力 → 服务价值 → 顾客满意 → 顾客忠诚 → **盈利能力与成长能力**（又反哺内部质量——良性循环）。
- **顾客忠诚五方面价值**：降低成本（忠诚顾客 +5% → 利润 +25%~85%；**争取新客成本是保留老客的 5 倍**）/ 更多购买量 / 获得溢价利益（老顾客更愿为优质服务付高价）/ 口碑传播（"义务"市场推广员）/ 符合 80/20 法则（80% 收入来自 20% 顾客）；
- **员工生产力**不等于工作时间而是"真正满足顾客需要之产出"；提升顾客价值要有"心"——将心比心/留心/尽心/细心/耐心/安心/恒心/不窝心 → 贴心 → "心心相印"；
- **员工满意度**：满意 = "对工作付出"与"从工作获得"的关系；内部服务品质两方面——**工作本身**（目标/权力/职权利责制衡机制）与**员工之间关系**（人际关系 + 沟通服务学习团队精神）；建设学习型组织实施自我超越。

## 关联模型

- 配套：`CS战略`（顾客满意系统）、`服务质量差距模型`（满意=感知-期望）、`服务金三角`（内部营销定位）
- 同族：`满意镜`（员工-顾客满意联动）、`顾客金字塔模型`（忠诚顾客分层）
