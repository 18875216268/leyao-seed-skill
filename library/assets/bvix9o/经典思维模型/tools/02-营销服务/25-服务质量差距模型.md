# 服务质量差距模型（5GAP）

> 编号 #25 ｜ 篇：二·营销服务 ｜ 源：`TOOL` P0446–P0466
> 全称：Service Quality Model / 5GAP（帕拉休拉曼 · 赞瑟姆 · 贝利 1985） ｜ 类型：服务质量管理工具

**一句话**：服务质量问题源于**五个差距**——管理者感知（G1）→ 标准制定（G2）→ 服务传递（G3）→ 对外沟通（G4）→ 顾客感知（G5）；**G5 是前四者共同作用的结果**，弥合 G5 的关键是弥合前 4 个差距。

## 什么时候用

- 服务质量问题诊断（定位"差在哪一环"）；
- 服务标准设计、员工管理、对外承诺管理的改进框架；
- 配套 SERVQUAL 量化测评（见下）。

**不适用**：纯产品（有形品）质量问题（→ 质量生产工具）；单点服务失误归因（那是具体 G3 事件）。

## 五个差距（定义 · 原因 · 结论 · 方法）

**G1 质量感知差距**（企业不能准确感知顾客服务预期）——服务质量具有"**理解性**"：
- 原因：管理者未深刻理解服务与竞争特性——调研与需求分析不准、对顾客期望解释不准、未做需求分析、**管理层次过多致信息传递失真**（责任不止在管理者，任何有权影响服务政策/程序的雇员都有份）；
- 结论：随**市场研究导向**增加而减少；随**自下而上的交流**增加而减少；随**管理层次**增加而增加；
- 方法：① 获取准确顾客期望信息（顾客拜访/调查/投诉系统/座谈会）；② 建立良好顾客关系（关系营销）；③ 改善"顾客接触人员 → 管理层"的上行沟通；④ **服务补救**（理解失误时期顾客期望并尽最大努力补救是关键战略）。

**G2 质量标准差距**（服务标准与管理层所认知的顾客预期不一致）——"**设计性**"：
- 原因：高层未将服务质量列为首要问题——计划失误/计划管理低下/组织目标不明确/缺乏高层有力支持；
- 结论：随对服务质量管理的**重视**增加而减小；随相关**目标设定**减小；随**服务标准化**减小；随管理者对**服务可行性的理解**增加而减小；
- 方法：① 有效开发与设计服务——**服务蓝图**（客观描述关键服务过程特点并形象化，让人人知道自己的角色）；② 建立**顾客定义的服务标准**（标准以顾客为出发点，非服务提供者一方说了算；赞瑟姆 9 步法）。

**G3 服务传递差距**（服务生产与传递未按标准执行）——"**执行性**"：
- 三类原因：**员工**（角色不清、左右为难、选人不当、技术支持不足、奖惩不当、缺授权与团队合作）、**顾客**（不懂/不愿/不能完成参与角色）、**中间商**（零售商/总经销/代理/经纪人代表企业却不一定按特许要求传递）；
- 结论：随团队合作、人岗适合度、工具与工作适合度、员工授权、评价系统改进而减小；随**角色冲突**与**角色模糊**增加而增加；
- 方法：① **人力资源战略**（雇用正确的人、人员开发、支持系统、保留最好的人）；② **增加顾客参与战略**（先定参与类型——仅在场/中水平（付出精力或信息）/实际生产（如健康训练）；再吸引合适顾客 + 教育培训 + 按细分管理——如影院吸烟分座）；③ **通过中间商有效供给**三战略——**控制**（有独特服务或经济权力时：建绩效标准+按绩效给报酬）、**授权**（资源不足控制时给灵活性）、**合伙**（最高效率潜力：与中间商合伙了解最终顾客、建标准、改善供给、诚实沟通）。

**G4 市场沟通差距**（宣传承诺与实际服务不一致）——"**沟通性**"：
- 原因两类：市场沟通计划与执行不力（与运营未融合、外部营销与运营不协调、未执行宣传的服务标准）；**过度承诺**；
- 结论：随水平交流增加而减小；随过度承诺倾向增加而增加；
- 方法：① **服务承诺管理**（承诺要切合实际、确实能保证——承诺高于实际对长期关系极为不利）；② **顾客期望管理**（提供不同价值等级服务选择、建立标准便于评估、对不现实期望进行谈判）；③ **改进顾客教育**（让顾客为服务过程做好准备、避开需求高峰）；④ **内部营销沟通管理**（垂直沟通、水平沟通、后台人员与外部顾客一致、创建跨职能团队）。

**G5 感知服务质量差距**（顾客感知/体验质量与预期不一致）——**模型核心**：
- 原因 = 前 4 个差距；G5 = f(G1, G2, G3, G4)（**不是简单累加**，同方向变化）；
- 方法：关键在于弥合前 4 个差距。
- **格罗鲁斯定义**：服务质量 = 感知的服务 − 期望的服务 = G5；**G5 ≥ 0 → 服务质量良好**（极端高质量、为数不多）；**G5 < 0 → 较差**（绝大多数企业面临的情况）。
- 差距间关系：G1 是 G2/G3/G4 产生的**充分条件**；G2 是 G3/G4 的**充分条件**（G1 不准则无论设计多完美、传递多准确都不是顾客想要的）。

## 案例锚点（原文 · 饭店业）

四步对应四差距：① 深入了解顾客需求（全面调查 5 万份/年 + 及时满意调查 + 员工反馈 + 宾客档案/意见表/投诉登记；鱼刺图分析顾客期望主次、80/20 法则）；② 以顾客为导向制定服务标准（标准清晰具体可量化、一线员工参与制定）；③ 提高员工素质（培训 + 应急服务授权——理解授权目的并控制权限）；④ 履行承诺（真实诚信宣传——"三星级饭店四星级设施五星级服务"是广告欺诈；卡尔顿饭店承诺一致→95% 客人难忘体验、90% 回头客、入住率 70%）。

## 测评工具：SERVQUAL（1988）

- 原理：**Servqual 分数 = 实际感受分数 − 期望分数**；问卷两部分各 **22 个项目**（记录对优秀公司期望 + 度量对特定公司感知）→ 44 项量表，7 分制；
- **五个维度**：**有形性**（设施设备人员外观——4 项）、**可靠性**（可靠准确履行承诺——5 项）、**响应性**（帮助顾客并迅速提高服务水平的意愿——4 项）、**保证性**（员工知识/礼节/自信可信能力——4 项）、**移情性**（关心并提供个性化服务——5 项）；
- 计算：SQ = Σ(Pi − Ei)（i=1..22）；现实中各属性重要性不同 → 加权：SQ = Σ Wj Σ (Pi−Ei)（j=1..5）；再除以因素数得单人平均分、加总除以顾客数得企业平均分；
- 发展：1985 十点分析（可靠性/反应性/胜任性/接近性/礼貌性/沟通性/信用性/安全性/了解性/有形性）→ 精简为五维度；
- 局限 4 条：行业划分限制（按服务接触水平划分，无法覆盖中间行业）；五维度重要性与权重/问卷次序问题；样本有限（三行业五公司，缺旅客运输等质量递减行业）；**事前研究**（顾客利益具有不可感知性、期望与感知在时间上有间断性，但方法需时间连续性）。

## 相关工具：KANO 模型（顾客需求分类）

1979 狩野纪昭引申双因素理论（二维模式：主观感受 × 客观表现）：
- **基本型需求**（"必须有"——不满足很不满意；满足也只是"充其量满意"）；
- **期望型需求**（越实现越满意、不实现就不满意——顾客通常谈论的就是这类）；
- **兴奋型需求**（出乎意料带来惊喜——不提供无所谓，提供则非常满意并提高忠诚度）；
- 另三属性：冷漠型（不在意）、可疑型（不清楚是否期待）、背离型（相反方面才被期望）；
- **操作意义**：先全力以赴满足基本型 → 尽力满足期望型（竞争性因素）→ 争取兴奋型（建立最忠诚客户群）；
- **KANO 问卷法**（1984）：每个特征一对问题（功能良好型/功能不良型），5 个备选答案（很喜欢/期待如此/无所谓/可以忍受/很不喜欢）→ 组合分析归类；六步骤（认识需要→设计问卷→实施→分类汇总建质量原型→分析找差距→调整验证）；
- **与差距模型比较**：同以顾客感知质量为出发点（KANO 发展魅力质量向期望接近；差距模型由内向外管理控制缩小差距）；同用结构型问卷与数理统计（KANO 直观易行、难点在数据转换；SERVQUAL 44 项对顾客理解力要求高）；KANO 侧重**事前控制**（多用于产品开发）、差距模型侧重**事后控制**（检验服务绩效）；KANO 已超越产品服务本身（强调高阶需求）、差距模型是管理工具。
