# 哈夫模型

> 编号 #27 ｜ 篇：二·营销服务 ｜ 源：`TOOL` P0481–P0492
> 又称：哈夫概率模型 / 时间面积商圈界限模型（D.L.Huff 1963） ｜ 类型：商圈计算与选址工具

**一句话**：消费者去某商店购物的**概率** = 该店**吸引力**（卖场面积等）÷ **距离阻力**（时间距离）之比的归一化——商店商圈规模**与吸引力成正比、与时间距离阻力成反比**。

## 什么时候用

- **商圈测算**（预测某商店/商业设施的顾客来源与销售额）；
- **开店选址**（比较不同位置的潜在交易区域与销售额）；
- 评估大型零售店对周边商业集聚的影响力、商圈结构变化。

**不适用**：日常消费品的粗略商圈（数理模型反而繁琐——雷利法则更简易）；无法获取距离/时间与竞争店数据的场景。

## 公式与参数

- 基础：万有引力原理（哈里斯市场潜能模型之上提出）；
- 核心式：**Pij = (Sj^λ / Tij^μ) ÷ Σj(Sj^λ / Tij^μ)**
  - **Pij** = I 地区消费者到 J 商店购物的概率；
  - **Sj** = J 商店的卖场吸引力（卖场面积、知名度、促销活动等）；
  - **Tij** = I 地区到 J 商店的距离阻力（交通时间、交通系统等）；
  - **λ、μ** = 以经验为基础估计的变数（**通常 λ=1，μ=2**）；n = 相互竞争的商店数；
- 引申：I 地区光顾 J 商店人数 = Pij × I 地区消费者数量。

**三个假设条件**：A 概率随卖场面积变化（面积代表商品齐全度与用途多样化）；B 消费者因购物动机走进卖场；C 概率受竞争店影响——**竞争店越多，概率越小**。

## 计算步骤（两步）

1. **算消费概率**：已知各店吸引力（Sj/Sm/Sn）与距离（Tij/Tim/Tin）→ 按公式求 I 地区到各店的概率（案例假设"吸引力只考虑面积"）；
2. **估算消费人群数**：**Eij = Pij × Ci**（Ci = 特定地区人群数）——即该店商圈范围内来自 I 地区的顾客规模。

## 应用：预测新店销售额（六步）

① 把市场区域划分为较小的顾客带分区 → ② 确认区域内所有竞争店规模（含拟开新店）→ ③ 确认各分区中心到各店的距离与时间 → ④ 各分区抽样调查（购买频率、习惯）→ ⑤ 计算新店对各分区的购物概率 → ⑥ 预计新店各分区销售额。
- 公式：**分区销售额 = 分区购物概率 × 分区人口 × 人均购买额**；
- 逐分区比较销售额 → 决定开店位置。

## 贡献与局限（原文）

- **贡献**：从"都市"单位具体到商店街/百货店/超市单位；综合考虑人口、距离、零售面积规模；将引力强弱与购物比率发展为**概率模型**；考虑顾客对距离的敏感度 → 可求出行车概率、预测销售额、集客能力、商圈结构与竞争关系变化；"更接近于实际"；
- **局限**：① 用卖场面积代替吸引力过于武断（同面积的百货店/超市/商业街被视作同魅力）；② 必须用计算机 + 需市场调查求 λ 值（费时费钱）；③ 修正参数与各地实际不适应（地区商业与消费文化差异大）；④ 各值的计算标准直接影响精度。

## 案例锚点（原文）

I 地区到 A/B/C 三店（时间 30/15/30 分钟；面积 9000/6000/1000 ㎡）→ 概率 **A 41% / B 55% / C 4%**（B 因时间最短概率最高）。

## 相关工具

- **雷利法则**（1931，威廉·J·雷利，基于万有引力、调查 150 城）：城市吸引力**与规模成正比、与距离成反比**；三假设（两城公路等距接近性/商品服务多少以人口为标志/**顾客只到一个城市购物**）；公式 Ba/Bb = (Pa/Pb)^N × (Db/Da)^n（N=1、n=2）；例：C 市到 A（4 万人，30km）、B（1 万人，10km）两市购物比例为 **4:9**（B 因近而吸引力大）；局限——只考虑距离未计交通状况（应以时间衡量）、"认知距离"受购物经验影响、人口数不具代表性（宜用销售额）；**只适用于耐用品、专门品**，不太适用日常消费品；资料不足时仍可粗略适用。
- **雷利和哈夫的修正模型**（日本通商产业省）：规定 **λ=2**、把"时间"表示为"两地距离"；**耐用品与日用品分别计算**；适用范围更广（互补完善雷利法则）。
