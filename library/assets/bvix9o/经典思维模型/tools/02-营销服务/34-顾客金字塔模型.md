# 顾客金字塔模型

> 编号 #34 ｜ 篇：二·营销服务 ｜ 源：`TOOL` P0606–P0625
> 又称：Customer Pyramid（泽丝曼尔 · 勒斯特 · 兰蒙 2002） ｜ 类型：顾客细分管理工具

**一句话**：按**盈利能力**把顾客分为**铂金 / 黄金 / 钢铁 / 重铅**四层——把有限资源集中到盈利能力最强的顾客身上，对不同层提供不同服务（**顾客炼金术**：把低层顾客升级、放弃无利润顾客）。

## 什么时候用

- 顾客分层管理与资源配置（营销预算、服务投入按层分配）；
- CRM 与顾客资产经营（按顾客终身价值构建）；
- 服务降本（有限资源下避免"为最不盈利的顾客提供过多服务"）。

**不适用**：顾客数量极少且无法分层；信息不足无法评估顾客价值时（信息收集是最大难点）。

## 四层顾客（盈利从高到低）

| 层级 | 特征 |
|---|---|
| **铂金层**（顶部） | 最能使企业赢利：使用量大、**价格敏感度低**、愿试用新产品新服务、**对企业忠诚感强**；愿为更优质服务支付更高价格；购买量与购买额不断递增；真正的忠诚者 |
| **黄金层** | 创造的利润较少：可能是大量使用者，但**希望优惠价**、忠诚度不高；为降低风险**从多家企业购买**（对价格敏感度稍高于铂金，要求折扣→边际利润率降低） |
| **钢铁层** | 可提供企业**必需的经济收益**，但消费量、忠诚度、利润数额**都不值得特殊服务** |
| **重铅层**（底部） | 需花费**大量成本**建立与保持关系：消费额与利润非常有限但**要求很高**；可能是"问题顾客"（向他人抱怨、损害声誉）——过于重视将浪费大量资源 |

- 模型不只依据消费额，还考虑多种利润率相关变量（因行业而异，**尤其适用服务业**——更易了解顾客信息、更易按详细资料划分层次）；
- **顾客价值构成三部分**：**历史价值**（已实现的）+ **当前价值**（行为模式不变的话将来会带来的）+ **潜在价值**（交叉销售/调动积极性/推荐带来的可能增量）；
- **顾客利润与投资成本呈反向关系**：铂金利润大、维系成本少；重铅利润为负、维系成本却大得多；
- 最常见的形态：**80/20 分布的顾客金字塔**（20% 顾客产生 80% 销售/利润）。

## 工具运用（分类管理）

**核心顾客（铂金 + 黄金，约 20%）**：
1. **增进对顾客需求的了解**：市场调研与分析（1990-1996 全球委托调研费用翻倍达年均 70 亿英镑；内部资料分析费增长更快）；高级经理接触顾客计划；密切关注竞对（三类监视：跟踪记录并图表化 / 解释原因 / 进行预测）；
2. **制定顾客满意（CS）计划**（科特勒满意定义：可感知效果与期望比较后的愉悦或失望状态——是心理反应而非行为；CS 把满意作为衡量经营活动的**唯一尺度**；强调全过程和差异性 + 满足社会需要）；
3. **提高顾客忠诚**（忠诚定义：对偏爱产品的深度承诺、一贯重复购买、不因市场情景和竞争性营销转移；忠诚五功能：提高盈利能力/增加份额/减少交易成本/**降低价格弹性**/乐于推荐有助信誉；**获得新顾客的投资比留住现有顾客多 5 倍**；感情联系渠道：电话问候/节日贺卡/联谊会等 → "自己人效应" → 基于信任与喜欢长期购买）；
4. **黄金层 → 铂金层**：全面服务 / **外包服务**（替客户做他们不擅长的职能工作，增强关系与顾客资产）/ **学习关系**（数据库记录每次交往 + 定制化服务）/ 扩大产品线增大品牌影响力。

**非核心顾客（钢铁 + 重铅，约 80%）**：
- **钢铁层 → 黄金层**：调整价格结构刺激额外销售额？/ 电话代替销售代表拜访降服务成本？/ 让顾客为可接受的服务付费？——能转化则转化，无法转化可考虑维持；
- **放弃重铅层**：先尝试——**提高售价**（要求为免费服务付费——真重铅不愿付费会离开，愿付费者变为钢铁层）；**降低成本**（高效低成本服务）；仍无法转化则**回避**；**终止关系只能作为最后手段**——稳定专业地处理、注意方式避免不利口头宣传；放弃无利润顾客将**解放销售人员**去关注其他盈利机会；
- **顾客炼金术**（重要管理措施）= 把金字塔中较低层次顾客转变为较高层次顾客、提高整体收益的艺术（金→铂、铁→金、放弃重铅均属之）。

## 约束条件与适用范围

- **约束条件（四个方面）**：① 各层消费者须有**可识别的人口统计特点**（识别与理解需求特点）；② 不同层顾客**对服务质量有不同看法**（须提供不同水平服务）；③ **不同驱动因素**引起不同层的购买行为并影响购买量（据此差异化营销）；④ 不同层对相同服务和营销有**不同反应**（较高层对服务质量改进反应更强烈、改进服务能从高层顾客获得更高投资回报）；
- **适用范围（七种情况收益明显）**：企业只有**有限的服务资源**（否则等于给最不盈利顾客过多服务、最好顾客反而得不到所需水平）/ 顾客需要不同服务或水平（电话公司三类客户例）/ 顾客愿意为不同服务水平**支付不同价格**（速递公司例）/ 顾客**对"价值"含义有不同理解**（四种理解：价格低廉 / 一切要求 / 质量价格比 / 得失比——采用"价格低廉"定义的往往是"铅类"顾客）/ 企业**可分隔不同类别顾客**（低层顾客看到他人受更好服务会不满——除非有正当理由如"70 岁以上老人免费乘车"）/ **差异化服务有助激励升级**（经济舱看到头等舱待遇 → 激励成为常客）/ 能为各层确定**不同营销策略**（尤其不同定价 + 产品服务组合策略）；
- **为不同层提供不同服务**：铂金与黄金——详细了解每个顾客的期望偏好与消费记录、提供**高度个性化的优质服务**；钢铁——只需了解同类顾客的平均需求、提供**略高于一般水平**的服务；重铅——采取**低成本低价战略**、把重点放在提高服务效率、无须投入过多资源。

## 构建意义

1. **正确配置营销资源**（直观展现顾客价值：识别创造 80% 利润的 20% 优质客户——香港恒生银行按资产规模分四级：普通（一般服务 + 引导使用自助设备）/ 纵横理财（5000 元港币以上）/ 优越理财（50 万以上——特惠利率 + 专人经理 + 优越理财中心）/ 私人银行（1000 万以上——固定私人经理贴身服务））；
2. **动态管理顾客**：定期审视顾客发展、修正终身价值估值与层级；防止高层下滑 + 低层升级；**对层级下滑或低层级顾客要特别慎重**——跟踪调查原因（顾客自身经营恶化 / 被竞对拉走 / 企业自身问题——若是自身问题必须针对性改进，任其发展只会把顾客更快推到竞对怀抱）；
3. **难点在顾客信息的收集与处理**（金融/电信/旅行社/公用事业尤其银行业条件最充分；数据库与数据挖掘技术发展使顾客终身价值评估越来越可靠）。

## 案例锚点（原文 · 移动通信企业）

四层占比：铂金 3-5%（月话费 500-600 元以上：企事业/政府领导、商务人士、报销话费者、高收入者——要求技术性质量 + 功能性服务）；黄金 20-30%（使用超三年、月话费 300-600 元、常以改购竞对服务讨价还价、可能同时用两种网络、流失率与欠费率高于铂金）；钢铁 50-60%（月消费不到 200 元、价格敏感、易被优惠策反、"跳槽"离网率较高）；重铅 3-5%（消费低要求高、抱怨攻击企业形象、含恶意欠费"问题顾客"）。
**管理措施**：金→铂（客户经理面对面 + 商业友谊但警惕"人员跳槽带走客户"→ 重点应放在企业服务本身；全面通信服务：咨询/代缴费/热线票务/秘书服务/年审提醒；外包服务：承接客户企业通信设备维护 + 办公自动化互联；扩大经营范围；学习关系定制化）；铁→金（多种服务方式降低**非货币代价**（自助系统/呼叫中心/网站——不轻易直接降价）；顾客消费奖励计划（注意区分顾客、防止盲目礼遇降低收益）；有效**补救性服务程序**（培训沟通技巧 + 授权 + 奖励 + 找差错根本原因））；回避铅层（低成本服务设施/通信"最低消费套餐"（提高享受优惠门槛→刺激自愿消费→部分铅层转铁层）/ 主动摆脱"问题顾客"（标记名单/预付制/到期半停机/强制措施/诉讼）；注意方式避免歧视感）。
