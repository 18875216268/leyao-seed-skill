# 净现值法（NPV）

> 编号 #78 ｜ 篇：五·财务管理 ｜ 源：`TOOL` P1506–P1518
> 全称：Net Present Value ｜ 类型：投资决策方法

**一句话**：找出计划的预期现金流量、假设一个适当的折现率（资金成本）求其现值——**用 NPV 的大小评价投资方案**（"企业投资决策中最基本、最常用的一种方法"）。

## 什么时候用

- 投资项目可行性评价（NPV≥0 可行）；
- 互斥方案比选（净现值最大最优）；
- 与金融市场投资机会比较决策。

**不适用**：年限不等的方案比较（"只适用于年限相等的互斥方案的评价"）；投资项目具有显著经营柔性或可延缓性的场景（NPV 隐含假设矛盾——需弹性决策技术补充）；现金流无法预估的项目。

## 概念与计算步骤（四步）

- **现值（PV）**："按照货币时间价值原理，对投资项目在未来的现金流量按照一定的贴现率贴现后的价值"；NPV 法"是一种考虑到货币时间价值的评估法则"；
- **第一步：计算投资项目的每年净现金流量**——现金流量三构成：**现金流入量**（营业收入（经营期主要现金流入项目）+ 固定资产变价收入 + 回收流动资金 + 其他）；**现金流出量**（建设投资（含更改投资——固定资产购置成本或建设费、运输成本、安装成本 + 无形资产投资和开办费用，"是建设期发生的主要现金流出量"）+ 垫支的流动资金 + 经营成本 + 各项税款 + 其他）；**现金净流量**（=流入−流出）；营业现金净流量公式：**= 营业收入−经营成本 = 营业收入−付现成本−所得税 = 净利润 + 折旧**；
- **第二步：计算未来报酬的总现值**——"如果每年的现金净流量相等时，则按**年金现值**进行贴现；如果不相等时，则先对每年的净现金流量按**复利现值**进行贴现、然后汇总；如果寿命期后有固定资产残值和垫支的营运资金，还应按复利现值贴现"；
- **第三步：将投资额折算成现值**（一次投入=现值；多次投入→初始投资以外的各次投资额按复利现值贴现再加初始投资额）；
- **第四步：计算净现值 = 未来报酬的总现值 − 初始投资额现值**。
**基本公式**：**NPV = Σ NCF_t ×(P/F, i, t)**（i=该项目行业基准折现率；(P/F,i,t)=复利现值系数）；**两种简化**：① 建设起点一次投入、建设期为零、投产后 1~n 年净现金流量相等（普通年金）——**NPV = −原始投资额 + 投产后每年相等的净现金流量 × 年金现值系数**；② 建设期 s、投产后 n−s 年每年净现金流量相等（递延年金）——按递延年金现值计算。

## 折现率确定与决策标准

- **折现率的重要性**："正确地选择折现率至关重要，它直接影响项目评价的结论"——"如果选择的折现率**过低**，则会导致一些经济效益较差的项目得以通过，从而浪费了有限的社会资源；如果选择的折现率**过高**，则会导致一些效益较好的项目不能通过评估，从而使有限的社会资源不能充分发挥作用"；
- **四种确定方法**：以投资项目的**资金成本**作为折现率 / 以投资的**机会成本**作为折现率 / **根据不同阶段采用不同折现率**（建设期净现金流量现值以贷款实际利率；经营期以全社会资金平均收益率）/ 以**行业平均资金收益率**作为折现率；
- **决策标准**（"净现值指标是折现的绝对值正指标"）：NPV ≥ 0 → 方案可行；NPV < 0 → 方案不可行；互斥方案比较（无资金限制、净现值均大于零）→ **净现值最大的方案最优**。

## 运用前提 · 注意问题 · 应用难点

- **前提条件 3 条**：已知各年净收益 / 已知投资方案寿命期（经济期）/ 已知折现率（一般为行业基准收益率（最低希望收益率）——"通常要高于筹资发生的资本成本率"）；
- **注意问题 4 条**：① 折现率的确定——"净现值法虽考虑了资金的时间价值，可以说明投资方案高于或低于某一特定的投资的报酬率，**但没有揭示方案本身可以达到的具体报酬率是多少**"；② 只适用于**年限相等**的互斥方案；③ "净现值法是假定前后各期净现金流量均按最低报酬率（基准报酬率）取得的"；④ "若投资项目存在不同阶段有不同风险，那么最好**分阶段采用不同折现率**进行折现"；
- **应用难点 3 条**：A. 现金流预估——"要对企业未来一定时期（通常是 **5 年**）每年的现金流作出预估，**除公用事业公司外，最有经验的分析员也无法直接准确估计企业未来几年的现金流**"；B. "折现率的确定没有很令人信服的方式，而且**风险是每年变化的**、投资者主观上对未来每年风险的预期也是逐年变化的"；C. 动态变化可能失效——"需要以**灵活的弹性决策技术**来加以补充"。

## 特征（六条）与缺陷

- **特征 6 条**：① 能与**金融市场的投资机会**进行比较（用金融市场期望收益率作折现率、NPV 为正就投资、为负就"去金融市场上寻找更好的投资机会"）；② 是**企业价值创造的衡量标准**（正创造价值、负减少价值）；③ **使用现金流量而非会计利润**（"相比之下，利润包含了许多人为因素，人们可以通过选择会计方法来调节利润——利润并不等同于现金"）；④ **包含了项目的全部现金流量**（"其他一些投资决策方法往往会忽略某一特定时期的现金流量"）；⑤ 对现金流量进行**合理折现**（"既考虑了货币的时间价值，也通过对折现率或是对未来现金流量的调整考虑了项目的风险"）；⑥ **具有可加性**——"如果两个项目是相互独立的，则其 NPV 可以相加……一个项目的某项相关成本在计算中由于疏忽等原因没有考虑，只要把这项成本进行折现后从原有的 NPV 中减去即可，而不必调整其他项目"——"**和其他投资决策方法相比，NPV 法在价值管理中是最优的投资决策方法**"；
- **缺陷**：**两个隐含假设前提**——"一是投资是**可逆的**（如果市场条件比预期的要差就可以某种方式不投资并能收回支出）；二是投资**不可延缓**（公司要么现在投资，要么永远失去这个机会）"——"虽然有些投资项目属于这种分类，但大多数情形并非如此——现实中更多的投资项目是**不可逆的，而且是可以延缓的**"；加上两缺陷：① **折现率的确定较为困难**（期望报酬率三部分：无风险报酬率+通货膨胀系数+风险报酬率——"大多投资项目风险高、影响因素较多，因而风险报酬率的确定较困难"）；② **忽视投资项目中的经营柔性**——"NPV 法假设项目投产后总是按决策之初的既定程序进行，未考虑经营者对未来变化的适时调整——事实上……如果市场环境对该项目有利，经营者可以在原始投资的基础上追加投资或扩大原有的生产规模；而在市场环境不利时则可延缓该项目的投资——**这种经营柔性无疑是有价值的**；NPV 法只是在当前所能获得信息的基础上对单个项目的现在投资与现在不投资相比较，而不是比较今年的投资、明年的投资、甚至后年投资的现金流的差别——从时间上限制了投资的灵活性及项目经营柔性的价值"。

## 案例锚点（原文 · 某企业项目）

某企业拟建一项固定资产：需投资 **100 万元**、按直线法计提折旧、使用寿命 **10 年**、期末无残值、当年投产、预计投产后每年可获利 **10 万元**、行业基准折现率为 **10%**：
- 原始投资额 NCF₀ = **−100（万元）**；投产后每年相等的净现金流量 NCF₁~ₙ = 10 + 100/10 = **20（万元）**；
- **NPV = −100 + 20×(P/A,10%,10) = −100 + 20×6.1446 = 22.8914（万元）> 0 → 方案可行**；
- 若该企业建设期为 1 年：**NPV = −100 + 20×(P/A,10%,10)×(P/F,10%,1) = −100 + 20×6.1446×0.9091 = 11.7194（万元）> 0 → 方案可行**。

## 相关工具：内含报酬率法（IRR）

- **经济涵义**："项目在寿命期内，按利率 I=IRR 计算，除寿命期结束后正好全部投资回收回来外，其它年份均存在未回收的资金、在寿命期内始终处于偿还未回收资金状态——**内部收益率是留在项目内部尚未回收资金的收益率**"；"如果内部收益大于金融市场上预期的资金成本，方案是可行的，否则就是不可行的"；**定义："内部收益率就是净现值为零时的折现率"**；
- **计算步骤 3 步**：在计算净现值的基础上，如果净现值是正值→用**更高的折现率**来测算直到净现值近于零 → 继续提高折现率直到测算出一个净现值为负值（"如果负值过大，就降低折现率后再测算到接近于零的负值"）→ 根据接近于零的相邻正负两个净现值的折现率、用**线性插值法**求得内部收益率；
- **与 NPV 的区别与关系**：区别——"净现值法是先根据预期的金融市场筹措资金的资金成本来确定折现率或基准收益率，然后根据计算出的净现值来判断项目的可行性；内部收益率法则是计算能使财务净现值为零时的折现率是多少"；关系——"一个项目净现值的大小与计算时采用的折现率大小有关，**折现率越大、净现值越小**……对于确定的各年现金流量而言，其净现值与内部收益率之间存在着对应关系"——**NPV>0 ⟺ IRR>基准收益率（可行）；NPV<0 ⟺ IRR<基准（不可行）；NPV=0 ⟺ IRR=基准**；**矛盾情形**（NPV 大而 IRR 小）——"决策者只需要确定是要更多的财富还是要更高的内含报酬率——**在两两选择的情况下，净现值最大的方案自然效用最高，是最优选择**；而在资金充裕的情况下，存在多个方案优先性排序的问题，内含报酬率较高者优先安排，但目的仍然是为保持投资组合的总净现值最高"；
- **两者比较表**：NPV 能用**绝对量**表示项目获利能力 / 各项目净现值**可以相加** / 必须已知折现率才能计算出来 / 净现值不小于零则项目可行；IRR 能反映项目的**资金增长速率** / 各项目内部收益率**不能相加** / 可以直接计算出来 / 内部收益率不小于基准收益率项目可行。
