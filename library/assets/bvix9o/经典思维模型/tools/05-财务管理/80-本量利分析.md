# 本量利分析（CVP）

> 编号 #80 ｜ 篇：五·财务管理 ｜ 源：`TOOL` P1530–P1551
> 全称：Cost-Volume-Profit Analysis（又称盈亏临界点/保本点分析） ｜ 类型：管理会计分析工具

**一句话**：在**变动成本计算模式**基础上，以数学化会计模型与图文揭示**固定成本、变动成本、销售量、单价、销售额、利润**等变量之间的内在规律性联系——"实施目标成本管理的一个重要工具"。

## 什么时候用

- 保本预测（"预测只有销售多少数量的产品才能保本"）与目标利润规划；
- 价格—销量—成本组合决策（"为了扩大销售数量，必须把产品的单价降为多少"）；
- 经营安全评价、亏损户取舍、特殊订货决策。

**不适用**：成本无法按习性可靠划分的企业（前提条件）；混合成本未分解的场景（"不能简单地将之归入固定成本或变动成本"）；相关范围之外的外推（线性假设）。

## 产生与概念

- **产生**：1904 年英国出版的会计百科全书最早出现保本图文字记载 → 1922 年美国哥伦比亚大学会计教授提出完整的保本分析理论 → 50 年代后 CVP 技术在西方会计实践中广泛应用、成为现代管理会计学重要组成部分 → **80 年代初我国引进**；
- **概念**："在变动成本计算模式的基础上，以数学化的会计模型与图文来揭示固定成本、变动成本、销售量、单价、销售额、利润等变量之间的内在规律性的联系，为会计预测决策和规划提供必要的财务信息的一种定量分析方法"；**两部分内容：盈亏平衡分析和实现目标利润分析**——"打破了传统会计对成本、业务量、利润三者间关系的认识"；
- **五个基本假设**：① 成本形态假设（全部成本必须被划分为固定成本和变动成本两部分）；② 相关范围与线性假设（"在一定时期和一定业务量范围内，成本水平保持不变——固定成本总额和单位变动成本保持不变，成本和销售收入均表现为直线关系"）；③ 目标利润假设（所分析的利润为"**税前利润**"）；④ 变动成本法假设；⑤ 产销平衡和品种结构稳定假设。

## 基本公式与贡献边际

- **基本公式**：**营业利润 = 销售收入 − 变动成本 − 固定成本 = 销售量 ×（单价 − 单位变动成本）− 固定成本**；衍生关系：销售收入 = 变动成本 + 贡献边际；**营业利润 = 贡献边际 − 固定成本**；
- **贡献边际**（也称贡献、贡献毛益、边际利润）："销售收入与相应的变动成本之间的差额——它是一个表示能为企业营业利润做多大贡献的指标，**只有贡献边际在补偿固定成本后还有剩余，企业才会有营业利润**"；
- **三种表现形式**：贡献边际总额 **Tcm**（销售收入总额 − 变动成本总额）/ 单位贡献边际 **cm**（单价 − 单位变动成本）/ 贡献边际率 **cmR**（贡献边际占销售收入的百分比）；关系：总额=单位×销售量；
- **变动成本率**（变动成本占销售收入的百分比）——互补性质：**贡献边际率 + 变动成本率 = 1**——"变动成本率越高，贡献边际率越低、盈利能力越小；反之亦然"。

## 前提（成本习性）与关键（盈亏临界点）

- **成本习性（前提）**：探讨成本变动与业务量变动的依存关系——**变动成本**（"凡成本总额与业务量总额成正比例增减变动关系的叫做变动成本，但就单位产品中的变动成本而言则是固定不变的"——原材料、辅助材料、燃料动力、计件工资等）/ **固定成本**（"一定时期和一定业务范围内不受业务量增减变动影响而固定不变——就单位产品中的固定成本而言则与业务量的增减成反比例变动"——办公费、折旧费、管理人员工资、租赁费等）/ **混合成本**（"虽然也随业务量的变动而变动，但不成同比例变动，不能简单地归入变动成本或固定成本"）；
- **盈亏临界点（关键）**："所谓盈亏临界点，就是指使得**贡献毛益与固定成本恰好相等**时的销售量——此时企业处于不盈不亏的状态"；两种计算方法：**按实物单位计算**（单位产品贡献毛益 = 单位产品销售收入 − 单位产品变动成本）和**按金额综合计算**。

## 基本内容（保本 · 经营安全 · 保利 · 多品种）

**单一品种的保本分析**：保本点（又称盈亏临界点、收支平衡点——"企业恰好达到保本状态的销售量或业务收入总额……当销售量超过保本点时企业就能结余，低于这一点时企业就会亏损"）：**保本量 = 固定成本 ÷ 单位贡献边际**；**保本额 = 固定成本 ÷ 贡献边际率 = 固定成本 ÷（1 − 变动成本率）**（基本等式法与边际贡献法）；
**经营安全程度评价**：**安全边际**（"企业经营盈亏临界点以上的销售量——反映企业运营的安全程度，数额越大安全程度越高"）；**安全边际量 = 实际或预计销售量 − 保本量**；**安全边际率 = 安全边际量 ÷ 实际或预计销售量 ×100%**；**评价标准**：10% 以下=危险 / 10%~20%=值得注意 / 20%~30%=较安全 / 30%~40%=安全 / **40% 以上=很安全**；**安全边际与利润的关系**——"利润是由安全边际提供的"：**利润 = 安全边际量 × 单位边际贡献 = 安全边际额 × 边际贡献率**；**利润率 = 安全边际率 × 边际贡献率**（"安全边际为零时企业处于保本状态；为负数时利润也为负数"）；
**单一品种的保利分析**：保利点（"在价格和成本水平既定的情况下，为确保预先制定的目标利润的实现而应达到的销售量和销售额"——"保利点的模型是保本点模型的扩展，就是在保本量公式的分子上加了目标结余部分"）：**保利量 =（固定成本 + 目标利润）÷ 单位贡献边际**；**保利额 =（固定成本 + 目标利润）÷ 贡献边际率**；**保净利分析**（保净利量 =（固定成本 + 目标净利润 ÷（1 − 所得税率））÷ 单位贡献边际）；
**多品种条件下的本量利分析**（"由于各品种的价格、单位变动成本等不同，不能将各品种的销售量简单相加，只宜用货币金额形式来反映保本点"）：**加权平均法**（以各产品预计收入额占总收入额的比重为权数确定加权平均边际贡献率——步骤：算各产品边际贡献率→算各产品收入比重→算综合边际贡献率→算多品种保本额→按比重分解各品种保本额→算多品种保利额→分解各品种保利额）；**顺序法**（"按照事先规定的销售品种顺序，依次用各品种的边际贡献来补偿全部固定成本"——各品种边际贡献率由大到小排列后与固定成本比较）。

## 本量利分析图（三种）

① **标准本量利图**（运用最广泛——绘制五步：选坐标系（横轴销售量、纵轴金额）→在纵轴上找固定成本数值画平行线→以固定成本值为起点、以单位变动成本为斜率画总成本线→以原点为起点、以单价为斜率画销售收入线→确定盈亏平衡点）；**观察三规律**："在盈亏平衡点不变的情况下，销售量超过盈亏平衡点一个单位，即可获得一个单位边际贡献的盈利……低于一个单位就产生一个单位边际贡献的亏损"；"在销售量不变的情况下，盈亏平衡点越低，盈利区的面积就会扩大、亏损区的面积就会缩小"；"在销售收入既定的情况下，盈亏平衡点的高低取决于单位变动成本和固定成本总额的大小——**单位变动成本或固定成本总额越小，盈亏平衡点就越低**"；② **边际贡献式**（"将固定成本置于变动成本线之上，总成本线是一条平行于变动成本线的直线——能直观地反映出边际贡献的形成及其与利润之间的关系"）；③ **利润—业务量式（利量图）**（"以利润线代替销售收入线和总成本线……提供的利润信息比上述两图更加直截了当"——利润线起点在"与固定成本总额相等的亏损额"上、与横轴的交点就是盈亏平衡点）。

## 因素变动影响（五类）与利润敏感性分析

- **影响 5 类**：① **销售价格变动**（"会引起单位边际贡献和边际贡献率向**同方向**变动——价格上升→销售收入线斜率提高→盈亏平衡点降低、利润增加"）；② **单位变动成本变动**（向**相反方向**——上升→总成本线斜率提高→盈亏平衡点上升、利润减少）；③ **固定成本变动**（"固定成本的大小与企业经营规模直接相关……固定成本总额上升会抬高总成本线的位置"）；④ **多因素同时变动**；⑤ **产品品种结构变动**（"当边际贡献率较低的产品的销售额占比上升时，企业的加权平均边际贡献率会下降，从而导致盈亏平衡点综合销售额的上升——在同样的销售收入总额情况下企业的利润就会下降"）；
- **利润敏感性分析**（"研究利润对各项因素变动的敏感程度"）：**强敏感性因素**（"略有变动就会导致利润发生较大幅度的变动"）vs **弱敏感性因素**；**敏感系数**（"测定某因素变动的利润敏感程度的指标"）——"使企业管理人员清楚地知道影响利润的各因素中其敏感程度哪个强哪个弱，从而分清主次"。

## 应用与案例锚点

- **应用范围 7 条**：测定保本产销规模 / 测定目标利润所需业务量 / 固定成本变化影响 / 售价变化影响 / 售价对量本利影响 / 品种构成影响 / 国家规定范围内"降低销售价格、扩大销售数量，或者提高价格、减少销售数量对盈利的影响"；
- **注意事项 3 条**：严格按成本习性划分变动/固定成本（"这是管理会计规划和控制企业经营活动的前提"）；混合成本"应采用**数学分解法**最终将之分解为固定成本和变动成本两个项目"；期间费用中的变动部分（银行贷款利息、产品包装费等）"应以产品制造成本为权数合理分摊到各该产品成本中"；
- **经营决策应用**：**不同生产方法选择**（"如果新方法的盈亏临界点低于现行方法的盈亏临界点，则说明在企业生产能力得到充分发挥、产品又有销路时，新方法比现行方法能获得更大的利润"）；**购置生产设备的选择**（三步：算购置前各项指标→算购置后变动成本减少数与折旧增加数及新盈亏临界点→"如果利润增加了，购置就合算"）；
- **案例锚点（某企业 2002 年）**：**保本分析**（保本结算量 = 36180 ÷（216.83−199.78）= **2122 万吨**；保本结算额 = 2122×216.83 = **460113 万元**）；**经营安全分析**（安全边际量 = 4500−2122 = **2378 万吨**；安全边际率 = 2378÷4500×100% = **25.84%**——介于 20%~30%（"较安全"档；原文此处引述有笔误）；**保利分析**（五个变形公式：实现目标利润的结算量=（销售环节费用+目标利润）÷（结算价−销售成本）、结算价、吨煤销售成本、销售环节费用等——"根据企业某个经营期间的计划数或实际数，可以计算出为实现当期目标利润各因素应当达到的最低或最高值"）；**利润敏感性**（灵敏度指标 Si=Mi÷利润基数×1%——结算价 S₁=975741.89÷40520×1%=**24%** > 单位销售成本 S₂=899010÷40520×1%=**22%** > 结算量 S₃=76725÷40520×1%=**1.8935%** > 销售环节费用 S₄=36180÷40520×1%=**0.9%**——"企业的结算价的灵敏度指标最高……其排列规律为 S₁>S₂>S₃>S₄"）；**对亏损户是否继续销售**（"只要亏损户提供的贡献边际是正值、能够分担相应金额的销售环节费用，就应当继续销售；如果提供的贡献边际是负值，则应当停止"）；**特殊价格订货**（"只要其提供的特殊价格大于单位销售成本（即单位贡献边际是正值），就应当接受订货"）。
