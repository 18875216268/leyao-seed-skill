# 比率分析法

> 编号 #74 ｜ 篇：五·财务管理 ｜ 源：`TOOL` P1436–P1453
> 类型：财务分析基础工具（"财务分析最基本的工具"）

**一句话**：通过对财务报表中**两个以上数据所反映的财务关系**进行研究，揭示企业的财务状况、经营成果和现金流动情况（三大类指标：偿债能力 / 盈利能力 / 资产管理能力）。

## 什么时候用

- 财务分析的基础环节（"财务分析最基本的工具"）；
- 债权人（偿债能力）、管理当局（综合）、政府机构等不同目的的差异化分析；
- 与趋势分析法、比较分析法配合使用。

**不适用**：孤立看单一比率（"不能简单、孤立地看待任何一个比率"）；报表不真实（"可靠性大打折扣，甚至会严重歪曲事实真相"）；跨口径直接比较（"只有根据正确的数据计算的财务比率才能反映企业的本质特征"）。

## 三大类指标体系

① **偿债能力比率**：流动比率、速动比率、经营活动净现金流量与负债的比率、资产负债率、负债与股东权益比率、利息保障倍数等；
② **盈利能力比率**：资产报酬率、净资产收益率、毛利率、销售收入利润、成本费用利润、每股收益、市盈率等；
③ **投资和资产利用能力比率**：应收账款周转率、存货周转率、营运资金周转率、固定资产周转率、总资产周转率等。
**三类关系**："**良好的投资及其对资产的有效利用是企业盈利的基础，企业持续盈利是其偿还所欠债务的保障**——正确的投资及其对投资所形成资产的恰当运作是企业长期生存与发展的基石"。

## 偿债能力分析（六个比率）

**短期偿债比率**：
- **流动比率 = 流动资产 ÷ 流动负债 ×100%**——"一般认为，流动比率为 **2:1** 对于大部分企业来说是比较合适的比率；**流动比率小于 1.0 是一个警示信号**"（不同行业差别很大）；"在很大程度上是一个**不精确**的指标——未考虑将非现金流动资产转化为现金的速度、也没有考虑短期债务的偿付期限——**孤立地看待它的作用很小**"；
- **速动比率**（酸性测验比率——流动比率的变形、更严格的测试）**=（流动资产−存货）÷ 流动负债**——"一般认为 **1:1** 被认为是合理的"；偏高→"有较多的不能盈利的现款和应收账款、企业失去了收益的机会"；偏低→"依赖出售存货或举新债来偿还到期债务——可能造成急需出售存货带来的**削价损失**或举新债形成的利息负担"；
- **现金到期债务比**（流动比率和速动比率都是**静态**分析、有很大局限性——"真正能用于偿还债务的是现金流量"）：**现金流动债务比 = 经营现金净流量 ÷ 流动负债**（反映实际短期偿债能力）；**现金债务总额比 = 经营现金净流量 ÷ 债务总额 ×100%**（反映最大付息能力——"企业只要能够按时付息，就能借新债还旧债，维持债务规模；**若低于银行同期贷款利率，说明该公司营业现金流量不足，举债能力差**"）。

**中长期偿债比率**：
- **资产负债率 = 负债总额 ÷ 资产总额**（又称举债经营比率——"衡量企业在清算时保护债权人利益的程度"；"从股东的立场看，在**全部资本利润率高于借款利息率时，负债比例越大越好**，否则相反"）；
- **产权比率 = 负债总额 ÷ 股东权益总额**（债务股权比率——反映企业基本财务结构是否稳定；"一般来说股东资本大于借入资本较好，但也不能一概而论"——**分时期判断**：通货膨胀加剧时期多借债可把损失和风险转嫁给债权人 / 经济繁荣时期多借债可获取额外利润 / 经济萎缩时期少借债可减少利息和财务风险；**产权比率高=高风险高报酬的财务结构、低=低风险低报酬**；同时表明清算时对债权人利益的保障程度）；
- **利息保障倍数 =（利息费用 + 税前盈利）÷ 利息费用**——"可用于测试公司偿付利息的能力；越高说明债权人每期可收到的利息越有安全保障"。

## 获利能力分析（六个比率）

- **营业毛利率 = 营业毛利额 ÷ 营业净收入 ×100%**——"毛利是公司利润形成的基础；单位收入的毛利越高、抵补各项支出的能力越强"——"与同行相比，毛利率偏低，则成本偏高"；
- **营业利润率**（营业利润与全部业务收入的比率）——"比营业毛利率更趋于全面"（抵扣营业成本和**全部期间费用**后的部分才构成稳定可靠的获利能力）；"比平均水平高些的营业利润率通常是企业良好管理的标志，但**不正常的过高营业利润率则可能意味着企业在未来会面临竞争**"；
- **资产报酬率 =（利润总额 + 利息支出）÷ 平均资产总额 ×100%**——"高于同期银行借款利率和社会平均利润率，则说明公司总资产获利能力足"；
- **资本金利润率 = 利润总额 ÷ 资本金总额 ×100%**——**基准利润率两部分**：相当于同期市场贷款利率（最低的投资回报）+ 风险费用率——"若实际资本利润率低于基准利润率，就是**危险的信号**"；
- **经营指数 = 经营现金流量 ÷ 净利润**——"**直接反映企业收益的质量**，说明公司每一元净利润中有多少实际收到了现金"；**<1 说明本期净利润中存在尚未实现现金的收入**——"即使企业盈利，也可能发生现金短缺，严重时会导致企业的**破产**"；
- **主营业务收入收现比率 = 销售商品提供劳务收到的现金 ÷ 主营业务收入**——">1 表明企业经营情况良好、应收账款管理也很到位；<1 可能是由于企业应收账款管理不善造成"。

## 资产管理能力分析（五个周转率）

- **应收账款周转率 = 销售收入 ÷ 平均应收账款**（"应收账款是指未取得现金的销售收入"）；**应收账款变现平均所需时间 = 365 ÷ 应收账款周转率**——"周转率越高、每周转一次所需天数越短，表明公司收账越快"；反之"变现过于缓慢、管理缺乏效率"；
- **存货周转率 = 销售成本 ÷ 平均商品存货**——"衡量公司销货能力强弱和存货是否过多或短缺的指标"；越高→"控制存货的能力越强、利润率越大、营运资金投资于存货上的金额越小"；反之→"资金积压、影响资产流动性、增加仓储费用与产品损耗、过时"；
- **固定资产周转率 = 销售收入 ÷ 平均固定资产金额**——"其比率越高表明固定资产周转速度越快、闲置越少；当然这一比率**也不是越高越好**，太高则表明固定资产过分投资，会缩短固定资产的使用寿命"；
- **资本周转率（净值周转率）= 销售收入 ÷ 股东权益平均金额**——"比率越高资本周转速度越快、运用效率越高；**但如果比率过高则表示公司过分依赖举债经营（即自有资本少）**"；
- **资产周转率 = 销售收入 ÷ 资产总额**——"衡量公司总资产是否得到充分利用的指标"。

## 局限性（三条）与应用策略（五条）

- **局限性**：① **财务报告的真实性影响可靠性**（报表按历史成本列示、未按通胀调整；"如果一个企业出于各种目的，有意人为地操纵某些会计事项的发生，甚至提供虚假的会计报表，那么据此计算的各种比率的可靠性就大打折扣"）；② **会计信息的可比性影响可比性**（存货计价和销售成本计价、折旧提取方法、投资收益核算、所得税确认——"会计准则允许使用几种不同的规则或程序，企业可以自行选择"→不同企业或同一企业前后期结论可能不同）；③ **会计信息的时效性影响有效性**（"历史不能代替未来，只能预示未来的可能趋向"；管理者如何取得并运用经济资源的情况"无法用比率指标分析得出"）；
- **应用策略 5 条**：① **做好基础工作**（先掌握非财务背景资料——分析目标/经营者诚信度与综合素质/人力资源与文化理念/经营环境与资源状况/发展阶段/发展战略/管理制度）；② **透过表面解读经营决策与经营活动**（"企业的经营决策和经营活动是'**本**'，财务比率所反映的企业状况是'**末**'——切不可本末倒置"）；③ **面向市场、面向未来**（避免"账面性、历史性和过去性"缺陷——"企业财务状况的好坏最终要由市场说了算、由投资者说了算"）；④ **有机结合进行综合分析**（"各项比率相互联系、错综复杂，不能简单、孤立地看待任何一个比率"）；⑤ **加强分析人员的培训与培养**（"使他们同时具备会计、财务、市场营销、战略管理和企业经营等方面的知识"——"分析人员的恰当判断都是最重要的"）。
- **应注意问题 5 条**：全面完整分析各种信息（会计报表、附表、附注、财务情况说明书 + 会计政策与重大会计事项 + 经济环境政治气候宏观政策）；**根据分析目的正确选择绝对数金额**（"将坏账费用与赊销金额对比计算的比率较之将坏账费用与销售收入（包括现销赊销）对比计算的比率就更有意义"）；注意**计算口径的一致性**（剔除非常因素——非主营业务巨额损益、重大事故或法律更改等特别影响）；有机结合综合分析；**与趋势分析法结合运用**。

## 案例锚点（原文 · 甲公司 2006 年）

**偿债能力**：流动比率 = 252593÷196623 = **1.28**（"离国际公认的安全比率 2 相差 0.72，说明短期偿债能力不足"）；速动比率 =（252593−32967）÷196623 = **1.12**；资产负债率 = 211138÷465088×100% = **45.4%**（"基本正常，说明该公司银行信誉较好"）；
**资产管理**：应收账款周转率 = 185134÷15590 = **11.66 次**（周转天数 = 360÷11.66 = **30.87 天**）；流动资产周转率 = 185134÷182992 = **1.01 次**（"说明该公司流动资产使用效率较低——表现在其他应收款、其他流动资产、存货、预付账款上，期末数比期初数增加了 **2.51 倍**，流动资金周转困难的局面仍在加剧"）；
**盈利能力**：资产净利率 = 4944÷364790×100% = **1.36%**；净值报酬率 = 4944÷167578.5×100% = **1.48%**（"**远远低于银行同期存款利率 2.25%**——说明所有者投资的获利能力较差、资本结构不尽合理，特别是对外投资占总资产的 **17.6%**、而投资回报率只有 **4.68%**（低于同期银行贷款利率 5.85%）——**甲公司既要合理使用全部资产，又要妥善安排资本结构**"）。

## 相关工具（两个配套方法）

- **趋势分析法**（动态分析法——"根据企业连续几期的财务报告，比较各期有关项目金额，以揭示当期财务状况和经营成果增减变化的性质及趋势"）：**应用前提**——各期会计数据时间上必须连续、中间没有间断，且**只反映百分率变化、不反映绝对值变化**；**三种具体应用**：① 重要财务指标的比较（**定基动态比率 = 分析期数额 ÷ 固定基期数额；环比动态比率 = 分析期数额 ÷ 前期数额**）；② 会计报表金额的比较（资产负债表/利润表/现金流量表比较——同时算绝对额与百分比）；③ **会计报表构成的比较**（以表中某总体指标作 100%、计算各组成指标占比——"能消除不同时期（不同企业）之间业务规模差异的影响"、可用于纵向和横向比较）；
- **比较分析法**（纵向比较=不同时期对比 / 横向比较=与同行业平均或其他公司对比）：**差异额 = 分析对象数值 − 判断标准数值**；**按内容分类 3**：比较会计要素的总量（时间序列为主、也可同业对比）+ 比较结构百分比（"主要用于发现有显著问题的项目"）+ **比较财务比率**（"比率的比较是最重要的分析……它们是相对数，排除了规模的影响"——"有些人只会计算财务比率而不会使用财务比率，使财务比率丧失了应有的作用"）；**按对比标准分类 5**：与企业预定目标比较（预算计划——内部考核）/ 与历史数据比较（发展状况趋势）/ 与行业平均水平比较（判断优劣地位）/ 与竞争对手实际水平比较（揭示竞争优势与差距）/ 与国内外同行业先进水平比较；**可比性要求**："相互对比指标的内容、口径、计算方法应当一致——若不一致应作必要的调整、换算，以消除不可比因素"。
