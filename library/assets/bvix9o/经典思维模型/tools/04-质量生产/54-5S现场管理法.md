# 5S 现场管理法

> 编号 #54 ｜ 篇：四·质量生产 ｜ 源：`TOOL` P0988–P1023
> 起源：日本丰田公司（1955） ｜ 类型：现场管理基础工具

**一句话**：**整理、整顿、清扫、清洁、修养（素养）**——在生产现场对人员、机器、材料、方法等生产要素进行有效管理（"五常法则"），是**现场科学管理的基础工具**（TPM/TQM/JIT 的共同基石）。

## 什么时候用

- 任何现场改善的第一步（一切改善活动的基石）；
- 与 TPM（TPM 的基石就是 5S）、TQM、目视管理配套推进；
- 企业形象与员工素养长期建设。

**不适用**：当一次性运动搞（"5S 贵在坚持——要很好地坚持，必须将 5S 标准化和制度化"）；只打扫不育人（"5S 管理始于素质，也终于素质"——素养是核心）。

## 来源与含义

- 起源于日本丰田公司；1955 年宣传口号"**安全始于整理整顿，终于整理整顿**"（当时只推行前 2S——确保作业空间和安全）→ 后因生产与品质控制需要逐步提出后续 3S → 1986 年首本 5S 著作问世掀起热潮；
- 五词（日语罗马音）：**SEIRI 整理 / SEITON 整顿 / SEISO 清扫 / SEIKETSU 清洁 / SHITSUKE 修养**——因首音都是 S 统称 5S，又称"五常法则/五常法"；
- **核心两个**：① **消除浪费**（不只材料物品，还有人力资源浪费、无效劳动、时间和空间浪费）；② **预防管理**（及时发现问题解决问题）；对象=人（改变行为品质提高素质）、事（改变处理方式）、物（区域化整齐化条理化）；
- **三大支柱**：创造一个**规律的工厂**（训练每个人为自己的行为负责）/ 创造**干净的工厂**（彻底清理角落与缝隙——"这是一场意识革命"）/ 创造**能目视管理的工厂**（眼睛一看就知异常——5S 的标准化）。

## 5S 逐项详解（定义/目的/实施要领）

**① 整理**：明确区分需要的和不需要的，清除不需要的物品。
- 目的：腾出空间活用空间 / 防止误用误送 / 塑造清爽的工作场所；
- 现场摆设不要物品的浪费表现：宽敞场所变窄小 / 棚架橱柜被杂物占据 / 增加寻找难度浪费操作时间 / 盘点困难成本核算失准；
- 实施要领 6 条：工作场所全面检查（含看不到的）→ 制定"要"与"不要"判别基准（与上级沟通）→ 不要物品清除出工作场所 → 对需要物品调查**使用频度**决定日常用量及放置位置 → 制定废弃物处理方法 → 每日自我检查。

**② 整顿**：对整理后留在现场的必需物品分门别类放置、排列整齐、明确数量、有效标识。
- 目的：工作场所一目了然 / 整整齐齐的工作环境 / **消除找寻物品的时间**（"将寻找必需品的时间减少为零"）/ 消除过多积压物品；
- 实施要领 5 条：整理要落实 → 流程布置确定放置场所 → 规定放置方法明确数量 → 划线定位 → 场所物品标识；
- **整顿"3 要素"**：场所、方法、标识（放置场所**原则上 100% 设定**、保管定点定容定量、生产线附近只放真正需要的；放置方法易取、不超规定范围；标识一对一表示、全公司统一）；
- **整顿时"3 定原则"**：**定点**（放哪里合适——方便取用还原的固定区域）/ **定容**（用什么容器颜色）/ **定量**（规定合适的数量——上下限或直接定量）。

**③ 清扫**：将工作环境打扫干净（机器、工具、地面、墙壁等）——**更深层次的"清扫"指的是点检**（每个工位员工每天定点清扫和点检，过程中容易形成专业知识和责任感）。
- 目的：消除脏污 / 稳定品质 / 减少工业伤害；
- 要点 6 条：确定清扫对象（地板天花板墙壁工具架橱柜机器工具量具）→ 将工作场所当作加工工程一部分加以清扫 → **自己使用的物品自己清扫** → 调查污染源予以杜绝或隔离 → 建立清扫基准作为规范 → **清扫也是为了改善**；
- 注意点：责任化、制度化。

**④ 清洁**：维持整理、整顿、清扫后的局面、使之制度化（"清洁的另一个意思是每天要做好整理、整顿及清扫的工作"）。
- 目的：维持前"3S"的成果；
- 要点：落实前 3S → 制订考评方法 → 制订奖惩制度加强执行 → **高阶主管经常带头巡查以表重视**；
- 注意点：制度化、定期检查。

**⑤ 修养（素养）**：自律——员工每天持续做到整理整顿清扫清洁、习惯地将这些活动视为每日工作的一部分。
- 目的：使员工自律地实行公司一切规章制度、实现效率化生产、最大限度提高客户满意度；
- "如果说前 4 个 S 使企业现场条理化，那么素养就是使企业管理**规律化**"——素养是其他 5S 内容的**衍生**；
- 实施要领 6 条：制订服装臂章工作帽等识别标准 / 制订公司规则规定 / 制订礼仪守则 / 教育训练（新进人员强化 5S 教育实践）/ 推动各种精神提升活动（早会、例行打招呼、礼貌运动）/ 推动各种激励活动。

## 原理与效能

- **作用原理**：通过**提升人的品质**实现——革除马虎之心养成凡事认真的习惯、遵守规定的习惯、自觉维护环境的习惯、文明礼貌的习惯；从心理学角度：**环境与情绪存在互动关系**（整洁幽雅环境 → 喜悦积极情绪 → 更积极投入工作 → 更大产出 → 环境进一步改善——**正反馈循环**，良性循环逐渐提升素质；反之恶性循环）；PDCA 循环保证 5S 连贯进行；"任何有效的监督机制都属于内耗范畴——如果能使员工自发执行，无论成本还是效果都大幅改善"；
- **五大效用（5 个 S）**：**Sales 最佳推销员**（被顾客称赞的工厂有信心、乐于下订单、口碑相传——"整洁明朗的环境会使大家希望到这样的厂工作"）/ **Saving 节约家**（降低不必要材料与工具浪费、减少寻找浪费降工时提效率）/ **Safety 安全有保障**（宽广明亮流物一目了然、遵守堆积限制、走道明确）/ **Standardization 标准化推动者**（"3 定""3 要素"原则规范现场作业、程序稳定带来品质稳定成本安定）/ **Satisfaction 令人满意的现场**（明亮清洁、员工动手改善有成就感）；
- **四个满意**：投资者满意（IS）/ 客户满意（CS——高质量、低成本、纳期准）/ 雇员满意（ES——安全、尊重和成就感）/ 社会满意（SS——区域贡献、热心公益、环境保护）。

## 实施步骤（八步 · PDCA 环）

① **获得高层承诺和做好准备**（"5S 是一把手项目"——没有最高管理层信仰和承诺容易变成一场表演；动员大会（最高领导表明决心、采用公司内具体事例）+ **小型 5S 演习**（丢会场不必要物品/一次大扫除/5 分钟抽屉整理））；
② **成立 5S 推进委员会、选定活动场所**（推行小组；选定固定场所作"司令部"切不可任其成为"游击队"；建议主要领导出任委员会主任）；
③ **制订 5S 实施计划**（推行小组拟草案评估成效→相关人员检讨确立；项目时间责任明确；找专家或顾问机构；策划具体活动）；
④ **活动前宣传造势、教育训练**（内部刊物/征文比赛/海报标语/每年规定一个 5S 月或每月一个 5S 日/定点摄影追踪/检查表/与其他管理活动配合/成果发表报告会；**"5S 日活动"**：第一个 5S 日整理（下班前 5 分钟抛掉不需要的物品）、第二个整顿（给每件物品命名定位置）、第三个清洁（全体大扫除）、第四个规范（视觉管理透明度管理）、第五个自律（自我反省评价））；
⑤ **局部推进**（现场诊断掌握整体水平 → 选定样板区（考虑代表性、实施难易度、影响力、教育促进意义、改善效果直观）→ 实施改善 → **效果确认**（总结经验、辨明功过是非、处理遗留问题、为后续做准备））；
⑥ **全面推进**（成败关键——区域责任制（5S 内容规范化成岗位责任、让员工知道**5W2H**：为什么做/做什么/在哪里做/何时做/谁来做/怎么做/做到什么程度）→ 制定评价标准（5S 审核工作表）→ **评估监督**（巡视（推进委员会巡察）/ 检查（自上而下层层检查）/ 自检（评估表格发个人自我检查）/ 互检（班组内相互检查））→ 举行评比竞赛（**评价基准应因部门先天条件不同而不同**、与薪资考绩结合）→ **可视化激励化推进**）；
⑦ **标准化、制度化**（"5S 贵在坚持——必须将 5S 标准化和制度化，让它成为员工工作中的一部分"）；
⑧ **挑战新目标**（随着公司整体水平提高逐步提高——必要时导入 ISO、TQM、TPM 等活动）。

**推进四方法**：目视管理（眼睛一看就知现场是否异常——透明化）/ **标准作业推进**（标准作业是现场管理者的重要道具、不符之处都表示异常应立即处理；创造标准 5 原则：没必要的工作不创标准/做标准的人应非常了解工作/通俗易懂/不断改良/所有工作都应标准化）/ PDCA 循环应用 / **三现主义**（现场（事情发生的场所）、现物（当前待处理的事物）、现实（目前存在的状况）——到现场、看现物、出现策，当场解决问题）。

**重点注意 5 问题**：确定推行组织（成败关键所在）/ 制订适合本企业的指导性文件（"文件是企业内部的法律"）/ 培训宣传 / 全面执行（从车间到办公室、从厂长到普通职工）/ 监督检查（与内部质量审核活动结合）。

## 评价表（五种评价方式）

自我评价（初期部门经理车间主任班组长评价、逐渐工人自己评价——让员工由自主性发展为自律性）/ 相互评价（作业者相互评价对方现场、互相启发）/ 专职人员评价（第三者客观目光公平基准）/ 领导巡回（与外企业比较针对差距指导）/ 安全巡查（安全卫生委员会——安全卫生评价）。
频率随成熟度调整：初期每日/每周→基本稳定（90% 达要求）→稳定（95% 以上）。评价要点：整理整顿情况（有无超出规定位置/放置位置好吗/标识划线适当吗/有无不用的物品）+ 安全卫生状况 + 现场纪律。

## 案例锚点（原文 · 家具企业）

各 S 的具体落地（整理——家具车间不需物品清单：用剩原料、多余半成品、边角余料、闲置设备、过期工艺文件等；**判别要与不要应依照使用价值而不是购买价值**；整顿——常用工具就近固定、工伤高发机床把操作便捷安全放第一位、活动物件地板划线定位；清扫——除尘通风、堵污染源头（刀具旁木屑堆积=除尘器效能不够）；清洁——3S 贵在坚持；修养——早会制度（10 分钟：总结昨天/传达文件/布置任务）、礼貌运动）。
**推行 11 步骤**：成立推行组织（一把手任主任）/ 拟定推行方针及目标（如"实施 5S 后达到有来宾参观时不用事先作任何准备"）/ 拟定工作计划及实施方法 / 教育（内容形式多样化）/ 宣传造势 / 具体实施（整顿注意 3 定原则、3 易原则（易取、易放、易管理）、红牌作战限期整改）/ 确定活动评比办法（考虑困难系数、人数系数、面积系数、教养系数以体现公平）/ 查核 / 评比及奖惩 / 检讨与修正 / 纳入定期活动管理。
**频率安排**：导入初前四个月每月两次作战活动 → 5S 导入结束后每月一次 → 逐步过渡到每季度一次。

## 相关工具（演进谱系）

- **6S**：5S + **安全（Safe）**（中国企业在 5S 基础上加入——"一切工作均以安全为前提"；清扫=点检、区域责任制、整修、清扫标准；安全=建立安全管理体制/重视教育培训/现场巡视排除隐患/创造明快有序安全的作业环境；新员工上班前三天应进行 6S 教育）；
- **7S**：5S + **安全** + **节约（Saving）**（对时间、空间、能源等合理利用发挥最大效能——三观念：能用的东西尽可能利用/以自己就是主人的心态对待企业资源/切勿随意丢弃、丢弃前思考剩余使用价值）；
- **8S**：5S + **学习（Study）** + 安全 + 节约（另有版本含"坚持"——项目活动一定要持之以恒、节约=不断减少人力成本空间时间物料浪费）。
