# OPT 最优生产技术

> 编号 #60 ｜ 篇：四·质量生产 ｜ 源：`TOOL` P1113–P1142
> 全称：Optimized Production Technology（戈德拉特博士，70 年代） ｜ 类型：生产计划与控制方法

**一句话**：以**瓶颈**为核心的同步生产方式——"为了实现公司的目标而使整个生产过程协调一致地工作"，把焦点集中在瓶颈资源上（"改善生产管理技术的新方式"，后发展为约束理论 TOC）。

## 什么时候用

- 生产系统的计划与控制改进（瓶颈识别与缓冲管理）；
- 基本、简单的产品 + 很大批量 + 工序较少的生产环境（"在单件生产车间中发挥的效果不佳"）；
- 与 MRPⅡ（企业级）或 JIT（车间级）结合运用。

**不适用**：需求剧烈波动（适用条件要求"需求是相对稳定的""瓶颈要相对稳定"）；单件生产车间；不愿改变传统成本会计考核体系的组织（"最大的威胁将来自传统的成本会计的考核体系"）。

## 产生与发展

- 以色列物理学家**戈德拉特博士 70 年代**提出：最初为朋友一个处于困境的制造厂设计人力和物料调度计算机软件（实施后使该厂迅速摆脱困境）→ 开发广泛适用于制造业的 OPT 软件；
- 原称"最优生产时间表"（Optimized Production Timetable），80 年代改称最优生产技术；**后又进一步发展为约束理论（TOC）**；"是继 MRP 和 JIT 之后出现的又一项组织生产的新方式"。

## 核心概念

- **含义**：OPT 试图协调各种资源使其协同工作或同步运作；把制造组织看作将原材料转化为产品的系统；
- **瓶颈（OPT 最重要概念）**：**实际生产能力小于或等于生产负荷的资源**——这一类资源限制了整个生产系统的产出速度；其余为非瓶颈资源；判别方法：从该资源的实际生产能力与它的生产负荷（或对其的需求量——不一定是市场需求量、可能是其他相关资源对该资源的需求量）来考察；用 OPT 组织生产建立在**严格区分瓶颈与非瓶颈资源**基础上——焦点集中在瓶颈资源上、瓶颈资源的作业计划**优先制定**（确保其负荷不超过生产能力）；
- **按物流分类企业（V/A/T 三型）**：**V 型**（一种原材料→许多种最终产品——炼油厂、钢铁厂：资金密集型高度专业化；工艺流程清楚简单、提前期短、瓶颈识别与协调相对容易）；**A 型**（许多种原材料→一种最终产品——造船厂：设备通用型；存在 BOM、工艺复杂、在制高、提前期长、瓶颈不易识别）；**T 型**（A 型的发展、最终产品有多种——制锁厂、汽车厂；许多成品零部件相同）；A/T 型企业计划与工序间协调非常困难；
- **瓶颈与非瓶颈的四种基本关系**：从瓶颈到非瓶颈 / 从非瓶颈到瓶颈 / 瓶颈与非瓶颈到同一装配中心 / 两者相互独立。

## OPT 的九条原则

① **追求物流的平衡，而不是生产能力的平衡**（多品种生产企业追求产能平衡→产品积压）；② **"非约束"的利用程度不由其本身决定，而是由系统的"约束"决定**；③ 资源的"**利用**"（应该利用的程度）和"**活力**"（能够利用的程度）**不是同义词**；④ **在"约束"上发生一个小时的损失则是整个系统的一个小时的损失**——约束资源必须保持 **100% 的"利用"**、尽量增大产出（四种增大方法：减少调整准备时间和频率、约束资源上批量尽可能大/实行午餐和工休连续工作制/在约束资源前设置质量检查站（保证投入件 100% 合格）/设置缓冲环节）；⑤ **"非约束"节省的一个小时无益于增加系统有效产出**（节约生产时间只会增加闲置时间）；⑥ **"约束"控制了库存和有效产出**（约束=资源约束（内部产能不足）或市场约束（市场需求）；非约束应与约束同步——"库存水平只要能维持约束上的物流连续稳定即可"）；⑦ **运输批量可以不等于（许多时候应该不等于）加工批量**（运输批量考虑：提高连续性平行性、减少等待时间和运输费用；加工批量考虑：资源的合理应用（减少调整次数）+ 合理的在制品库存）；⑧ **批量大小应是可变的，而不是固定的**；⑨ **提前期是作业计划的结果，而不是预定值**（与 MRPⅡ 相反——OPT 不采用固定提前期、考虑计划期内系统资源约束、用**有限能力计划法**：先安排约束资源上关键件生产进度、以约束资源为基准把其前、之间、后工序分别按**拉动、工艺顺序、推动**方式排定）。
**总提示**："要抓住关键问题、解决瓶颈环节，为企业用少量的投资实现较大的利润。"

## 目标与指标体系

- **真正目标只有一个：现在和将来都能赚钱**（在增加产销率的同时减少库存和运行费）；
- **财务三指标**（衡量是否赚钱）：净利润 NP / 投资收益率 ROI / 现金流量 CF——三指标太一般、不能直接指导生产（"开车时挡风玻璃被纸糊上、在汽车后视镜中景象指导下开车"）；
- **三个作业指标（桥梁）**：**产销率 T**（单位时间内生产出来**并销售出去**的量——通过销售获取金钱的速率；生产出来但未销售出去的只能是库存）/ **库存 I**（一切暂时不用的资源——含原材料在制品未售成品和扣除折旧后的固定资产）/ **运行费 OE**（将库存转化为产销量的过程中的一切花费）；
- **关系公式：NP = T - OE；ROI = (T-OE)/I**——T 增加（I、OE 不变）→三项全增；OE 减少→三项增；I 降低→ROI 和 CF 提高但 NP 不变（可通过减少 OE 间接增 NP——"通过降低 I 来减少 OE 的作用是随着 I 降低的程度而减弱的"）。

## 基本原理（三条）

① **尽量保证关键资源的满负荷工作**（关键资源=最薄弱环节、其工作的每一分钟都直接贡献于产出量；四措施：关键工序前设**质量检查点**（保证 100% 合格）/关键工序前设**缓冲环节**（单件小批生产用时间缓冲、成批生产用保险在制品）/采取**动态的加工批量和搬运批量**/减少关键工序中的辅助生产时间）；
② **以关键资源的能力决定非关键资源的利用率和生产效率**（"盲目地提高非关键资源的利用率和生产率，只能生产出不配套的多余工件或产品……并不能提高经济效益"）；
③ **对关键工序的前导工序和后续工序采用不同的计划方法**（前导采用**拉动**方式（按后续工序需求决定前导投产日期和数量）、后续采用**推动**方式（按前导完成情况决定后续投产时间和数量）——先编关键件生产计划、确认前提下再编非关键件计划）。

## 实施应用

- **认识（四种看法）**：一种新的计划思想 / 一种作业计划的仿真语言 / 生成 MPS 与物料能力需求计划的软件包 / 一种在数据未高度精确之前获得利润的尝试——共同点：OPT 强调**车间现场**、用一组"管理系数"加权函数确定每个作业的优先权数及批量；
- **实施关键与威胁**：计划后的落实是关键——"传统的成本会计的考核体系忽视了瓶颈与非瓶颈的区别……着重于局部的优化，必然助长盲目生产、导致高库存和浪费"；OPT 力求从**全局观点**考核（从原材料采购追踪到产品销售）、对瓶颈与非瓶颈分别对待（非瓶颈不应以生产量为依据、而应以生产的有效产品量考核）；"成本会计注重的是'活力'而非'利用'，正确的做法应是注重'利用'而非'活力'"；
- **适用条件 4 条**：瓶颈相对稳定 / 瓶颈保证达到 100% 负荷能力 / 需求相对稳定 / 员工愿意并能够服从计划的调度安排；需要对员工培训（在不同岗位上及时发现问题、跟踪问题、解决问题）；
- **作业计划方法五步**：① 计算设备（工作中心）负荷、找出瓶颈（负荷量超过可用能力最多的设备）→ ② 确定控制点和建立控制流（瓶颈是最适当控制点——与生产过程的两个端点（投入与产出）建立联系）→ ③ 安排瓶颈设备的产量或流量（生产计划先从瓶颈开始）→ ④ 计算其他设备的产量或流量（**拉动式**：以瓶颈为基准由后向前排定；**推动式**：由前往后排）→ ⑤ 保证瓶颈满负荷（设置缓冲处和检查点）。

## 计划与控制系统：DBR 系统

**DBR 法（Drum-Buffer-Rope，"鼓、缓冲器、绳子"）**：
- **鼓（Drum）**：即"鼓点"、节拍——"在行进的队列中，鼓点起着指挥、驱动、统一步调的作用"，是 OPT 生产计划的**驱动**；
- **缓冲（Buffer）**：为保证瓶颈的高产出率——"**喂饱**瓶颈"、使瓶颈利用率最高费用最低；两种：**时间缓冲**和**库存缓冲**；"与一般意义的 MRP 的安全库存、安全提前期不同，它是**针对瓶颈资源**设置的"；
- **绳子（Rope）**：建立"鼓"与其**上游工序**的联系——起传递生产指令的作用、驱动系统所有部分按鼓的节奏生产；实施中由涉及原材料投料到各车间的详细作业计划实现；"OPT 的'绳子'相当于 MRP 的指令或 JIT 的'看板'"——保证库存量或在制品数量最小；
- **实施三步骤**：① **识别瓶颈**（计划与控制的关键——"当需求超过能力时，排队最长的机器就是瓶颈"；按 BOM 和加工路线工时定额计算比较；瓶颈即最好控制点——确保其作业不过量生产、预防瓶颈不能处理的过量在制品）；② 基于瓶颈约束建立产品出产计划（缓冲器管理与控制——时间缓冲（物料比预定时间提早一段时间到达、避免停工待料）/控制进入非瓶颈的物料（用倒排方法对非关键资源排序、与关键资源工序同步）/瓶颈上加工批量最大而瓶颈上游小批量多批次/综合考虑各种费用使总费用最小）；③ **绳子**（使库存最小——把瓶颈与上游工序串联起来、使物料依据产品出产计划快速通过非瓶颈作业以保证瓶颈需要；"没有瓶颈发出的生产指令就不能进行生产"——要么库存过大、要么瓶颈"饥饿"）。

## 相关工具：约束理论（TOC）

- **概念**：戈德拉特在 OPT 基础上发展起来的管理哲理——"**找出妨碍实现系统目标的约束条件，并对它进行消除的系统改善方法**"；对 MRPⅡ 和 JIT 在观念和方法上的发展；支持连续改进；
- **基本要点**：企业是系统（目标=当前和今后获得更多利润）/ **一切妨碍企业实现整体目标的因素都是约束**（按帕拉图原理有重大影响的往往是少数几个约束——物质型（市场、物料、能力、资金）+ **非物质型**（后勤及质量保证体系、企业文化和管理体制、规章制度、员工行为规范和工作态度——又称**策略性约束**））/ 三项衡量指标（**只能从企业的整体来评价改进效果**——"库存投资和运行费用虽然可以降低，但不能降到零以下，只有有效产出才有可能不断增长"）/ DBR 法和缓冲管理法（MPS 比喻成"鼓"、按瓶颈和 CCR 的可用能力确定最大物流量作为全局鼓点；瓶颈前非制约工序倒排计划、瓶颈顺排、后续按瓶颈节奏）/ 思维过程（TP）三种方法；
- **TOC 五大核心步骤**：① **找出系统中存在哪些约束**（增加产销率的四个方面：原料/能力/市场/政策）→ ② **寻找突破这些约束的办法**（原材料的确保及时供应和充分利用；市场约束→扩大需求；内部资源约束→保证该环节始终高效率生产；瓶颈设备利用率不高时的行动：设置时间缓冲（单件小批）/在制品缓冲（成批）/瓶颈前设质检环节/统计瓶颈设备产出的废品率/找出出废品原因并根除/对返修返工方法研究改进）→ ③ **使企业的所有其他活动服从于第二步中提出的各种措施**（"如果那些非约束环节追求百分之百的利用率的话，将给企业带来的不是利润，而是更多的在制品、约束环节更多的等待时间和其他种种浪费——而现在一些企业恰恰正在追求这些非约束环节的百分之百利用！"）→ ④ **具体实施**（缩短设备调整和操作时间/改进流程/加班/增加操作人员/增加机器）→ ⑤ **谨防人的惰性成为系统的约束**（突破一个约束后重新回到第一步开始新循环——"**今天的解决方案就是明天的问题所在**"；"这些公司设法使约束转移到使他们为难最少的环节……利用和控制约束，而不是被约束所控制"）；
- **思维流程（TP）**——严格按因果逻辑回答三问题（**改进什么 / 改成什么样子 / 怎样使改进得以实现**）：工具链——**当前现实树 CRT**（从"不良效果 UDE"（发货单不准时、库存超标、提前期变长、人际关系不融洽）出发绘逻辑关系图、找到真正的核心问题）→ **消雾法 EC**（以双赢方式解决企业中的冲突——驱散冲突周围的混淆和含糊、找到突破点即"**注入**"）→ **未来现实树 FRT**（把"注入"插入 CRT 突破环节重绘——看"不良效果"是否转变为"满意效果 DE"）→ **负效应枝条**（找与改进后果相关程度最大的人参与——"正是这些受改进影响最大的人，才对那些意料之外的负面效应了解得最清楚"——"剪去负效应枝条"）→ **必备树**（让将与转变直接相关的人来制定实施行动方案——"人们对自己参与设计的改进方案一般抵触较少"——TP 中最有力的一环）→ **转变树**（把实现成功实施所需的活动集中、给出关系与先后顺序）；
- **应用**：生产观念转变（改进三问）/ 指标体系运用 / 生产计划执行与控制（"DBR 规定车间作业标准是维持市场需求，而不是仅让工人的机器连轴转"）/ **营销理念**（"营销和打鸭子"类比——"如果把销售比作向那些正在湖边吃谷的蹲着不飞的鸭子射击，那么广告就是撒下谷子让鸭子到岸上来吃，而营销就是首先得知道鸭子是爱吃谷子的"——列出顾客抱怨（负效应）、找出核心所在、提出最大化提高满意度的解决方案）/ 与 MRPⅡ 结合（企业级 MRPⅡ、车间级 DBR：计划周期周 vs 天；共享 BOM、工序描述、资源能力数据）/ 与 JIT 结合（瓶颈前设置合理缓冲、以瓶颈工序为"看板"指令、企业级仍用 MRPⅡ）。

**TOC 与 MRPⅡ、JIT 三方法对比**（要点）：计划展开——TOC 先排约束环节关键件、前拉动/后推动；MRPⅡ 集中式计划、无能力计划法；JIT 看板管理、有限能力计划逐道倒序传递。库存观——TOC：一种可能的限制因素（取决于约束位置）；MRPⅡ：一种资产（预防预测误差/机床故障/供货商拖期）；JIT：一种不利因素（尽一切努力减少）。质量管理——TOC：避免质量问题波及约束环节；MRPⅡ：允许一定废品以最终检验控制；JIT：以生产中质量控制代替最终检验、消灭废品。人员使用——TOC："把资源的'利用'与'活力'加以区别，不认为'满员满岗'就一定是最有效率的"；MRPⅡ：严格执行各级计划与指令；JIT：强调协调、以人的协同合作为现场控制主体。
