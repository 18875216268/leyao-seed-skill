# 8D 工作法

> 编号 #70 ｜ 篇：四·质量生产 ｜ 源：`TOOL` P1367–P1379
> 又称：团队导向问题解决法（福特 1987 书面记录） ｜ 类型：纠正措施实施工具

**一句话**：解决**一组原因不明问题**的 8 个步骤（D1~D8）——"以事实为依据，按一定程序找出原因，实施改进，从而客观地解决问题"（"科学有效的实施纠正质量措施的工具"）。

## 什么时候用

- 顾客投诉/外场失效等**原因不明**的复杂问题（"问题可以被初步判定，但原因不明"）；
- 制程能力指数低于其应有值时问题的解决（"对于统计制程管制与实际的品质提升架起了一座桥梁"）；
- 供应链质量问题的闭环处理（提高对供应商质量管理的水平）。

**不适用**：责任不明确或问题未被确定（使用前提之一）；简单问题（"此方法成本较高，故需判定使用 8D 的条件"）；成员"谁有空谁去"（常见问题之一——"往往小组未配置真正熟悉产品、过程的人员"）。

## 起源与含义

- 二战期间美国政府率先采用类似流程——"**军事标准 1520**"（"不合格品的修正行动及部署系统"）→ **1987 年福特汽车公司首次书面记录**（课程手册中命名为"**团队导向的问题解决法**"——当时福特动力系统部门"正被一些经年累月、反复出现的生产问题搞得焦头烂额"）；
- **含义**：8D = 解决一组原因不明问题的 **8 个步骤**（"D"为"第"字的字头）；三点特性：a) 团队运作导向、以事实为基础、**避免个人主见的介入**；b) 宜由公司各部门人员**共同投入**、求得创造性及永久性的解决方案；c) **可适用于任何问题**、能促进部门间有效沟通；
- **盛行原因 4 条**：汽车产品日益复杂、缺陷影响越来越大（2001 福特轮胎召回致全面亏损；2004 日本某车企因质量缺陷面临倒闭——"引起了企业组织者的重视，使质量改进工作有了自上而下的推动力"）；产品生命周期缩短和缺陷原因复杂化 + 人员流动快经验有限（"推动了团队工作法的模式"）；社会技术和协作水平提升；**8D 是一个表格化作业程序、有高效的工具性特点**（全球推广）。

## 使用前提（四条）

① 问题已被确定、用户和企业的责任明确；② 问题可以被初步判定、但**原因不明**；③ 企业管理者要求查明原因、解决问题；④ 问题较复杂、需要靠**团队的力量**。

## 实施步骤（D1~D8 详解）

**D1 成立小组**：不合格产品发生时成立**跨功能工作小组**（质量部门、生产分厂、设计、销售等共同组成、"具备解决问题的能力和相关技术素质"）；关键要点：成员资格（具备工艺、产品的知识）/ 目标 / 分工 / 程序 / 小组建设；
**D2 说明问题**：用**可量化的术语**详细说明具体情况（问题发生的时间、地点、数量和频率、持续的时间和严重性——"主要是与标准对照，找出不符合的地方"）+ 确定解决问题的结果（按顾客需求设定应达到的指标）；要点：收集和组织所有有关数据 / 问题说明是特别有用的数据的总结 / 审核现有数据识别问题确定范围 / **细分问题（将复杂问题细分为单个问题）** / 问题定义要"找到和顾客所确认问题一致的说明——'什么东西出了什么问题'，而原因又未知"；
**D3 实施并验证临时措施**：接到质量问题信息后**立即对产品进行隔离**→库存产品复查筛选→检查生产现场（投诉的问题是否还在发生——"如顾客反馈的问题原来一直没有察觉，现在加工的产品还是按照错误的方法进行加工，应立即停止加工"）→采取**100% 检验、返工**等临时性纠正措施（"应最大限度减少顾客损失，在时间安排上不能太长，而且不能引起新问题的出现"）；要点：以抑制问题的扩大 / 判断临时措施有效性、风险和益处；
**D4 确定并验证根本原因**：用统计工具列出**所有潜在原因**、将造成偏差的事件或环境相互隔离测试——**两方面分析**：① 什么原因造成这种缺陷的产生；② **质检部门为什么没有查出来、是怎样流出去的**（"检查为什么有漏洞"）；对每个潜在原因通过试验测量检查分析、采用**判别矩阵**寻找并验证根本原因；要点：评估可能原因列表中的每一个原因 / 原因可否使问题排除 / 验证 / 控制计划；
**D5 选择并验证永久纠正措施**：定量确定所选择的纠正措施（确保解决顾客问题且不会发生副作用）；对每一个措施的有效性**进行验证**、必要时做**风险性评价**并制定**应急计划**；计划含**原因、实施前情况、纠正措施、目标和验证情况**；要点：重新审视小组成员资格 / 决策选择最佳措施 / 重新评估临时措施（如必要重新选择）/ 验证 / **管理层承诺执行永久纠正措施** / 控制计划；
**D6 实施永久纠正措施**：为保证不合格原因的消除对顾客投诉实施永久性纠正措施；"如果原因还没有很清楚时，应多做几项改善行动……然后在此步骤中将 5D 中最根本的原因列上进行**长期验证**"；如果第 5 步没有找到根本原因——将 5D 所有措施都列在第六步长期验证、**待 3~6 个月后**将验证结果再写报告给客户——"将此问题彻底解决，报告要存档、由质管部门跟踪，**形成闭环运行**"；要点：重新审视小组成员 / **执行永久纠正措施、废除临时措施** / 利用故障的可测量性确认故障已排除 / 控制计划与工艺文件修改；
**D7 预防再发生**：修改管理文件、操作系统、工作惯例及工作程序；例（操作工误操作造成的问题）：将此培训列入培训计划 + 此问题应体现在**控制计划、失效模式分析和作业指导书**中；要点：选择预防措施 / 验证有效性 / 决策 / **组织、人员、设备、环境、材料、文件重新确定**；
**D8 小组祝贺**：通过座谈会等形式由**高层领导**对小组的集体努力和工作成果给予肯定、必要时表彰；要点：有选择的保留重要文档 / 把心得形成文件 / 了解小组解决问题的集体力量及贡献 / 必要的物质精神奖励。

## 常见问题（八类）

**小组的成员**（未配置真正熟悉产品过程的人员、"谁有空谁去" / D5、D6 阶段未重新审视 / 没有配备足够时间（"把改进工作作为附属工作来完成"）/ 小组长或成员因工作调动未及时变更）；**问题说明**（"停留在故障表现上，没有用工程师的语言"→"只是治标不治本"）；**临时措施**（没有采取临时措施保证问题与顾客隔离）；**根本原因**（"没有对所有可能原因进行测试以确定根本原因，而多是凭经验"）；**永久措施**（选择前没有进行成本效果评价、确定后无计划或预防措施保证）；**必要的验证手段**（缺少试验或验证手段）；**防止再发生**（"永久措施与防止再发生概念模糊——认为工艺、检验方法的完善就是防止再发生"）；**小组祝贺**（激励机制不健全——"做好了无大奖、做坏了却要罚"，最后不得不由质量管理部人员担任；评审委员会成员不能每次参加）。

## 主要作用（四条）

8D 将所要解决的问题以专题形式充分细化、直到确定并消除问题的原因、防止不合格再发生——实施应由组织**高层领导推动并对小组充分授权**、保证小组成员有足够时间从事活动：① 有助于提高产品开发的质量；② 有助于提高对供应商质量管理的水平（从而提高供应链系统的质量保证能力）；③ 有助于提高对潜在供方的评价质量；④ 有助于开展降低成本工作。

## 案例锚点（原文 · 某仪表电器厂）

**背景**：为某主机厂配套的继电器外场"三包"故障品率超标、收到主机厂质量信息单要求整改——采用 8D 深入剖析。
**D1 成立小组**：立即成立以**总质量师为组长**、设计/工艺/质量/销售人员为成员的小组；
**D2 说明问题**：界定问题（使用过程失效自 2000 年 9 月初开始时有发生、共返回"三包"产品 **28 只**、外场故障率 **0.6%**、主要由于**触点烧蚀**引起失效）；严重性（继电器失效将导致车辆电喇叭无声、**影响行车安全**；主机厂计划从 6 月起跟踪考核、若故障率仍高于 **0.3%** 将实施惩罚性措施）；确定结果（整改后故障率 **<0.25%**）；
**D3 临时措施**：隔离 + 主机厂库存产品**空运回厂**复查筛选；100% 筛选维修（检查电气参数；打开外壳检查发现**触点压力普遍偏小**——应保证大于 **0.5N**，剔除触点压力小于 0.5N 的产品（约占有问题产品的 **40%**）；环境应力筛选（高低温动作、随机振动）再剔除 **0.2%**；抽取触点压力满足和不满足 0.5N 的产品各两只做电气寿命耐久试验）；及时发出筛选后产品保证装车进度 + 通知驻外服务组重点跟踪；
**D4 根本原因**：通过**直方图**找出第一优先问题（失效机理 **95%** 为触点烧蚀）；采用**鱼刺图**从人、机、料、法、环、管理入手寻找所有潜在原因；对每个潜在原因通过试验测量检查分析、采用**判别矩阵**验证；
**D5 纠正措施表**（原因/实施前情况/纠正措施/目标/验证情况）：**弹簧片稳定性差**（合格率 60%）→ 增加校正工序（目标 99.5%）→ **实际合格率提高到 99.7%、继电器参数离散性小**；**采用了复合触点**（电气寿命小于 5×10⁴ 次）→ 用**纯银氧化物触点**（目标大于 5×10⁴ 次）→ 试验结果：触点压力 0.2N→18000 次、0.3N→48000 次、0.5N→93000 次、>0.5N→**大于 1×10⁵ 次**；**人员培训不够**（考试合格率 70%）→ 培训 → 目标考试合格率 100%；
**D6 实施**（2001 年 7 月起实施永久性纠正措施 + 确定 **6 个月**外场故障率跟踪期限验证）；**D7 防止再发生**（对所有永久性纠正措施验证 + 设计文件、工艺文件相应修改 + 增加必要的工具及测试手段）；**D8 祝贺**（座谈会+高层肯定+必要时表彰）。
