# 朱兰三步曲（质量三元论）

> 编号 #64 ｜ 篇：四·质量生产 ｜ 源：`TOOL` P1206–P1218
> 全称：Juran Trilogy（约瑟夫·摩西·朱兰） ｜ 类型：质量管理战略框架

**一句话**：质量管理由三个**内在相关、定序排列**的基本过程实现——**质量策划 → 质量控制 → 质量改进**（"质量战略思想和管理的有力武器"）。

## 什么时候用

- 质量管理体系的顶层设计（战略框架）；
- 一切工作的质量改进（"不仅适用于每一个质量体系要素，而且对所有工作都是适用的"——包括行政管理、人才培养等）；
- 扭转"重控制、轻策划与改进"的误区（"质量策划是经常性质量问题的主要滋生温床"）。

**不适用**：指望改进自发发生（"这一突破不会自行发生，它是由于上层管理者在管理者职责中引入了一个新的管理过程——质量改进……的结果"）；只做质量控制不做策划与改进的组织（反复"救火"）。

## 概念与来源

- **朱兰质量管理的核心**："通过管理过程可以'使质量得以实现'"；
- **1964 年《管理突破》**奠定质量管理基础——叙述三步曲的**后两者：质量改进和质量控制**；**1988 年《朱兰论质量策划》**撰述"质量策划"；
- **实施顺序**：先质量计划阶段（确定质量目标、辨识顾客及需要、开发和设计应对顾客需要的产品特征及过程）→ 再质量控制阶段（将工作情况与目标对比评估、找出差距）→ 最后对每个差距找出一套弥合差距的**质量改进**方法并付诸实施。

## 三个过程的定义与对比

**质量策划**：设定质量目标 → 辨识顾客是谁 → 确定顾客的需要 → 开发应对顾客需要的产品特征 → 开发能够生产具有这种特征的产品的过程 → 建立过程控制措施、将计划转入实施阶段；
**质量控制**：评价实际绩效 → 将实际绩效与质量目标对比 → 对差异采取措施；
**质量改进**：提出改进的必要性 → 做好改进的基础工作 → 确定改进项目 → 建立项目小组 → 为小组提供资源培训和激励 → 诊断原因 → 设想纠正措施 → 建立控制措施以巩固成果。

| 三步曲过程 | 过程内容 | 最终结果 |
|---|---|---|
| **质量策划** | 满足质量目标的**准备**过程 | 开发一个在作业条件下能满足质量目标的过程 |
| **质量控制** | 在**作业中符合**质量目标的过程 | 与质量计划相一致的作业实施 |
| **质量改进** | 由突破达到一个**前所未有的执行水平**的过程 | 在明显优于原计划执行的质量水平上的作业实施 |

## 基本步骤（三个过程的分别展开）

**质量策划 6 步**：识别顾客（包括外部和内部的）→ 确定顾客需要 → 开发符合顾客要求的产品特性（产品包括商品和服务）→ 建立**综合成本最低**的既满足顾客要求、供方又能达到的质量目标 → 开发能满足产品目标的过程 → **验证过程能力**（证实该过程在作业条件下能满足质量目标）；
**质量控制 7 步**：选定控制对象（控制什么）→ 配置测量设备 → 确定测量方法 → 建立作业标准 → 判断操作的正确性 → 分析与现行标准的差距 → 对差距采取行动；
**质量改进 8 步**：证实改进的必要（争取立项）→ 确定专门的改进项目（设立项目组）→ 对项目组织指导（**领导亲自参与**）→ 组织诊断（为发现原因）→ 实施诊断找出原因 → 采取补救措施 → 在操作条件下验证补救措施的有效性 → 在新水平上控制、保持已取得的成果。

## 特性曲线（三过程的相关性）

纵坐标=不良成本、横坐标=时间：
① **起点是质量策划**（创建一个能满足既定目标并在作业条件下运行的过程——策划对象可以是任何质量体系要素（产品设计技术过程/办公室编制文件过程/制造过程/检验过程/服务过程等）；策划应形成质量计划或指导控制的文件）；
② 策划完成后过程移交操作者——操作人员的职责是按质量计划进行控制，发生**偶发性波动的"尖峰"**超出限定控制区域时进行"**救火**"、使过程回复到规定控制区域内；
③ 由于**原先策划的不足**（策划失误、更多是技术和市场竞争迅猛发展使原先策划跟不上形势），**经常性损耗**处于很高水平——朱兰："**质量策划是经常性质量问题的主要滋生温床**"——"居高的经常性损耗成了该策划过程的**固有损耗**，而按质量计划实施控制的操作者对之是无能为力的"；
④ 从 M~N 时段不良成本大幅降下来——**这一突破不会自行发生**，是由于**上层管理者在管理者职责中引入了一个新的管理过程——质量改进**这个有目的的过程的结果（质量改进过程是**叠加在原有质量控制过程之上**的）；
⑤ 改进中获得的经验教训**反馈到新一轮的策划中**（朱兰在《论质量领导》中发展了三步曲、增加了"**反馈**"）——一方面将改进成果转入新的策划过程产生新的质量计划、对过程在新水平上进行控制保持改进成果；另一方面把三个过程串成一个链——"**一个有生命力的不断突破—策划—控制的循环链**"。

## 三部曲的时间分配（组织层次模型）

横轴=各类人员时间分配百分比、纵轴=在组织中所处的层次：
- **高层主管**：大部分时间用在**计划和改进**上（战略计划上相当多时间；用于控制的时间不多且集中在主要控制项目）；
- **随组织阶梯往下走**：用于战略计划的时间减少、用于**控制和维持**的时间迅速增加；
- **最低层**：时间主要用于控制和维持，但在计划和改进上也要花一部分时间。

## 主要意义（六条）

① **将实现质量管理的过程概括为三步曲**——把三者内在相关性的潜能充分发掘出来、形成有进取性的循环链（与戴明的 PDCA 循环和费根堡姆的 TQC 一起成为"具有里程碑意义的质量战略思想和管理的有力武器"）；② **普遍适用的进程**（适用每一个质量体系要素、对所有工作适用）；③ **培训便利**（"对于一个组织要对其不同职能的各级人员建立起完整的有针对性的培训课程……实在太庞大了——而三步曲以一个简炼的普遍适用的进程用于对所有人员的培训十分方便"）；④ **与财务管理的相似性**（与财务预算、开支控制和收益改进极其相似——"有助于管理者理解质量管理，并便于被组织接受，**减少被公司内在的'免疫系统'排斥的风险**"）；⑤ **指出策划是滋生温床**（"不改进是没有出路的，它有利于扭转对质量改进不重视的错误习惯"）；⑥ **日本超越美国的启示**——日本从 50 年代"劣质产品的代名词"到 70 年代在广泛质量领域超过欧美——"那是因为日本采取了**主动进取的变革型的改进步伐**，在单位时间里质量改进的项目远高于西方一个数量级，从而超越了惯于固步自封的自然进化型改进速率的西方"——为质量和经济的后进国指明赶超方向："**不懈地采取改变型的、一个接一个项目的质量改进**"。

## 案例锚点（原文 · 质量三元论在博士后管理工作的应用）

**质量计划阶段**：目标明确（目标管理——"目标管理是管理者通过目标来管理部下，而不是用手段或手续来管理部下"；江苏省博士后管理中心要求进站前认真阅读文件、明确任务甚至论文格式；确保目标的软硬件条件（管理制度、实验室、经费、生活设施）；西北工业大学三级管理体制（学校负责资格审查年度出站考核及待遇/院系负责研究计划培养使用计划/合作导师负责计划落实及日常管理考核））；目标制定三要求（起点要高（双高特点）/人性化/分层进行）；
**质量控制阶段**：做好检查考核工作（首先管理人员自我检查考核）；质量控制七步骤落实；人性化管理（强化服务意识——解决"三子"（房子妻子孩子）问题、岗位津贴制度；政策制度层面解决职称待遇；管理策略化——灵活机动富有弹性的管理措施）；重点=对博士后人员的考核和检查（定期考评全程监督；素质有问题限期改正否则劝其出站；成绩突出者推荐奖励基金评选或提前晋升；课题层层把关（设立/开题报告/中期考核/期满考核）；"择优汰劣"创造"**赛场选马**"的公平竞争环境；学术委员会导师论证评估+严格打分制和旁听制）；
**质量改进阶段**：不断对管理目标和对象检查考核找出问题加以改正——"关键在于摸索创造出一套适合本学校和本部门的切实有效的管理方法"（不人云亦云、不因循守旧）；两方面改进（管理目标改进（是否切实可行）；管理方法和管理措施改进——围绕"**三个质量**"：博士后科研工作站的管理质量、思想作风上的管理质量、科学研究质量）；"将获得的经验教训反馈到下一轮的质量计划中"。

## 人物链接（朱兰）

约瑟夫·摩西·朱兰（1904 生于罗马尼亚、成长于明尼苏达）：就读明尼苏达大学电气工程、国际象棋冠军；毕业后在西方电气公司发展出重要质量理念；二战后到纽约大学任教；五六十年代到日本开展系列讲座和咨询项目；朱兰学院（1979）和朱兰基金会创建者；协助创建美国马尔科姆·鲍德里奇国家质量奖；获 14 个国家 50 多种嘉奖（日本天皇授予"勋二等瑞宝章"、美国总统颁发国家技术勋章）；《朱兰质量手册》被誉为"**质量管理领域的圣经**"。
