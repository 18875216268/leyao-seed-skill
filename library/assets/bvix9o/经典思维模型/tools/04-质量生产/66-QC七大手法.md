# QC 七大手法

> 编号 #66 ｜ 篇：四·质量生产 ｜ 源：`TOOL` P1235–P1283
> 又称：品管七大手法 / 初级统计管理方法 ｜ 类型：统计分析工具集

**一句话**：一组对质量管理活动的数据进行**客观分析**的有力工具——**排列图、鱼骨图（因果图）、散布图、检查表、分层法、直方图、控制图**（"品管七大手法"）。

## 什么时候用

- 质量管理活动中的数据整理与客观分析（PDCA 全过程的"七种工具"）；
- 现场问题诊断（从"收集数据"到"找出原因"到"过程控制"的全链条）；
- 服务业同样适用（物业管理案例——"将数据加以抽丝剥茧，就能够改进服务效果"）。

**不适用**：数据尚未分层就贸然作图（"用好层别法是把握其他 QC 手法的基础"）；把工具当目的（"排列图是管理手段而非目的，如果数据项目已经很清楚者，则无需再浪费时间制作排列图"）；解决了不合格品却不追溯造出它的过程（零缺陷视角）。

## 七大手法逐项详解

**① 排列图**（帕累托图）——分析和寻找影响质量主要因素的工具（"关键的少数和次要的多数"原理；帕累托首创、朱兰推广、石川馨 60 年代在 QCC 品管圈中使用从而成为品管七大手法之一）：
- 形式：双直角坐标（左纵轴=频数、右纵轴=频率（百分比）；折线=累积频率；横轴因素按影响程度从左向右排列）；
- 绘制程序 7 步：确定分类依据 → 确定时间段 → 确定测量对象（频数/百分比/成本/时间和数量）→ 收集数据 → 确定刻度 → 画出每类条柱（按长短从左到右；数值很小的归为"其他"）→ 分析；
- **应用要点 7 条**：① 要留存、改善前后对比可评估改善后果；② 分析只要抓住前面 **2-3 项**；③ 分类项目 **5-9 项**较合适；④ 各项目比例差不多时排列图失去意义；⑤ 是管理手段而非目的；⑥ "其他"项目如果大于前面几项必须分析层别；⑦ **第一项很难解决或花费很大时，可以避开第一项从第二项入手**；
- 案例：某酒杯厂 120 个次品统计——主要因素是**划痕和气泡**（"一旦这些问题得到纠正，大部分质量问题即可消除"）；作用 6 条（降低不良依据/决定改善攻击目标/确认改善效果/发现现场重要问题点/整理报表记录/不同条件评价）。

**② 鱼骨图**（因果图/鱼刺图/石川图）——将原因和结果联系起来的分析工具：
- "以结果作为特性、以原因作为因素……是充分发动员工动脑筋、查原因、集思广益的好办法，特别适合于工作小组中实行质量的民主管理"（经常用来组织头脑风暴会议并对观点进行有效分类）；
- **制作步骤**：分析问题原因/结构（A 针对问题点选择层别方法（人机料法环）；B 头脑风暴找出所有可能原因；C 归类整理明确从属关系；D 分析选取重要因素；E 检查描述方法）——**分析要点 6 条**：a 大要因现场作业一般从"**人机料法环**"着手、管理类问题从"**人事时地物**"层别；b 大要因必须用**中性词**描述、中/小要因必须使用**价值判断**（如…不良）；c 脑力激荡时尽可能多而全、对人的原因宜从**行动而非思想态度**面着手；d 小要因应分析至**可以直接下对策**；e 一因多属时以**关联性最强者**为准（必要时三现主义）；f 选取重要原因不要超过 **7 项**、标识在最末端原因；
- **绘制**：填鱼头（按"为什么不好"的方式描述）画主骨 → 画大骨填大要因 → 画中骨小骨填中小要因 → 特殊符号标识重要因素——"大骨与主骨成 **60 度**夹角，中骨与主骨平行"；
- **使用步骤 8 步**：查找问题 → 写在鱼骨头上 → 召集讨论找原因 → 相同问题分组标出 → 总结正确的原因 → 研究为什么会产生 → **至少深入五个层次（连续问五个问题）** → 列出至少 **20 个**解决方法；
- 案例：**惠普墨盒**——真正原因包括：惠普的**无条件退货政策**、顾客不会解决小问题、非授权擅自给墨盒灌入劣质墨水导致损坏；结论：鱼刺图能全面反映产品质量因果关系（层次分明）；但"若没有一定的技术水平与生产经验……就难以绘成"。

**③ 散布图**（散点图/相关图）——判断两个变量之间相关关系的工具：
- 分类 5 种：强正相关（容量和附料重量）/ 强负相关（油的粘度与温度）/ 不相关（气压与气温）/ 弱正相关（身高和体重）/ 弱负相关（温度与步伐）；
- 用途 2：调查相关关系 / **求得控制管理的最佳值**（为使特性达到目标值而要因应取什么适当值）；
- 绘制步骤 5：收集资料（至少 **30 组**以上）→ 找最大最小值 → 画坐标轴刻度（通常纵轴=结果、横轴=原因；横轴越右越大、纵轴越上越大）→ 标点 → 填收集地点时间测定方法制作者；
- **观察 5 个方面**：有无相关关系 / **有无异常点**（"遇有'异常点'一定要彻底追究其原因"） / 有无分层的必要 / **是否假相关**（技术上看不存在相关却显示有相关——"一定要对几种数据的关系予以技术性考察"） / 能否外推（测定范围以外关系不明确则不宜外推）；
- 要点："调查两个因素之间的关系时应尽可能**固定**对这两个因素有影响的**其他因素**，才能使通过散布图得到的结果比较准确"。

**④ 直方图**（柱状图）——表示数据变化情况的主要工具（"将杂乱无章的资料解析出规则性"；分组是关键——两个关键数字是**分组数和组距**）：
- **六种形状与结论**：正常型（中间高两边低有集中趋势——制程正常运转）/ 偏向型（高处偏向一边——多由**工具磨损、松动及加工习惯**引起）/ 双峰型（有两个高峰——**两种分配混合**）/ 锯齿型（高低不一有缺齿——**分组过细或假造数据**）/ 平顶型（平顶——**不同平均值的分配混在一起**）/ 孤岛型（左端或右端形成小岛——**测定有错误、工程调节错误或不同原料**引起）；
- 绘制步骤 6：收集数据（100 个以上、至少 50 个以上）→ 分组（6~20 组较适宜）→ 计算组距宽度→ 计算各组界限值 → 统计频数作频数分布表 → 作直方图；
- **注意问题 8 条**：组距必须取"测定单位"（计量测试器具最小刻度）的**整数倍** / 确认数据测定单位 / **组边界值要取在"测定单位的 1/2 处"** / 组数根据数据量确定 / 横纵坐标轴标度比例适宜（"正确的直方图应近似于正方形"） / 横坐标两种标度方法 / 数据最大值最小值在两瑞组**对称**位置为宜（"S、L 位于两端组的正中央最为理想"） / 不要刻意要求组边界与标准一致（若给出标准值则边界定在标准值处、明确区分合格与不良）；
- 作用 3（易观察分布状态/知中心值和离散/调查分布的统计学类型）+ 用途 4（**过程（工序）寻找改进点** / 同公差标准比较求过程能力掌握余量 / 按时间系列作直方图控制过程 / 用于数据整理报告）。

**⑤ 检查表**（调查表/统计分析表/查核表）——利用统计表对数据进行整理和初步分析原因的工具（"QC 七大手法中最简单也是使用得最多的手法"）：
- 种类 4：不合格项目的检查表（调查不良情况及其比率）/ 工序分布检查表 / **缺陷位置检查表**（把产品的草图或展开图画在调查表上、缺陷发生时用不同符号或颜色在发生部位标出）/ 操作检查表；
- 使用步骤 6：决定观察什么建立作业定义 → 决定何时收集及收集多长时间 → 设计表格（用 √/×/相似符号简单记录）→ 留出空间 → 短时间试验测试检查表 → 每次观测值出现即记录；
- 应用时机 3：必须记下事件发生的具体情况时 / 想了解事件发生的次数时 / 想收集资讯时；
- **注意事项 5 条**：尽量取得分层的信息 / 尽量简便地取得数据 / **立即与措施结合**（事先规定对什么样的数据发出警告、停止生产或向上级报告）/ 检查项目过时必须重新研究和修订 / 通常情况下归类中不能出现"其他问题类"；
- 特别提醒：检查表"主要的出发点均建立在'假如'的假设精神上"——"对事物常存'怀疑'的心态，常用'假设'的精神去思考需要发明创造的问题"；注意**联想法与检查表法的顺序**（思考时先把想象力发挥极致直到再也想不出新构思时才使用检查表法——"若一开始就把要点列成一张表来思考，想象力很可能被束缚住"）。

**⑥ 分层法**（层别法）——对统计数据加以归类、整理和汇总的方法（"使同一层次内的数据波动幅度尽可能小，而层与层之间的差别尽可能大"；常与其他方法结合：分层直方图/分层排列图/分层控制图/分层散布图/分层因果图）：
- **分层标志 8 类**：人员（年龄/工级/性别）/ 机器（设备类型/新旧/生产线/工夹具）/ 材料（产地/批号/制造厂/规格/成分）/ 方法（工艺要求/操作参数/操作方法/生产速度）/ 测量（设备/方法/人员/取样方法/环境条件）/ 时间（班次/日期）/ 环境（照明度/清洁度/温度/湿度）/ 其他（地区/使用条件/缺陷部位/缺陷内容）；
- **案例：缸体与缸盖之间漏油**——按操作者分层（漏油率：张师傅 53% > 王师傅 32% > 李师傅 25%）；按生产厂家分层（A 厂 39% vs B 厂 37%——差不多）；**按两种因素交叉分层**（关键发现：王师傅用 A 厂气缸垫漏油 6 次而用 B 厂为 0；李师傅和张师傅类似——**分层的威力在于交叉分析**）；
- 应用要点 3：**在收集数据之前就应使用层别法**（"在解决日常问题时经常会发现对于收集来的数据必须浪费相当多的精神来分类……所以在收集数据之前应该考虑数据的条件背景以后，先把它层别化，再开始收集数据"）；**用好层别法是把握其他 QC 手法的基础**（柏拉图、查检表、散布图、直方图和管制图都必须以发现的问题或原因来作层别法——"直方图的双峰型或高原型都有层别的问题"）；管理工作上也应该活用层别法。

**⑦ 控制图**（管制图/管理图/休哈特图）——**统计过程控制理论与实践的核心工具**：
- 定义：一种**有控制界限**的图——用来区分引起质量波动的原因是**偶然的还是系统的**，从而判断生产过程是否处于受控状态；图上有中心线和上下控制线（中心线=所控制统计量的平均值、上下控制界限与中心线相距数倍标准差——"大多数制造企业采用**三倍标准差**控制界限"）；
- **分类**：按用途——分析用控制图（看工序是否处于稳定受控状）/ 管理用控制图（预防产生不合格品）；按控制对象变化——稳值控制图 / 变值控制图；按数据性质——**计量值控制图**（均值-极差控制图（最常用、判断工序是否正常效果好、计算量大——产品批量较大的工序）/ 单值-移动极差控制图（简便省事能及时判断、但不易发现工序分布中心变化——每次只能得到一个数据或希望尽快发现并消除异常因素的情况））与**计数值控制图**（不合格品数控制图 / 不合格品率控制图 / 缺陷数控制图 / 单位缺陷数控制图）；
- 绘制步骤 4：按规定抽样间隔和样本大小抽取样本 → 测量计算统计量数值 → 在控制图上描点 → 判断生产过程是否有异常；
- **确定控制界限（现场抽样法）4 步**：随机抽取样品 **50 件以上**测数据计算控制界限做控制图 → 观察是否在控制状态中（点全部在控制界限内且排列无异常→转下一步）→ 有异常则查明原因采取措施使之处在控制状态后再重新取数据 → 把数据作直方图与标准界限（公差上下限）比较看是否理想、不达要求则采取措施使平均值移动或标准偏差减少后重复；
- **工序处于控制状态的两条件**：没有超出控制界限的点（或连续 35 个点子中仅有一点出界、连续 100 点中不多于 2 点出界）；界限内点子排列完全随机没有规律没有排列缺陷；
- **判断异常 6 种情况**：样本点超出控制界限；连续 7 个以上点全部偏离中心线上方或下方；连续三个点中的两个点进入管理界限的附近区域（从中心线开始到管理界限的三分之二以上区域）；点相继出现向上或向下的趋势；点的排列呈周期性变化（可对作业时间层次处理重新制作）；——"如果发现了超越管理界限的异常现象却不去努力追究原因、采取对策，那么尽管控制图的效用很好，也只不过是空纸一张"；
- **使用注意事项 7 条**：不能用规格线或规格范围的 3/4 线来代替控制线（控制线只能根据生产实际数据计算）；控制对象应有定量指标且过程必须具有重复性；抽样间隔时间要从系统因素发生情况、处理问题及时性等技术方面考虑；应在生产现场及时分析（报警后先查取样读数计算打点再查生产原因）；生产条件变化或使用一段时间后必须重新核定；**控制图能起预防作用但并不解决生产条件的优化问题**；**当工序能力指数达不到要求时不能使用控制图**。

## 案例锚点（原文 · 物业管理服务）

应用基础是**数据收集**（将中控室或客户服务中心作为项目的数据中心——所有外来信息汇聚、统一向各部门输出指令）；流程：**分层法**（人/原材料/机械与工具/作业条件/时间/不良与错误状况——"客户信息是投诉、报修还是求助，同时区分是安管问题、工程问题还是环境问题"）→ **直方图**（统计引导关注）→ **鱼骨图/柏拉图/散布图**（找要因——"品质异常的原因可以从 **5M1E（人机料法环测）** 来考虑……人为疏忽、沟通问题往往是引起客户投诉的要因"）→ **控制图**（验证对策有效性——"验证结果的数据要尽可能做到改善前和改善后统计数据的其他基本条件一致，才能把握事实真相"）。

## 相关工具：新 QC 七大手法

- 1972 年日本科技联盟**纳谷嘉信**教授归纳——"为有别于原有的 QC 七大手法，所以称为新 QC 七大手法"；**主要运用于 PDCA 循环的 P（计划）阶段**（"着重在整理问题数值资料取得前的管理手法"——与原七手法相互补充：原手法用于生产过程质量的控制和预防）；
- **七种手法**：**箭线图法（ADM）**（网络图在质量管理中的应用——制定最佳日程计划和有效进度管理、"特别适用于工序繁多、复杂、衔接紧密的一次性生产项目"）；**关联图法**（用箭线表示各种因素之间因果关系的连线图——用于制定 TQC 活动计划/质量方针/生产过程质量保证措施等）；**系统图法**（系统寻找达到目的的手段——"把要达到的目的所需要的手段逐级深入"、广泛应用于因果图分析、质量保证体系建立等）；**KJ 法**（亲和图法——川喜田二郎创造；针对某一问题广泛收集资料按近似程度内在联系分类整理、"尤其针对未来和未知的问题可以进行不受限制的预见、构思"）；**矩阵图法**（L 型/T 型/Y 型/X 型/C 型——用于原材料新用途分析、质量保证体系关键环节等）；**矩阵数据分析法**（当矩阵图对应关系能定量表示时——**主成分分析法**、"QC 新七种工具中唯一一种利用数据分析问题的方法"）；**PDPC 法**（过程决策程序图法——"事先预测可能发生的障碍（不理想事态或结果），并相应地提出多种应变计划"——顺向思维法与逆向思维法；7 步骤；能预测重大事故）；
- **按用途分组**：澄清问题——亲和图法、关联图法；展开方案——系统图法、矩阵图法；实施计划——箭线图法、PDPC 法、矩阵数据分析法；
- **益处 5 条**：迅速掌握重点 / 学习重视企划 / 重视解决过程 / 了解重点目标 / 全员系统导向。
