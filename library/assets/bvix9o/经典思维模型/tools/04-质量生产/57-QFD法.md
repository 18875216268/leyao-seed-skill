# QFD 法

> 编号 #57 ｜ 篇：四·质量生产 ｜ 源：`TOOL` P1080–P1093
> 全称：Quality Function Deployment 质量功能展开（赤尾洋二 & 水野滋，60 年代） ｜ 类型：顾客驱动质量管理技术

**一句话**：把**用户需求（What）系统展开转化为产品技术特征（How）**，再逐级展开到零部件、工艺、生产要求——用"**质量屋**"（HOQ）量化分析需求与工程措施的关系度、找出关键措施（"一种顾客驱动的先进质量管理应用技术"）。

## 什么时候用

- 新产品设计开发（**设计之初就把质量作为内置要素**——从事后把关转变为事前防范）；
- 产品规划、工艺规划、生产规划的系统展开；
- 计划与管理（顾客驱动的计划过程——战略计划、投资项目、供应商选择、标杆管理等）。

**不适用**：需求无法调查获取的场景（QFD 的输入就是顾客声音）；纯工程细节优化（→ 用田口方法等）。

## 来源与定义

- 60 年代由日本质量管理大师**赤尾洋二和水野滋**提出（日本工业从模仿生产过渡到基于创新的产品发展的时期）；70 年代后期在汽车、电器领域广泛应用——"被认为是日本式质量管理最重要的特点"；**1985 年在美国开始应用**（伴随 6σ 技术）；1995 年第一届国际质量机能展开研讨会（ISQFD）在东京举行；**我国 1994 年引进**；
- **定义三版本**：赤尾洋二——"QFD 将用户需求质量特征，通过系统展开后将转化为最后产品的设计质量，并从每个功能部件的质量一直延伸到每个零件及工艺过程的质量"；美国 ASI——"将用户需求转换为产品开发和生产的每一阶段（市场分析、系统规划、产品设计、原型评估、生产过程和销售服务）相应技术需求的方法，是保证达到用户要求的产品质量所需一切活动的总称"；福特——"把用户需求和期望转换成公司适合于市场需求的一个规划工具"；
- **四层主要意义**：① 用户需求驱动的产品开发和规划方法；② 结构化的产品规划和开发方法；③ 能从满足用户需求的角度对产品或服务性能进行**系统评估比较**；④ 系统化获取分析需求 + 结构性（**矩阵图解法**）转化为各类技术规范及信息（产品特征、工艺特性、质量控制、加工过程）。

## 实际效益

- **可量化**：新产品开发周期缩短、设计更改次数减少、开发启动经费降低、保单索赔额减少、市场销售量增加；
- **不可量化 4 条**：① 准确理解用户需求→显著提高用户满意度；② 综合考虑用户需求、竞争对手、技术特征和工艺成本→既增加生产率又提高质量→提高市场竞争力；③ 参与开发各部门**取得共识并建立信息联系**——"改变自上而下的信息流为**水平式的信息流**、建立多功能开发小组协同工作模式"；④ 系统化结构化的分析解题与规划决策方法——合理分配利用资源、合理解决开发中的矛盾冲突。

## 基础工具：质量屋（HOQ）六部分

原理=用质量屋形式量化分析顾客需求与工程措施的关系度→找出对满足顾客需求贡献最大的**关键措施**→指导设计人员抓住主要矛盾：
① **顾客需求及其权重**（"**什么 What**"——质量屋输入信息；通过问卷市场调查、将"顾客的声音"转换成顾客真正需要；信息提取三步：合理确定调查对象/确定合理调研方法/全面市场调查）；
② **技术需求（最终产品特性）**（"**如何 How**"——满足用户需求必须保证实现的技术特征；确立三条件：**针对性**（针对对应需求提出）/ **可测性**（可测量测试便于控制）/ **全局性**（只为选择方案提供评价标准、不涉及具体设计方案——必须至少满足一项用户需求））；
③ **关系矩阵**（顾客需求与技术需求之间相关程度——从需求到技术特征的映射关系）；
④ **技术需求相关关系矩阵**（质量屋的**屋顶**——记录设计要求之间支持、冲突和相关程度）；
⑤ **评价矩阵**（竞争分析——站在顾客角度对本企业产品与竞争者产品评估——确定竞争优势劣势、寻找突破性改进方向、设置战略目标）；
⑥ **技术评估**（对技术需求竞争性评估、确定重要度和目标值——含：根据顾客要求重要度和关系矩阵确定设计要求权重/技术竞争性评分/确定设计要求目标值）。

## 基本过程（4 阶段分解法）

用户需求分解四阶段、用四个矩阵得出工艺和质量控制参数：
- **产品规划矩阵**：顾客需求 → 产品技术特征（根据顾客竞争性评估（顾客角度）和技术竞争性评估（技术角度）结果确定各技术需求目标值）；
- **产品/零件配置矩阵**：以产品技术特征为输入 → 确定最佳产品设计方案、进行产品结构设计 → 转化为关键零部件特征（复杂产品可分子阶段）；
- **工艺规划矩阵**：确定工艺方案基础上通过工艺规划"质量屋"→ 确定关键工艺操作及工艺参数；
- **生产规划矩阵**：关键工艺操作及参数 → 具体可行的生产及质量控制方法手段（控制参数、控制点、样本容量、检验方法等）。

## 主要工具（8 种）

**亲和图**（使具有深层结构特征的顾客需求"浮出水面"）/ **关系图**（发现优先需求、质量流程问题根本原因、**沉默顾客**的需求）/ **树图**（寻找亲和图和树图中的缺陷和遗漏）/ **各种矩阵**（表示指标关系、优先项、责任）/ **流程决策程序图 PDPC**（分析可能造成新产品或服务失败的潜在因素）/ **层级分析法 AHP**（对顾客需求优先排列、选出满足需求的设计生产方案）/ **蓝图**（对提供产品或服务的整个流程分析描述）/ **质量屋**。

## 适用范围（五领域）

产品设计开发（修枝剪刀、耐高压电子元器件、社会系统、体育用品等——"产品质量的事后把关转变为事前防范"）/ 产品生产（起源于神户造船厂实践——半导体、电子、汽车制造）/ 质量改进（TQM 的工具之一——过程改进、过程管理和质量机能展开、过程控制、使用阶段质量保证）/ 计划（积极的"顾客驱动计划过程"——在开发之初就发现解决问题；可应用于土木工程、企业资源计划、制造战略计划、投资计划）/ 管理（顾客驱动和市场导向型管理过程——知识管理、供应商选择、成本控制、时间控制、项目管理、标杆管理）。

## 案例锚点（原文 · 山地车车架 · 七步建质量屋）

**步骤一·列顾客要求**（分层定义——第一层：经济性/美观性/性能；第二层展开：价格适宜；外观协调、外表磨光、防腐蚀；轻盈、快速、持久耐用）；
**步骤二·列技术要求**（第一层：用料选择、制造工艺；第二层：钢/铝/钛材料；焊接、压力铸造、砂型铸造、锻造、粉末冶金）；
**步骤三·需求与措施相关关系**（**●=9 强关系 / O=3 中等 / △=1 弱 / 空白=0 无**）；
**步骤四·技术要求相互相关**（**●=9 强正相关 / O=3 正相关 / ×=-3 负相关 / ★=-9 强负相关 / 空白=0**）；
**步骤五·竞争性评估**（顾客对产品竞争力评价 + 技术竞争力评价——均 1-5 分）；
**步骤六·顾客要求排序**（对顾客重要度 1-10 分 / 目标值 1-5 分 / 提升值=目标值÷顾客对产品竞争力评定分数 / 卖点 1.0-2.0 / **绝对量=重要度×提升值×卖点**——数值越大越重要）；
**步骤七·技术要求排序**（困难程度 1-10 分（10=难度很高）/ 目标值 / **绝对量=Σ[关系矩阵关联值×对顾客的重要度]** / **相对值=Σ[关系矩阵关联值×顾客顺序排列值]**）。
**结论方法**（三条综合考虑）：绝对值/相对值越大越优先；技术困难程度越低越优先；HOWS 之间正相关或强正相关可以考虑 → 本案例最佳选择：**铝材料 + 砂型铸造**（结合技术难度铝较低、砂型铸造难度较低、二者正相关）；注意"研发人员只能把上述输出信息作为设计开发输入信息的重要依据，而非百分之百的依据"。

## 作用功能

- **量化作用**：产品开发周期可缩短**三分之一**、成本可减少**二分之一**；工程设计更改减少 **40%~60%**、开发周期缩短 **30%~60%**、试制成本降低 **20%~40%**；
- **功能 4 条**：① **顾客驱动的产品开发方法**（需求贯穿全过程——"要求企业不断地倾听顾客的意见和需求"）；② **各职能部门协调工作的方法**（从被动的反应式"**设计—试验—调整**"到主动的预防式现代开发模式——"将注意力集中于规划和问题的预防上，而不仅仅集中于问题的解决上"）；③ **在产品设计阶段进行质量保证的方法**（早期设计阶段有效规划预防、避免后期返工——"制造领域的信息都起源于用户的信息"）；④ 使产品以**最快的速度、最低的成本和最优的质量**占领市场（不必选择太多配置项——优先配置综合考虑技术需求重要度、用户/技术竞争性评估、实施难度和成本、相关矩阵）；
- **核心理念转变**：质量的定义从"**满足设计需求**"转变为"**满足顾客需求**"；用户化产品越来越成为市场需求趋势。
