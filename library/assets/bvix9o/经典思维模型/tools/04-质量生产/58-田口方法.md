# 田口方法

> 编号 #58 ｜ 篇：四·质量生产 ｜ 源：`TOOL` P1094–P1103
> 全称：Taguchi Methods（田口玄一，1950 年代） ｜ 类型：质量稳健性设计方法

**一句话**：以**正交表安排试验 + 误差因素模拟干扰 + 信噪比衡量稳健性**——用"三次设计"（系统设计/参数设计/容差设计）在**不增加甚至降低成本**的情况下，设计出抗干扰能力强、性能稳定的产品（"质量管理利器、企业技术创新不可或缺的工具"，核心内容被日本视为"国宝"）。

## 什么时候用

- 产品设计开发、科学试验、技术革新、工艺改革、材料研制等**开发性领域**；
- 质量评价和质量改进（使设计对不可控因素不敏感、"大大减低零部件和装配容差"）；
- 用廉价元件做出稳定产品（"采用特征值波动大的三级品元件仍可得到较稳定的质量特性"）。

**不适用**：把田口当"唯一正确"的统计方法（田口 DOE 统计有效度"非常弱"、改进程度"低度"——需知选择）；不做确认实验就采信（应用步骤最后必须确认实验）。

## 产生与发展

- 日本田口玄一博士 1950 年代创立；1962 年获质量应用戴明奖；1980 年代后美国 AT&T、Ford、Xerox、Motorola、Kodak 等公司陆续采用；
- 起源：50 年代初日本电讯研究所，以田口为首的研究人员在**费歇尔多元配置法试验设计**基础上开发正交试验技术（用规范化正交表安排试验）——"将质量管理与经济效益联系在一起，将工程经验与统计原理相结合"；
- 影响：**据称日本 80% 的质量改进收益是由田口方法带来的**；美国专门成立田口方法研究会；我国原兵器工业部大力推广（武器研制开发与功能改进取得成绩）。

## 基本思想与目的

- **思想**：有效的稳健性优化设计方法——用正交表安排试验方案、以误差因素模拟造成质量波动的各种干扰、以**信噪比（SN 比）**作为衡量质量稳健性的指标、通过统计分析找出**抗干扰能力最强、调整性最好、性能最稳定可靠**的设计方案；以质量损失最小为原则合理确定参数容差；
- **目的**：使所设计的产品质量稳定、波动性小，使生产过程对各种**噪声不敏感**；在低成本条件下开发高质量产品（效益=企业内部效益（功能相同条件下的低成本）+ 社会损失（产品进入消费领域后给人们带来的影响）——"由于一个产品功能波动偏离了理想目标、给社会带来了损失，我们就认为它的稳健性设计不好"）。

## 二次损失函数（基础）

**L(y) = k(y-T)²**——T=目标值（顾客要求、偏好或期望）；(y-T)=质量性能与目标值的偏离；k=为避免质量指标偏离目标的成本。
意义：用**货币单位**对产品质量定量衡量（社会损害损失越小质量越好）；用损失函数描述质量更加切合实际——"使决策者认识到是顾客满意、偏好和期望决定了质量损失，从而进一步驱动工程和技术人员从**技术和经济两个方面**同时分析产品设计与制造过程"。

## 三次设计（核心框架）

**① 系统设计**（功能设计——按市场规划的产品功能选择基本模型系统、确定产品特性值的目标与容差；主要是运用专业技术理论与方法确定系统功能结构，包括原材料、零件、部件及组装系统的选择）；
**② 参数设计**（**产品设计的核心**——按实际生产及将来使用情况对系统模型改进与再设计、选择所有参数（原材料/零件/部件/组合件）的**最优水平组合**、使产品抗干扰性强、性能稳定在目标值附近；**实质是非线性效应的利用**——产品质量特性与某些零件参数水平间存在非线性关系，目的就是利用非线性寻找能给出质量特征数与目标值最小偏差的参数组合；此阶段**一般用波动范围较宽的廉价原部件进行设计**，使质量和成本两方面均改善；方法：正交试验法（**内侧正交、外侧正交**）+ **信噪比 SN 比**作为稳定性指标）；
**③ 容差设计**（在参数设计基础上对产品生产时各种参数给出**最佳容差范围**——综合考虑产品质量和生产维修成本、进行再改进再设计使**总经济效益最佳**；主要运用质量损失函数和正交多项式回归分析）。
**分工**：系统设计主要是专业技术工作；参数设计和容差设计属通用技术范畴（主要依赖数学和统计知识）。

## 应用步骤（10 步）与注意点

**步骤**：选定质量特性 → 判定质量特性的理想机能 → 列出所有影响此质量特性的因子 → 定出**信号因子**的水平 → 决定**控制因子**并定出它们的水平 → 决定**干扰因子**并定出它们的水平（必要时可进行干扰实验）→ 选定适当的直交表、安排完整的实验计划 → 执行实验、记录数据 → 资料分析 → **确认实验**（若有必要可重复以上步骤直到达到最佳质量及性能）。
**注意点 3 条**：最好能使误差因子复合为 1、2 个或最多三个；误差因子按其影响程度及实验目的确定；一般选择 2 个水平。

## 工具特点（五条）

① **工程特色**（用工程方法研究产品质量——把产品设计当成工程设计、用产品给社会造成的经济损失衡量质量）；② **"源流"管理理论**（开发设计阶段是保证产品质量的**源流（上游）**、制造和检验阶段是下游——"**抓好上游管理，下游管理就很容易**"；若设计质量上不去，生产制造中很难造出高质量产品）；③ **产品开发的三次设计法**（参数设计是核心——传统多数设计是先追求目标值、通过筛选元器件减少波动（"尽管都是一级品的器件，但整机由于参数搭配不佳而性能不稳定"）；田口方法则**先追求产品的稳定性**、强调可以使用低级品元件——通过分析质量特性与元部件之间的非线性关系（交互作用）找出使稳定性达到最佳水平的组合）；④ **质量与成本的平衡性**（引入质量损失函数——使产品整个寿命周期内**社会总损失最小**；用容差设计技术使质量和成本达到平衡）；⑤ **新颖实用的正交试验设计技术**（综合误差因素法、动态特性设计——用误差因素模拟各种干扰（如噪声），最优结果在加工过程和顾客环境下都达到最优、大大节约试验费用）。

## 工具作用（四条）

① 提高产品科技含量、促进技术创新（改变企业一味引进先进设备的状况、增强**二次创新能力**）；② 缩短产品开发周期、加速产品更新换代；③ **应用田口方法创名牌**（三次设计的产品稳健性好、抵御外界干扰能力强、波动小、质量可靠）；④ **应用田口方法创效益**（"用廉价的三等品零件组装一等品整机，真正做到了价廉物美"）。

## 相关工具：谢宁方法（对比参考）

- 美国人多里安·谢宁 1980 年代起历经 **40 余年**研究开发——解决产品制造及设计开发过程中质量和可靠性问题的系统方法工具；总结**七种 DOE 技术**：多变图技术 / 零件搜索技术 / 成对比较技术 / 变量搜索技术 / 完全析因技术 / 改进效果检查 / 实验设计的回归分析；
- 七种技术可单用可组合（试验因素 20 个以上时依次采用前四种）：**多变图**（按工人班次/机床/原材料等要素定时抽样画图比较——分三类：单个工件严重变差型/工件到工件严重变差型/工时到工时严重变差型）；**零件搜索**（好坏产品交换可疑零件重新装配测量——找主要零件）；**成对比较**（5 对以上好/坏产品测试比较——适用不可拆卸产品）；**变量搜索**（与零件搜索相似但针对变量）；**完全析因**（找出 4 个以下主要因素、全部组合实验研究主效应与交互作用）；**改进效果检查**（设第Ⅰ/Ⅱ类风险率、假设检验验证改进后工序是否优于改进前）；**实验设计回归分析**（散布图+回归理论诊断因素、确定目标值和容差）；
- **三种 DOE 对比表**：经典 DOE（分析因法、响应曲面法——**中度改进、成功率低**；高（30~60 次试验）；复杂；准备 3~14 天；统计有效度弱；需硬件主要用于生产；难；试验期间停产）；田口 DOE（**正交表**——低度改进、成功率低；高（50~100 次）；复杂；7~14 天；**非常弱**；结合计算机仿真主要用于论文；难；停产）；谢宁 DOE（**10 多种方法**——**高度改进、高成功率**；低（**2~30 次**）；**简单**；短（**1 天**）；**强**；需硬件、通用于企业的经营活动；**易**；**思维创新中不停产（原因查找试验可以解决 70% 的长期问题）**）。
