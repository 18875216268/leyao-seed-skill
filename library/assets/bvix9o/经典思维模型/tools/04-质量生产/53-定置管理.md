# 定置管理

> 编号 #53 ｜ 篇：四·质量生产 ｜ 源：`TOOL` P0966–P0987
> 创始：青木龟男（日本，50 年代）；清水千里 1982《定置管理入门》 ｜ 类型：现场管理方法

**一句话**：把现场的**物品按工艺流程要求定置在科学合理的位置上**——通过物品定置 + 信息系统媒介，实现**人、物、现场三者的最佳结合**（时间、空间优化组合），强化现场管理和谋求系统改善。

## 什么时候用

- 生产现场管理改善（物流有序、安全文明生产）；
- 5S/TPM 的深化配套（定置管理是 5S 的延展——"物分四类，按图定位"）；
- 复杂现场（多品种、大件、中转多、脏乱源多的车间）的系统治理。

**不适用**：把定置理解为"摆整齐"（核心是**人-物-场所-信息**四者关系与物流系统效率）；一次定死（**动态原则**——定置物及场所随生产经营变化而变动）。

## 来源与定义

- 起源日本：青木能率（工业工程）研究所的文明生产创导者**青木龟男**从 50 年代开始根据日本企业生产现场管理实践提出；后由清水千里应用发展、1982 年《定置管理入门》提炼成科学管理方法；
- **定义**：企事业单位强化现场管理和谋求系统改善的科学管理方法——以生产和工作现场为研究对象，探讨生产要素中**人、物、场所、信息**的状况及相互关系；通过**作业研究、动作研究**，将现场各种物品按工艺流程要求、制约条件和使用方法定置在科学合理的位置；**以物在现场的科学定置为前提、以完整的信息系统为媒介、以实现人和物的有效结合为目的**。

## 主要作用（五个方面）

① **消除物的不安全状态**（物品定置合理化、机电设备优化组合、工位器具布局合理、安全通道畅通——对建筑施工、设备安装、高处作业、压力容器、起重吊运、危险作业、易燃易爆、有毒有害物品**特殊定置**）；
② **制约人的不安全行为**（庭院式、居室式工作环境强烈影响心理——不安全行为的人会被"同化"而"顺从"，潜移默化形成自我约束、自我控制的自我管理态势）；
③ **内建一流现场、外创一流市场**（环境整洁、生产均衡、物流有序、纪律严明、设备完好、信息准确）；
④ **物流有序保证产品质量**（避免碰伤、锈蚀、变形、混淆错乱）；
⑤ **变废为宝**（"**世界上本没有什么废物。所谓废物，就是放错了位置的东西**"——挖掘空间资源、改变拥挤状况）。

## 基本理论（四层关系）

**① 人与物的关系**：结合形式两种——**直接结合**（所需之物立即准确得到）vs **间接结合**（人与物分离、需信息媒介引导确认）；结合**三状态**：
- **A 状态**（立即准确结合、有效生产——最理想，要持久保持）；
- **B 状态**（寻找状态或物有缺陷、需经过某种活动才能结合——要分析改进使其接近/达到 A）；
- **C 状态**（物与生产无关、无需结合却占现场空间——要清理，使与生产失去联系的物品清理出现场；C 状态处理最关键：既恢复物品使用价值、又腾出空间）。

**② 场所与人、物的关系**：场所与物两种结合形式——**固定位置**（场所固定、存放位置固定、信息媒介物固定——如行车吊具工作台模具，周期性往返、用后**回归原地**）vs **自由位置**（一定范围内自由放置、依靠信息媒介物——适用于不回归、不重复使用的物品）；场所**三状态**：A 良好状态（环境作业空间通风采光温湿度噪声粉尘都符合生理和生产要求）/ B 需要改善（不能满足生理或生产要求）/ C 需要彻底改造（既不能满足生理又不能保证安全）。

**③ 信息媒介物**（人与物大多是间接结合，靠信息指引确认）：信息分四类（指令性/标准性/引导性/确认性），定置管理用两类——
- **引导性信息**：第一媒介物告诉"**该物在何处**"（如位置台帐）；第二媒介物告诉"**该处在哪里**"（如定置图）；
- **确认性信息**：第三媒介物告诉"**这里就是该场所**"（区域标牌、货架标牌——场所标志）；第四媒介物告诉"**此物就是该物**"（名称/规格/数量/质量等——物的确认）；
- 要求：确认信息清楚醒目、引导信息齐全；车间工段班组乃至所有现场都要有定置图、位置台账完备；信息媒介物标准化、规范化。固定位置系统例：仓库"**四号定位**"（库、区、架、位）与"**三一致**"（账、卡、物）。

**④ 物流系统**：原材料进厂→按工艺流程进入各工序→加工检验→成品出厂的全过程；三个关系——良好工作场所是物流畅通的**基础**；信息媒介物及时准确反映对象物位置特性状态是**前提**；物品合理定置、加工对象物与加工手段物合理配置、人与物有效结合是**主体**。

## 基本内容（口诀与四类物品）

**口诀**："物分四类，按图定位；ABCD，常转代废；颜色各异，红蓝黄黑；坚持定置，文明之最"：
- **A 类**：常用物品（正在加工的对象物与手段物）——**红色**；
- **B 类**：随时转化为 A 类的物品（周转中的半成品、周转工位器具）——**蓝色**；
- **C 类**：代为保管的物品（待发运产品、暂时封存的工位器具）——**黄色**；
- **D 类**：废品废料等等待处理的物品（钢渣、垃圾）——**黑色**；
四类按定置图定置、按标准设标志牌、**图物一致**。

**定置对象**：场地定置（生产区/绿化区/卫生区/堆放区划分 + 安全通道标识）/ 设备定置（动作时间与工艺流程分析、易损件备件箱、材料按每班需用量定时补充）/ 特殊物品定置（易燃易爆有毒有害特殊定置）/ 仓库定置管理 / 工具箱定置 / 操作者定置（坚守岗位不许混岗、特种作业持证上岗）。
**五种类型**：全系统定置 / 区域定置（按工艺流程划分定置区域）/ 职能部门定置 / 仓库定置 / 特别定置（质量安全薄弱环节）。

## 实施应用（原则 · 要求 · 步骤 · 技法）

- **依据**：生产系统目标（存贮费用、劳动力、闲置设备和管理费用保持在一定水平下达到预期生产量）+ 加工过程要求 + 生产现场的有效空间；
- **五原则**：符合工艺要求 / **以安全为前提**（物放稳妥、防护得力、道路畅通、消防方便）/ 符合环保与劳保规定标准 / 节约原则（因地制宜少花钱多办事）/ **动态原则**（随生产经营变化而变动）；
- **基本要求**：划清范围实行责任制 / 物品摆放优化定位 / 与生产工作无关的物品一律不得摆放 / 制定室内物品平面定置图 / 物品有完整规范标签标志；
- **开展六步**：① 建立机构培训人员（生产副总为组长的领导小组）；② **工艺路线研究**（起点——调查记录现行方法 → 分析事实找问题 → 拟定改进方案（技术经济对比后标准化））；③ **现场调查与人、物结合状态分析**（最关键环节——消除 C 状态、改进 B 状态、保持 A 状态）；④ **定置管理设计**（定置图设计（五原则：所有物绘在图上/简明扼要完整/已定置未制之物也画、准备清理之物不出现/标准符号标注并说明/随定置关系变化修改）+ 信息媒介物设计（信息符号（国标优先）+ 示板图标牌，底色宜淡色调））；⑤ **定置实施**（清除与生产无关之物 → 按定置图实施定置 → 放置标准信息名牌；总要求："**有图必有物，有物必有区，有区必挂牌，有牌必分类；按图定置，按类存放，账（图）物一致**"）；⑥ **检查与考核**（验收检查 + 定期检查考核；基本指标=**定置率=实际定置物品个数（种数）/定置图规定的定置物品个数（种数）×100%**）；
- **五种基本技法**：现场诊断 / 作业研究分析 / 工艺分析（加工、搬运、检查、停滞、储存五个环节）/ 动作分析 / 环境因素分析。

## 案例锚点（原文 · XX 船厂）

内河大型船厂（固定资产 1 亿多、职工 4800 多人）——难点在船体、船台、水上等车间（作业面宽、场地分散、构件粗重、中转多、脏乱源多）。
**做法**：制定《文明生产定置管理办法》（含概念、定置内容两条：确定"物"放置场所方式+确定定置物标志；对象四类定置（①结合态之物②待用待加工类③代管物品类④待清除类）；定置图绘制规定；加强要求；**目标：生产现场定置率 80% 以上、库房 85% 以上**；职能分配）；在船体车间试点（21m 和 27m 跨为重点——绘制定置图竖立现场；开展 5S（清理死角、搬出与生产无关的铁房子）；构件半成品堆场棋盘式布置、流动设备（电焊机）纳入定置；建章立制与经济责任制挂钩考核；**电焊条管理改善**：定额发放 + 回收考核（回交 95% 焊条头、尺寸超标扣发、0.1 元/焊条头奖励）——同类船舶节约焊条 5t 以上）。
**效果**：企业形象赢得市场（促进造船合同签订）/ 扩展生产空间提高效率 / 现场改观提高产品质量 / 创造较好经济效益。
