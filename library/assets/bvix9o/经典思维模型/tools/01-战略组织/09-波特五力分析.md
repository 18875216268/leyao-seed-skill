# 波特五力分析

> 编号 #9 ｜ 篇：一·战略组织 ｜ 源：`TOOL` P0150–P0182 ｜ 同源：`PPT`（P1-29 / P2-45，页码锚点见 index.md）
> 全称：波特五力分析模型（Porter's Five Forces） ｜ 类型：行业竞争结构分析工具

**一句话**：用**供应商议价能力 / 购买者议价能力 / 新进入者威胁 / 替代品威胁 / 行业内现有竞争**五种力量，分析行业的基本竞争态势与盈利吸引力（波特 1979 年《竞争力如何塑造战略》提出、1980 年《竞争战略》整合成型）。

## 什么时候用

- **行业竞争结构分析**（企业外部分析的"事实标准"，从制造业到金融、高新普遍适用）；
- 投资可行性研究、商业计划书前期研究；
- 决定"是否进入某行业"（选择有潜在高利润的行业）＋ 选定行业后确定竞争策略。

**不适用**：企业内部能力分析（→ `价值链分析` / `7S模型`）；快速变化行业需配合动态分析补足。

## 五种力量（判定"何时强大"）

**1. 供应商议价能力（供方强时）**：供方行业稳固集中、不受剧烈竞争困扰；产品有特色致买方难以转换或转换成本高、难找替代；供方能前向一体化而买方不能后向；供方投入要素占买主总成本比例大 / 对生产重要 / 严重影响质量。影响因素：行业集中度、产品标准化程度、成本占比、对流程重要性、与自产成本比较、对质量影响、采购转换成本、前向一体化意图。

**2. 购买者议价能力（买方强时）**：购买者总数少而单体购买量大（占卖方销量比例高）；卖方行业由大量小企业组成；产品标准化、可多卖主购买；买方能后向一体化而卖方不能前向。影响因素：集体购买、产品标准化程度、质量敏感性、替代品替代程度、大批量购买普遍性、占购买者成本比例、后向一体化意图。

**3. 新进入者威胁**：取决于**进入障碍大小 + 预期报复可能性**（报复取决于财力、报复记录、固定资产规模、行业增速等）。
- 进入障碍构成：**规模经济**（最低有效规模越高障碍越大）、**产品差异化**（独特质量/品牌/服务/组合）、**转换成本**（重培训、新辅助设备、检验考核的时间风险成本、技术帮助、重新设计、心理代价）、**技术障碍**（专利、专有技术 know-how、**学习曲线**——最早进入者享有与规模无关的成本优势）、**销售渠道控制**、**政策法律**（如金融业保护）。

**4. 替代品威胁**：替代品价格越低、质量越好、用户转换成本越低 → 竞争压力越强；来源不止同行业（**跨行业的替代往往更具威胁**）。识别替代品：列替代清单 → 追问"顾客需求是什么、哪些产品能满足这些需求、它们的功能特征是什么"（价值 = 顾客愿支付的一组功能，可用"价值曲线"描述）。压力大小取决于：替代品盈利能力、替代品企业策略、买方转换成本。

**5. 行业内现有竞争（加剧条件）**：进入障碍低、势均力敌的对手多且范围广；市场成熟、需求增长缓慢；竞争者降价促销；产品同质、用户转换成本低；行业外强手收购弱手后发起进攻；**退出障碍高**（资产专用性、退出固定费用、战略牵制、情绪难以接受、政府与社会限制）——退出比继续竞争代价更高时竞争最烈。

## 工具特点

- 三大用途：**多元经营决策工具**（进入陌生行业时了解并控制投资风险）、**市场定位分析工具**（定战略的同时确定自己是领导者/竞争者/追随者）、**利润分析辅助工具**（明确维持利润来源的关键因素）；
- **静态分析**：五种作用力越弱 → 行业利润越高；企业战略与市场位置能有效应对五力 → 可获得超额利润；最终目的是建立在竞争优势上的坚固市场位置；
- **动态分析（行业演进）**：四连问——预测每个作用力将来如何变化？变化如何影响其他作用力？相关变化到顶峰时如何影响行业未来利润？现行战略下企业未来实力如何？据此调整战略、利用变化中的行业结构；
- 是 `SWOT分析` 的重要扩展（"资源-环境"模型）；被视为正式情景分析理论的先驱。

## 局限（原文四点）

1. 未清楚解释**不同行业竞争模型之间的内在联系与相互影响**；
2. 未直接说明**竞争角色多重性**（同一参与者可能既是购买者又是供应者）；
3. 未用行业间联系说明**竞争者角色转换**（如烤烟厂：在原料模型中是购买者、在卷烟模型中是供应者）；
4. 模型**静态而非动态**（未分析竞争角色在时间与空间上的动态性）。

## 应用流程

1. 收集信息确认每个作用力的特征（检查评估其对产业的影响）；
2. 用因素确定每个作用力的影响程度（大部分信息可从间接资源获取；重要资源用于提高分析客观性）；
3. 从**确认竞争压力的主要来源**入手：竞对间竞争 → 替代品 → 潜在进入者 → 供应商议价 → 购买者议价。
- 提醒：五力只是环境分析利器、**不是制定战略的全部依据**——还需考察自身资源与行业的匹配度（归核化趋势）、保持战略柔性（巨人集团 vs 苹果案例）。

## 与一般战略的关系（波特三大通用战略）

- **总成本领先**：高效规模化设施、全力以赴降成本、严格控制管理/研发/服务/推销/广告费用；
- **差异化**：全产业范围的独特性（名牌形象、技术性能、顾客服务、商业网络…）；与提高市场份额不可兼顾，伴随高成本代价；
- **专一化**：主攻特殊顾客群 / 某产品线细分区段 / 某地区市场——以更高效率服务狭窄对象、超越广范围竞对；
- 核心：**竞争优势是所有战略的核心，必须做出选择**（全面出击 = 毫无竞争优势）。

## 关联模型

- 扩展：**安迪·格鲁夫六力模型**（+第六力"协力业者的力量"——互补者/通路伙伴，技术变革可能改变其平衡）；**波特行业竞争结构分析模型**（五力打分表：坚决同意 1 分 ~ 坚决反对 5 分，逐项量化，分数越高越应尽快解决）
- 配套：`PEST分析`（宏观环境）、`SWOT分析`（内外匹配）、`竞争态势矩阵`（竞对逐项对比）
- 同族：`战略集团分析法`（行业内战略群体划分）
