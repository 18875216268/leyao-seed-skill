# PEST 分析

> 编号 #2 ｜ 篇：一·战略组织 ｜ 源：`TOOL` P0034–P0054 ｜ 同源：`PPT`（P1-32 / P2-44，页码锚点见 index.md）
> 也称：STEP 分析；扩展版 STEEP / PESTEL / STEEPLE ｜ 类型：环境分析框架

**一句话**：从**政治法律（P）· 经济（E）· 社会文化（S）· 技术（T）**四个维度扫描宏观环境，识别外部变化带来的机会与威胁，作为战略制定的外部输入。

## 什么时候用

- 战略规划前的宏观环境扫描（公司战略规划、市场规划、产品经营发展、研究报告）
- 进入新市场 / 新行业前的环境评估（政策壁垒、经济景气、文化习俗、技术条件）
- 与 SWOT 配套：**PEST 提供 OT 输入**，SWOT 做内外匹配（SWOT-PEST 组合矩阵见下）

**不适用**：企业内部能力分析（→ `价值链分析` / `7S模型`）；具体行业竞争结构分析（→ `波特五力分析`）。

## 四个维度（扫描什么）

**P 政治法律**：社会制度、执政党方针、政策法令、税制、反垄断、环保法规、产业与投资政策、政府补贴、进出口限制、专利保护等。
**E 经济**：GDP 及增长率、利率/汇率/通胀、可支配收入、消费与储蓄倾向、失业趋势、货币与财政政策、地区收入差别等。
- 分两层：宏观（人口、国民收入、GDP）与微观（区域消费者收入、偏好、就业程度）。
**S 社会文化**：人口统计（生育率、年龄分布、流动）、文化传统与价值观、生活方式、教育水平、宗教信仰、审美、健康与环保意识等。
- 核心价值观高度稳定（历史沉淀）；次价值观易改变——重点找"哪些价值观/生活方式变迁会影响需求"。
**T 技术**：新技术/新工艺/新材料及趋势、国家对科技的投资方向、研发费用总额、技术转移与商品化速度、专利与保护、技术更新周期等。

## 核心步骤

1. **罗列关键宏观因素**：四维逐一扫描（可用《PEST 分析项目核对表》防遗漏）；识别方法——头脑风暴 / 因果分析 / 集体讨论 / 关键事件。
2. **定权重**：按因素对本企业的具体影响赋权（经验判断 / 参照 / 三维确定 / 价值因子分析）。
3. **按现行战略评分**：区分战略类型（生产制造 / 财务投资 / 人力资源 / 市场营销 / 产品研发）；要求小组评估、过程公开、集体决策。
4. **加权求和**：权重 × 评分 → 汇总得宏观环境总加权分数（配合统计监督、数据纠偏）。
5. **导出机会与威胁（OT）**：把关键因素翻译成 OT，供 SWOT / 战略制定消费。

## 关键要点

- PEST **只提供框架，不提供指标选择与评估标准**——具体指标必须结合行业自行选择丰富，结果相当程度依赖分析者水平（原文明确提示此局限）；
- 关注**未来**而非现状：哪些因素过去重要、未来重要性如何变化；
- 与 SWOT 的分工：PEST 侧重**大行业背景**；SWOT 从企业出发、结果可指导趋利避害；
- **SWOT-PEST 组合矩阵**：S/W/O/T × P/E/S/T → 16 个决策子方案（SP/SE/SS/ST、WP/WE/WS/WT、OP/OE/OS/OT、TP/TE/TS/TT），归纳为 S/W/O/T 四组策略；
- 扩展工具族：**STEEP**（+生态）、**PESTEL**（+环境、法律）、**STEEPLE**（+道德、法律、人口）、SLEPT。

## 常见坑

- 四维列成"大而空的清单"，不与本企业/本行业关联（框架空转）；
- 只罗列现状、不给未来趋势判断；
- 把 PEST 清单直接当结论（它只是 OT 输入，须经"关键因素选择 + 加权"才成判断）；
- 忽略维度间的传导与交叉（政治→经济→社会/技术；环保与法律维度常被漏掉）。
