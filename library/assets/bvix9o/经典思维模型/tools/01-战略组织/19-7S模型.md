# 7S 模型

> 编号 #19 ｜ 篇：一·战略组织 ｜ 源：`TOOL` P0330–P0348 ｜ 同源：`PPT`（P1-48 / P2-50，页码锚点见 index.md）
> 又称：麦肯锡 7S 框架 ｜ 类型：组织诊断/战略执行框架

**一句话**：企业成功需要七个要素相互匹配——**战略、结构、制度（硬件）+ 风格、人员、技能、共同价值观（软件）**；仅"明确战略 + 行动计划"远远不够，软件与硬件同等重要。

## 什么时候用

- **组织诊断与战略执行评估**（七个要素是否协调匹配）；
- 企业转型/变革设计（如服务转型、数字化转型的组织侧设计）；
- 解释"战略正确但执行失败"（多因硬件/软件不匹配）。

**不适用**：纯粹的外部行业分析（→ `波特五力分析`）；单一职能问题。

## 起源

帕斯卡尔与艾索思《日本的管理艺术》（1981，调查日本企业成功原因）→ 与彼得斯、沃特曼（斯坦福管理学硕士、麦肯锡学者；访问 62 家美国大公司、选拔 43 家杰出模范公司，含 IBM/德州仪器/惠普/麦当劳/柯达/杜邦）于 1978 年共同提出 → 出现在《追求卓越》→ 成为麦肯锡最基础的管理咨询工具。

## 七要素（软硬件）

| 类别 | 要素 | 内涵 |
|---|---|---|
| **硬件** | **战略 Strategy** | 为实现目标对途径与手段的总体谋划（前瞻性/整体性/灵活性） |
| | **结构 Structure** | 组织的构成形式（目标、协同、人员、职位的排列组合；为战略实施服务） |
| | **制度 Systems** | 各项制度是企业精神与战略思想的体现（须与战略思想一致） |
| **软件** | **风格 Style** | 管理风格/企业文化（杰出企业：宽严并济——生产开发部门极端自主 + 坚守价值观） |
| | **人员 Staff** | 人力准备（配备、培训、分配、宣导——战略实施的关键） |
| | **技能 Skills** | 员工应掌握的技术与能力（有赖严格、系统的培训） |
| | **共同价值观 Shared Values** | 企业成员共同的价值观念（导向、约束、凝聚、激励、辐射作用） |

**核心提醒**：软件和硬件同样重要——各公司长期忽略的人性（非理性、固执、直觉、喜欢非正式组织等）其实都可以加以管理。

## 硬件要素分析要点（原文）

- **战略**：重要性三方面——**前瞻性**（预测性/指导性/时代性，与时俱进）、**整体性**（系统层面考虑所有相关因素、忽略次要）、**灵活性**（随社会发展适当调整纠偏）；"企业经营已进入战略制胜的时代"；
- **结构**：不同的战略需要不同的组织结构与之对应；案例——**GE** 20 世纪 50 年代末事业部制 → 60 年代销售额大增但行政管理跟不上、多种经营失控 → 70 年代初重新设计为**战略经营单位结构**，解决问题；发现"简单明了"是美国成功企业的组织特点（不到一百个管理人员经营上百亿美元事业）；
- **制度**：防止制度不配套、不协调，避免背离战略的制度；案例——**3M 创新制度**：参加新产品开发者职位薪酬随产品成绩改变（一线工程师 → 产品工程师 → 产品线经理，年销售额 500 万美元时可成为产品线经理）。

## 软件要素分析要点（原文）

- **风格**：杰出企业呈现"既中央集权又地方分权"的宽严并济管理风格；
- **共同价值观**：战略不能只停留在高层——让执行战略的所有人员了解整个战略意图；日本经验：注重沟通领导层与执行层的思想；
- **人员**：IBM"尊重个人"原则（员工不论职位高低都是产生效能的源泉）；麦当劳微笑服务、IBM 销售工程师技术水平、迪斯尼员工乐观；
- **技能**：松下幸之助——每个人须经严格训练才能成为优秀人才（天赋再好，不经训练也无从发挥）。

## 实例锚点：中国电信业转型 7S 分析（原文）

- **战略层面**：从"围绕产品竞争"转向"围绕服务竞争"（固网/移动运营商均无产品差异 → 只能围绕服务）；
- **执行层面**：结构（职能型→产品主导型→前后端型，管理难度大、要求多面手）；制度（公司治理、激励约束机制）；风格（企业文化体现在对利益相关者的关注——中国网通"服务编织未来"的言与行差距、中国移动客服对比为例）；能力（核心竞争能力——IBM 服务/P&G 产品管理/丰田成本控制，中国运营商缺"业界公认做得最好"的方面）；人员（绩效评价/薪酬/培训体系 + 士气态度动机；领导干部的能力与激情）；**最高目标**（远景使命——"微软：让每张桌面上和每个家庭里都有一台电脑"；相对最稳定；没有基础无法建楼）。

## 新 7S 模型（对比 · 达维尼《超优势竞争》）

超强竞争环境下建立"一系列暂时的竞争优势"：
1. **更高的股东满意度**（"股东"广义=客户/顾客/员工；高获利率公司多选"客户满意度"为最重要价值）；
2. **战略预测**（预见/创造未来需求，看出下一个优势在哪、在哪里从事破坏）；
3. **速度**（快速从一个优势转移到另一个优势的能力）；
4. **出其不意的定位**（探寻价值创新道路；佳能 35mm 相机案例）；
5. **改变竞争规则**（精工/卡西欧改写手表规则、斯沃琪案例）；
6. **告示战略意图**（告诫对手 + 在顾客中形成"占位"效应）；
7. **持续不断的战略冲击**（一系列同时和接续的行动夺取胜利、把优势迅速转移到不同市场；小松 vs 凯特彼勒案例）。
- 三部分：破坏的远见（前 2S）+ 破坏的能力（速度、出其不意）+ 破坏的战术（后 3S）；
- **与经典 7S 的区别**：传统 7S 追求组织内**静态战略搭配**；新 7S 强调基于对长期**动态战略互动**的了解，达到破坏现状、创造暂时优势、掌握先机、维持动能——优势不再求持久，而是"一连串短期优势"。
