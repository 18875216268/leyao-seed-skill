# SPACE 矩阵

> 编号 #16 ｜ 篇：一·战略组织 ｜ 源：`TOOL` P0289–P0305
> 全称：Strategic Position and Action Evaluation Matrix（战略地位与行动评价矩阵） ｜ 类型：战略态势选择工具

**一句话**：用**四个维度**（内部：财务优势 FS、竞争优势 CA；外部：环境稳定性 ES、产业优势 IS）打分求向量，判断企业应采取的**进取 / 保守 / 竞争 / 防御**四种战略态势之一。

## 什么时候用

- 分析企业**外部环境 + 应采用的战略组合**（总战略定位）；
- **风险较大的行业**或对风险非常敏感的企业（SPACE 特殊之处：把"财务优势 × 环境稳定性"独立为纵轴、把**风险因素作专门分析**）；
- 多业务企业为每项业务分别定位。

**不适用**：向量落在半径 1 的圆内 → 战略态势模糊（"夹在中间"，无突出战略目标或执行极差）——此时先解决战略清晰度问题。

## 四个维度（各自常用指标）

- **FS 财务优势**（内部）：投资收益、杠杆比率、偿债能力、流动资金、现金流动、退出市场的便利性、业务风险；
- **CA 竞争优势**（内部）：市场份额、产品质量、产品生命周期、用户忠诚度、竞争能力利用率、专有技术知识、对供应商和经销商的**控制**；
- **IS 产业优势**（外部）：增长潜力、盈利能力、财务稳定性、专有技术知识、资源利用、资本密集性、进入市场的便利性、生产效率与产能利用率；
- **ES 环境稳定性**（外部）：技术变化、通货膨胀、需求变化性、竞争产品的价格范围、市场进入壁垒、竞争压力、价格需求弹性。

## 分析步骤（六步）

1. **选变量**：为 FS、CA、ES、IS 各选一组变量；
2. **评分**：FS 与 IS 的变量从 **+1（最差）到 +6（最好）**；ES 与 CA 的变量从 **−1（最好）到 −6（最差）**；
3. **求平均**：各轴变量评分相加 ÷ 变量总数 → FS、CA、IS、ES 各自的平均分；
4. **标数轴**：将四个平均分分别标在各自数轴上；
5. **求交叉点**：**X 轴 = CA + IS**；**Y 轴 = FS + ES**；标出 X、Y 交叉点；
6. **画向量**：从原点到交叉点画一条向量——**向量所在象限即战略类型**（进取/竞争/防御/保守）。

## 四象限战略（向量落点 → 战略）

| 象限 | 态势 | 应对战略 |
|---|---|---|
| **进取**（强 FS + 强 CA） | 财务强、竞争优势强 | 市场渗透、市场开发、产品开发、后向/前向/横向一体化、混合式多角化、集中式多角化 |
| **保守**（稳定不增长行业中 FS 强、无重要 CA） | 有财务实力但缺竞争优势 | 固守基本竞争优势、不过分冒险：市场渗透、市场开发、产品开发、集中化多角化 |
| **竞争**（不稳定行业中 CA 强） | 环境不稳但竞争地位好 | 后向/前向/横向一体化、市场渗透、市场开发、产品开发 |
| **防御**（不稳定行业中竞争地位不利） | 环境差 + 地位弱 | 集中精力克服内部劣势、回避外部威胁：紧缩、剥离、结业清算、集中化多角化 |

## 运用原则（三条）

1. **理论与实际相结合**（方法源于工业企业经验总结，须注意企业自身特点）；
2. **定性与定量相结合**（因素确定是定性过程，可用综合判断法/特尔斐法；但**各因素分值须问卷调查再加权平均**才更接近实际）；
3. **尊重与修订相结合**（尊重分析结论，但指导行动的评价结论可因时因势及时修订）。

## 局限

最大缺陷：向量位于**半径 1 的圆内**时战略态势模糊——公司一般处于"夹在中间"的战略地位（没有突出鲜明的战略目标，或战略目标执行能力极差；可能盲目经营、对外界变化反应迟钝）。

## 案例锚点（原文）

- **吉列公司**：FS +3.2、IS +4.0、CA −2.8、ES −3.75 → 向量 X = +1.2、Y = −0.55 → **竞争象限**（高增长行业中拥有重要竞争优势，新产品上市可借内部优势利用外部机会）；
- **某三级甲等医院**：FS 3.83、ES −2.33、CA −2.14、IS 4.71 → X = 1.50、Y = 2.57 → **进取型战略**（人才/专科特色/沟通扁平化/文化/成本核算六条行动）。
