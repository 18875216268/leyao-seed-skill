# GE 矩阵（九盒矩阵）

> 编号 #4 ｜ 篇：一·战略组织 ｜ 源：`TOOL` P0082–P0101
> 又称：麦肯锡矩阵 / GE / McKinsey Matrix / Business Assessment Array / GE Business Screen ｜ 类型：业务组合决策矩阵

**一句话**：用"**行业吸引力 × 业务实力**"两个**多因素加权**维度构成九象限，为每项业务（SBU）匹配"投资发展 / 维持收获 / 收割放弃"策略——BCG 矩阵的升级版（通用电气与麦肯锡 1970 年代共同开发）。

## 什么时候用

- 多业务公司评估**业务组合**：哪些加投资、哪些维持、哪些退出
- **目标市场选择**：按"市场吸引力 × 企业竞争地位"打分排序
- BCG 矩阵不够用时——BCG 只看两个单因素（市场增长率 × 相对市场份额），GE 用**多因素加权**且增加了中间档

**不适用**：单一业务的战术问题；需要精确财务测算的投资决策（GE 是结构性辅助框架，非计算模型）。

## 核心步骤（绘制 GE 矩阵）

1. **定义因素**：分别选"市场吸引力（外部）"与"竞争实力（内部）"的评估因素（头脑风暴 / 名义群体法；不遗漏重要因素、不纳入微不足道因素、指标不重复）
   - 外部典型：市场规模、成长率、收益率、定价趋势、竞争强度、行业投资风险、进入障碍、差异化机会、需求变动性、市场分割、分销渠道结构、技术发展
   - 内部典型：资产与实力、品牌/营销相对力量、市场份额及其成长、顾客忠诚度、相对成本结构、相对利润率、分销与产能、研发创新记录、质量、融资能力、管理能力
2. **定权重**：按因素重要性赋权（各维权重之和 = 1）
3. **评分**：五级制——外部（1=毫无吸引力 … 5=极有吸引力）；内部（1=极度劣势 … 5=极度优势，选**最强竞对**作参照）
4. **加权求和**：权重 × 评分 → 汇总得两个综合分值
5. **定位落图**：纵轴行业吸引力、横轴业务实力，各分高/中/低三档 → **九象限**；业务用圆表示（**圆面积 ∝ 市场总规模，阴影扇形 ∝ 本企业市占率**）
6. **诠释出策**：左上三角（1/2/4 象限）→ 投资 / 发展；对角线（3/5/7）→ 维持 / 选择性发展；右下三角（6/8/9）→ 收割 / 放弃

## 关键要点

- **与 BCG 的三点进化**：① 市场吸引力（多因素）替代市场成长率；② 竞争实力（多因素）替代相对市场份额；③ 九象限替代四象限——更复杂、也更准确（原文：在灵活性、变量考量、直观性三方面更成熟）；
- **规模-份额可视化**：圆心 = 两维综合分，圆面积 = 市场规模，阴影 = 本企业份额（一图看清"盘子多大、我们占多少、竞争力如何"）；
- **动态化使用**：用箭头标出 SBU 未来移动方向，持续监控变量变化（避免静态快照）；
- 因素与权重**因行业/业务而变**（GE 的灵活性所在，也是主观偏差来源）。

## 常见坑（原文专列）

- **静态分析**：只给某时点快照、不跟踪变化；
- **过度依赖通用战略**：把九象限的通用建议当答案（它只是描述性辅助模型）；
- **SBU / 行业界定错误**：边界微小失误 → 象限定位错误 → 战略错误；
- **过分简化的战略**：被"三档策略"框住、忽略创新投入等更丰富的选项（新兴行业尤甚）；
- 变量选择不准确 / 权重有偏差（工具假设变量可被准确界定），且**忽略回报风险**（只关注投资回报）。

## 关联模型

- 同族上游：`BCG矩阵法`（四象限单因素简化版）；`产品/市场演变矩阵（霍夫矩阵）`——15 格（产品生命周期 5 阶段 × 竞争地位 3 档）
  - 选择判据（原文）：小型多种经营企业多用霍夫矩阵；大型多种经营企业多用 GE 矩阵；特大企业两者并用（GE 看 SBU 间、霍夫看 SBU 内部产品/细分市场）；业务松散选 GE，业务集中于少数关联产品/细分市场选霍夫
- 外部输入：`PEST分析`、`波特五力分析`；配套：`SWOT分析`
