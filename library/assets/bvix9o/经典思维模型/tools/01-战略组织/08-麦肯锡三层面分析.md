# 麦肯锡三层面分析（三层面论）

> 编号 #8 ｜ 篇：一·战略组织 ｜ 源：`TOOL` P0133–P0149
> 又称：三层面论 / 增长三层面 / 增长阶梯（《增长炼金术》） ｜ 类型：增长管理框架

**一句话**：把企业业务按成熟度分三层——**守卫拓展核心业务（第一层）/ 建立即将涌现增长动力的业务（第二层）/ 创造有生命力的未来业务（第三层）**，三层必须**同时并举**管理，才能实现持续增长。

## 什么时候用

- **增长战略规划**（设计一条"连续不断的业务更新管道"）
- 业务组合**健康度诊断**（三层面是否平衡）
- 排查"增长为什么停滞"（对照六种不健康增长模式自查）

**不适用**：单一产品初创期的战术问题；短期经营改善。

## 三个层面（各自管理重点）

| 层 | 业务属性 | 关注指标 | 需要的人 |
|---|---|---|---|
| 一 · 守卫拓展核心业务 | 心脏位置、主要利润与现金流来源 | 利润、现金流、投资回报率、成本与生产率 | 实施者 / 行动者 |
| 二 · 建立新兴业务 | 成长引擎、创业性高成长、需不断追加投资 | 市场份额、新客户数、收入增长、资本投资效率与预期净现值 | 创业者 / 开拓者 |
| 三 · 创造未来业务 | 未来方向与种子、少量尝试/试点/联盟、失败率高 | 待选项目估价、转实际业务的速度、项目数量、回报大小与成功概率 | 先行者 / 探索者 |

**原文表2（三层面增长对照）**：第一层 = 核心业务（关键在最差业绩与盈利能力 → 放松渐进增长、业务下降时管理价值）；第二层 = 新业务（关键在最快增长与资金效率 → 培育种子、集中所需能力、推动建立业务的主动性）；第三层 = 未来可选方案（关键在增长潜能与多情形适应性 → 源选择（想法/关系/资本）与商业观点可行性）。

## 精髓与要点（原文表1 · 六条）

1. **准确诊断**：多数公司缺乏配套齐全的层级建设——先诊断，才能对症下药、给增长项目排序；
2. **奠定基础**：获利性增长赋予活力、营造振奋环境；
3. **阶梯架构**：成功增长四阶段——培育最初选择项目 → 测试业务模式 → 复制和拓展 → 保证获利可能性；
4. **循序渐进**：两大难题（市场不确定性 + 技能/资产/关系差距）→ 不莽撞突进，用一系列经过测算的步骤（每步让现金流行使自身权利、增强综合能力）；
5. **层级管理**：第一层 = 优异管理 + 严格纪律（增强可预见性与责任心）；第二层 = 抢在竞对前用足远见、当机立断加大投资；第三层 = 寻求新机遇、无成规戒律（交谈、研究、沉思、联络同行、联盟、小规模试投）；
6. **三级统筹**：三层并行不悖（不可混同于"短中长期计划"的依次推迟）。

## 六种不健康增长模式（自查）

- **受困**：核心业务不佳 + 更新通道无所作为（受投资者蔑视）
- **失去增长的权利**：过量开发新业务、忽视核心业务（无资金支持增长）
- **失去未来盈利能力**：过度重视核心业务、忽视新兴业务（盈利短期化、危机将现）
- **试图开创新未来**：有前途广阔的二/三层业务，却没有生存力的核心业务（无财力支撑转移）
- **没有开发未来**：第一层收入可观、第二层有希望，但无第三层待开发业务（未来增长停滞）
- **产生观念但没有新业务**：有强核心 + 众多待选项目，却不能转化为实际业务（虚假繁荣）

## 界定三层面平衡的四因素

1. **产业演进步伐**（快速变化产业中，第三层面可能就是两三年内的事；软件业尤其强调二三层）；
2. **不确定程度**（不确定越大 → 选择机会越多、战略灵活性越大）；
3. **管理和财务能力**（财力与管理才能越大，二三层可支撑项目越多；但不能让增长项目削弱第一层）；
4. **股东期望值**（能接受大起大落 → 平衡向后倾斜、支持二三层投资）。

## 运用要点（实操）

- **准备三步**：① 取得"增长的资格"（以优良运营业绩成为强竞争力企业；剥离业绩低劣、难起死回生的业务；使投资者确信增长是好投资）② 做出增长决心（高层承诺、统一认识、选对关键人、提出更高目标、去除企业文化/偏见/系统/激励中的障碍）③ 建立增长平台（能力吐旧纳新、形成竞对难以模仿的能力）；
- **七个自由度**寻增长机遇（层层拓展）：现有产品卖给现有客户 → 现有产品卖给新客户 → 新产品卖给现有客户 → 新产品卖给新客户 → 更好的交付系统 → 新地域 → 收购/联合改变产业结构 → 现有产业领域之外；
- **保护新增长阶梯**：用"作茧"或隐蔽新业务创造小公司氛围（培养紧迫感与责任心、独立运作）；新业务**不奉行第一层面的管理程序与制度**，按新业务目标变通规则；
- **后台支持**：三层人才的**人才管理/业绩管理/业务计划管理**分别设计——第一层（短期业绩奖罚、"不找借口"）；第二层（行动自主权、现金奖金与入股、创业机会）；第三层（心理奖励、认可设想、试验探索自由、职业优惠）。

## 意义

- 评估各层级增长前景，查出**新利润源在"数量与可持续性"之间的差距**；
- 迫使企业在考虑当前经营时同时考虑未来发展；
- 为投资者与雇员提供**一致的沟通说法**（便于讨论项目选择）。

## 关联模型

- 配套：`BCG矩阵法` / `GE矩阵`（现有业务组合分析）、`安索夫矩阵`（增长方向矩阵）
- 同域：产品生命周期（三层面与生命周期阶段呼应）
