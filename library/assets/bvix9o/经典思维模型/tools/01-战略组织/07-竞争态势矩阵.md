# 竞争态势矩阵（CPM）

> 编号 #7 ｜ 篇：一·战略组织 ｜ 源：`TOOL` P0127–P0132
> 全称：Competitive Profile Matrix ｜ 类型：竞争对手分析工具

**一句话**：把行业内**关键战略因素**在"被分析企业 vs 主要竞争对手"之间逐项**加权评分对比**，量化各家战略地位、特定优劣势与相对竞争优势。

## 什么时候用

- **竞争对手分析**：识别主要竞对的具体优势与弱点、机会与风险大小；
- 制定竞争战略前的态势对比（"我们哪项强、哪项是软肋"）；
- 多竞对横向对比（一行一因素、一列一公司）。

**不适用**：需要精确数据支撑的决策（CPM 因素较笼统、不含具体实际数据，且可能集中于内部问题）；单一维度问题。

## 分析步骤

1. 确定行业**关键战略因素**（通常 **6–18 个**；即关键成功因素与竞争优势决定因素）；
2. 定权重（0 = 最不重要 → 1 = 最重要，**总和 = 1**；同一因素在不同行业的权重可能不同）；
3. 筛选关键竞争对手，逐因素评分（**1 最弱 / 2 较弱 / 3 相同 / 4 较强 / 5 最强**；某因素得分最高者拥有该因素上的竞争优势，**分差反映优势大小**）；
   - 注：原文示例表用 1–4 分制（4 强 / 3 次强 / 2 弱 / 1 很弱），正文另述 1–5 分制——**用时须标注口径**；
4. 权重 × 评分 → 各竞争者在各要素上的加权评分值；
5. 加总比较 → 确定竞争能力最强/最弱地位，以及各方优势差异。

## 关键要点

- **数字不是万能的**：总加权分 2.3 vs 2.2 **不能**据此说前者比后者强 10%——表面精确往往带来错觉；CPM 的目的是对信息做有实际意义的吸收与评价、辅助决策；
- 常用因素（除市场份额/价格/财务/质量/忠诚度外）：管理、产品品种、专利优势、生产能力、销售及效率、经验、配送效率、计算优势、研发能力等；
- 因素偏笼统、多为定性判断 → 结论宜与定量工具配合使用。

## 关联模型

- 配套：`EFE矩阵` / `IFE矩阵`（因素可互供）、`SWOT分析`、`波特五力分析`（行业竞争结构）
- 同族：`BCG矩阵法` / `GE矩阵`（业务组合决策——CPM 是竞争维度补充）
