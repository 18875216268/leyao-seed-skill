# 核心竞争力分析

> 编号 #12 ｜ 篇：一·战略组织 ｜ 源：`TOOL` P0210–P0237
> 又称：核心能力（Core Competence · 哈默尔 & 普拉哈拉德 1990《企业核心能力》） ｜ 类型：企业能力分析工具

**一句话**：识别、培育、维护企业**不易被模仿、能带来超额利润的独特能力**——"组织中的累积性学识，特别是关于怎样协调各种生产技能和整合各种技术的学识"。

## 什么时候用

- 确定竞争战略前的能力盘点（"我们真正的优势是什么"）；
- 投资分析（只有发挥核心竞争力的方案才可能获取理想回报）；
- 培育/维护/再造核心能力的规划（构建、巩固、再创新三个阶段）。

**不适用**：短周期战术决策；把"一般竞争力"（某一功能领域的相对优势）误当核心竞争力。

## 核心概念

- **树型理论**：多样化公司像一棵树——树干主枝 = 核心产品、分枝 = 业务单元、叶花果实 = 最终产品、**根 = 核心竞争力**（提供养分、维系生命、稳固树身）；
- **与一般竞争力的区别**：一般竞争力 = 某一方面/领域的相对优势（如营销、品牌、技术竞争力），稳定性差（产品生命周期晚期就减弱）；**核心竞争力 = 核心地位、较长时期内难被超越、生命周期长、稳定性高**，能支撑长期竞争优势与稳定超额利润；
- 二者关系：核心竞争力的形成依赖各种一般竞争力——**构建过程就是以一般竞争力为基础进行整合、上升为"高级"竞争力的过程**。

## 识别标准（四标准 · 达标即核心竞争力）

1. **价值性**（能挖掘机会/避免威胁，实现顾客看重价值：降成本、提质量、提效率、增效用）；
2. **稀缺性**（只为少数现有或潜在竞争者掌握）；
3. **不可替代性**（其他企业没有类似资源或能力）；
4. **难以模仿性**（无法获取或需付出多得多的成本；不像材料设备可在市场购买，难以转移或复制）。

**四标准组合判读（原文表）**：四低 → 无核心竞争力、低于平均回报；价值高其余低 → 无核心竞争力（平均回报）；价值+稀缺高、难模仿低 → 无核心竞争力（暂时竞争优势）；**四项全高 → 形成核心竞争力、持续竞争优势（高于平均回报）**。
**补充判断（后续研究者）**：应当是异质的、数量很少；难以替代；具有较强延展性。

## 识别方法（内部 + 外部）

**内部识别**：
- **价值链分析**（以活动为基础）：真正核心能力 = 关键价值增值活动（能以比竞对更低成本进行）；例：GE 的核心竞争力曾是营销与产品形象，松下在零配件、无线电设备公司在零售——各家的核心增值活动不同；
- **技能分析**（哈默尔与普拉哈拉德本旨）：关键业务技能 → 分解为"部件/子部件" → 找**关键性部件**（对总体业绩影响大者）→ 其诀窍质量决定整体业绩；
- **资产分析**：稳定持续的竞争优势主要来自**无形资产**的专用性投资——市场资产（品牌/忠诚客户/渠道/专营协议）、人力资产（群体技能/创造力/解决问题/领导力）、知识产权资产（技能/商业秘密/版权/专利/商标）、基础结构资产（管理哲学/文化/管理过程/IT 系统/网络/金融关系）；例：可口可乐的核心能力与其说是配方，不如说是"使消费者相信其有秘密配方的能力"；
- **知识分析**：OECD 四类知识——Know-what / Know-why（显性）、Know-how / Know-who（隐性）；企业通过"组织记忆"拥有知识。

**外部识别**：
- **顾客贡献分析**（从外部出发）：顾客愿意付钱购买、愿意多付钱的价值因素是什么——带来核心价值的才是核心能力（如本田：发动机与传动系统"极省油、易发动、易加速"）；
- **竞争差异分析**（波特）：① 分析双方拥有的**战略产业要素**（有吸引力产业的资源与能力）及差异原因；② 分析**市场和资产表现差异**（技术开发速度、产品形象、品牌、声誉、售后、忠诚）——识别**战略性资产**，根植于其中的便是核心能力。

**识别工具**（通用电气"数一数二"战略的重要工具）：资源/能力矩阵——"与竞对相似或易模仿" = 一般必要资源 / 一般基本能力；"比竞对好或不易模仿" = 独一无二的资源 / **核心竞争力**。另有三法：历史性对比（与过去比）、行业标准对比（与同业比）、最优对比（与行业最好比）。

## 构成要素（七个）

战略决策能力 / 研究开发能力 / 不断创新能力（技术+产品+管理创新）/ 组织协调各生产要素有效生产的能力（团队精神、凝聚力、整体协调、资源配置）/ 核心市场营销能力 / 应变能力 / 有特色的企业文化。

## 产生来源（五个创新 + 一个前提）

核心竞争力产生于：**技术创新**（创新是灵魂与最强保障；SONY 例）、**组织创新**（组织机构=企业大厦架构）、**价值创新**（价值观更新是动力）、**管理创新**（培育的保证）、**知识创新**（核心产品更新换代的来源）；**前提**：体制和机制的创新（现代企业制度 + 学习型组织）。

## 表现形态（三种）

- **要素整合力**（有机组合、激活要素效应——不可模仿的整合方式）；
- **要素转化力**（科技→生产技术、资源→产品、品牌→效益）；
- **要素运营力**（对要素的管理、运用与市场运作）——三者分别对应效能、质能、动能创造力。

## 如何构建（三段）

1. **开发**：明确战略意图 → 建立合理战略结构（协调工作、优化配置、设协作组织）→ 战略实施（实时控制）；
2. **维护和巩固**：实施战略管理（专注行业、持续投入——通用/摩托罗拉退出彩电丧失影像技术优势为其反例）；加强组织管理体系建设（专职队伍、定期评价会）；信息体系培育；知识技能的学习积累；
3. **再创新**：增强再研发能力（以核心竞争力为基础、资源共享）；寻找培育新生长点；塑造优秀企业文化与价值观。
- **构建硬件 = 技术创新；构建软件 = 组织创新**（技术提供潜在可能，组织去实现）。

## 案例锚点（原文）

- **华为**：企业家素质（任正非）/ 体制创新（员工内部持股、利益共同体）/ 核心技术（研发投入常年 10%+、2 万余人 40% 为研发）/ 管理创新；
- **沃尔玛**：天天平价（中央采购制 + 供应链信息共享 + 物流成本 + 极致降经营成本）/ 顾客至上（无条件退货、超越期望的服务）/ 高效物流配送系统（62 个配送中心、卫星通信、48 小时到店）/ 管理信息化 / 独特企业文化（员工=合伙人、利润分享、购股计划）。
