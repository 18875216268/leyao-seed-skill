# 利益相关者分析

> 编号 #14 ｜ 篇：一·战略组织 ｜ 源：`TOOL` P0260–P0273
> 又称：Stakeholder Analysis（弗里曼 1984《战略管理：利益相关者分析》） ｜ 类型：战略制定与评价分析工具

**一句话**：识别**所有能影响组织目标实现、或受其影响的团体与个人**，分析他们的利益、权力与态度，平衡各方要求、争取最大合作——把"阻力"变为"推力"。

## 什么时候用

- **战略制定与战略评价**（谁支持、谁阻碍、如何引导）；
- 新产品/项目/服务的**开始与形成阶段**（考虑市场产品或目标重大变化时）；
- 政策/方案的利益分配效应分析（事前预测可行性与可控性、事后评估后果与影响）。

**不适用**：纯技术性问题；无多方利益博弈的场景。

## 概念要点

- stakeholder 源自 1963 年斯坦福研究所（受戏剧"股东"启发）；弗里曼定义：**"任何能影响组织目标的实现或受这种实现影响的团体和个人"**；斯威齐："受组织活动影响并且有能力影响组织活动的人"；
- **主要利益相关者**：所有者/股东、银行及债权人、供应商、购买者/顾客、广告商、管理人员、雇员、工会、竞争对手、政府、管制者、媒体、公众利益群体、政党/宗教群体/军队等；
- **七类要点**：经营者与员工（关心前途/发展机会/福利待遇）；用户（"衣食父母"——需求/偏好/购买动机分析贯穿全程）；供应商（长期互惠互利）；债权人（信心→借款条件）；**竞争者**（要考虑其对己方动作的反应并预判；竞争与合作是永恒主题——可口可乐与百事之争反而共同做大市场）；政府（货币政策/财政/税收直接作用于企业 + 立法约束）；其他（工会、营销中介、公众与社区、院校科研、媒体）。

## 利益相关者四种类型（按合作/威胁可能性）

1. **支持型**（倾向于合作）；
2. **威胁型**（倾向于造成威胁）；
3. **混合型**（合作或威胁的可能性都大）；
4. **边缘型**（两种可能性都不大）。
**处理原则**：妥善处理关系、平衡正当权益、抵制非分要求——任意一方的期望得不到满足，就会从"推动力"变为"破坏力"。

## 分析框架（确定主体 → 分析利益 → 定权重 → 综合评估）

- 步骤：① 确定所有相关利益主体 → ② 用定性/定量方法分析各主体利益分配状况 → ③ 遵循明确的**指导原则或价值取向**确定各主体利益权重 → ④ 得出综合效应，事前预测方案可行性与可控性 / 事后评估后果与影响；
- 分析四问（战略与竞争分析）：
  1. **谁是**组织的利益相关者？（识别一般 + 特定团体；建立利益相关者识别表：利益/需求、影响、重要性、优势、弱点）
  2. 他们的**利害关系**是什么？（可能多重且内部冲突）
  3. 他们带给企业**和竞争对手**的挑战与风险是什么？（评估正面/负面/未知）
  4. 处理这些挑战与机遇的**最佳战略和行动**是什么？

## 两个关键矩阵（定位工具）

**权力/动态性矩阵**（评估新战略过程中何处引入"政治力量"）：
- **D 区（权力大、立场难测）= 最难应付**——能很好地支持或阻碍新战略但观点难预测 → 在建立不可改变的地位前，一定先找方法**测试其态度**；
- **C 区**：可通过管理人员的参与过程影响战略（同意其观点、建立代表其期望的战略）；
- **A / B 区**（权力小）：不等于不重要——其积极支持会**影响权力更大的利益相关者的态度**。

**权力/利益矩阵**（据权力大小与对战略关注程度分类，指明应建立何种关系）：
- **D 区（权力大、利益高）= 主要角色**——制定和发展新战略时**重点考虑其是否接受**；
- **C 区（权力大、利益低）= 最困难者**——总体相对被动，但特定事件会促使其施加影响；若低估其利益、突然重新定位到 D 区阻止新战略，则情况很糟 → 全面考虑其可能反应；
- **B 区（权力小、利益高）**：主要通过**信息**满足其需要——他们是影响更有权力者态度的重要"**联盟**"；
- 需要维持活动阻止相关方自我重新定位（保持 C 区满意程度、减少与 B 区保持联系的过分程度）——用于回答：政治/文化状况是否会阻止采纳特定战略？谁是变化的主要阻止者/推进者？

## 分析目的（五条）

确定基本利益相关者影响力水平；找出主要利益相关者特征；找出他们可能影响干预或受干预影响的方式；了解不同利益相关者之间的关系（含现存与潜在利益冲突、彼此预期）；评估其影响政策过程的能力。

## 案例锚点（原文）

企业网站利益相关者分析：股东（支持参与治理）、员工（内部网/培训）、顾客（LTV 管理、隐私承诺）、商业伙伴（供应链双赢）、所在社区、竞争对手（防范+争取合作）、网络黑客（防守为主）、社会公众与媒体（和平共处、关注态度重大变化）——启发：网站应围绕利益相关者愿望制订方案；不能使全部相关者同时满意（可建若干链接网站分而服务）。

## 关联模型
