# 波特价值链分析模型

> 编号 #13 ｜ 篇：一·战略组织 ｜ 源：`TOOL` P0238–P0259
> 全称：Value Chain（波特 1985《竞争优势》） ｜ 类型：竞争优势/资源分析工具

**一句话**：把企业分解为**一系列价值活动**（基本活动 + 支持性活动），通过分析各活动及其**联系**来确定竞争优势所在（成本领先 or 标新立异），并找到"战略环节"。

## 什么时候用

- 竞争优势定位：**在哪个环节有优势、哪个薄弱**（调整结构、补强薄弱、保持强项）；
- 成本分析与差异化来源分析（逐环节看成本、收入与价值）；
- 识别核心竞争力（关键价值增值活动）；
- 上下游整合决策（自制 vs 外购、渠道策略）。

**不适用**：纯外部行业分析（→ `波特五力分析`）；无流程可分解的极简业务。

## 基本思想

- 企业 = 在设计、生产、销售、发送和辅助产品过程中进行的**种种活动的集合体**；
- **价值** = 买方愿意为企业产品支付的价格；**总价值 = 价值活动 + 利润**（利润 = 总价值 − 各种价值活动的总成本）；
- 价值活动是"物质上和技术上界限分明的各项活动"，是创造对买方有价值产品的基石；
- **与竞争对手价值链的比较**揭示决定竞争优势的差异所在。

## 两类价值活动

**基本活动（5）**：
1. **进料后勤**（内部后勤）：接收、存储、分配——原材料搬运、仓储、库存控制、车辆调度、退货；
2. **生产作业**：投入转最终产品——机械加工、包装、组装、设备维护、检测；
3. **发货后勤**（外部后勤）：集中、存储、发送——产成品库存管理、送货车辆调度；
4. **销售**（市场营销）：广告、促销、销售队伍、渠道建设；
5. **服务**：安装、维修、培训、零部件供应。

**支持性活动（4）**：
1. **采购**（购买各种投入，含研发设备等支持性购买）；
2. **研究与开发**（技术诀窍、程序、工艺设备中的技术——每项活动都含技术成分）；
3. **人力资源管理**（招聘、雇佣、培训、开发、报酬——支撑整个价值链）；
4. **企业基础设施**（总体管理、计划、财务、会计、法律、质量管理——通过整个价值链起作用）。

**活动三类型**（用于区分核心/非核心）：**直接活动**（直接为买方创造价值）/ **间接活动**（使直接活动持续可行）/ **质量保证**（监督、视察、检测、核对、调整、返工）。

## 联系（优势的隐藏来源）

- **内部联系**：活动间的权衡与协调——通过**最优化**（如更严的工艺检查减少服务成本）和**协调一致**（如发货按时要求生产/后勤/服务协同）带来竞争优势；信息系统对从联系中获取优势**至关重要**；管理联系比管理活动本身更复杂——能做好者构成"取之不尽的竞争优势资源"；
- **纵向联系**：与**供应商价值链**和**渠道价值链**的联系——供应商的运输/包装/检验会改变企业成本；渠道（如酒类占最终售价 50%+）的活动可替代或补充企业活动；**与供应商的关系并非零和游戏**（如散装巧克力罐装运输、双方受益）；
- **四个景框**（影响价值链的结构与经济性）：**细分景框**（产品种类与买方）、**纵向景框**（内部开展活动的程度）、**地理景框**（跨地区共用/协调——佳能在日本开发生产、多国销售服务）、**产业景框**（相关产业的业务单元相互关系）；广阔景框利用共享（一支销售队伍卖两个业务单元）但产生共享成本，狭窄景框可为目标细分市场定制。

## 分析步骤（四步 · 循环过程）

1. **识别价值活动**（按技术上和战略上显著差别独立；构建基本价值链；分析各活动相互联系）；
2. **确立活动类型、确定战略环节**（区分直接/间接/质量保证；估算每一活动的价值与成本增量、附加价值 → 找出**战略环节**——真正创造价值、具有竞争优势的关键环节）；
3. **明确一般环节和重点环节**（战略实施使价值链具有动态性 → 战略环节会迁移）；
4. **系统开展整条价值链分析**（随内外环境变化动态调整 → 回到第一步，**循环过程**）。

## 特点 · 意义

- **特点**：以价值为基础；两种活动（基本+辅助）；列示总价值（含利润）；**整体性**（企业价值链处于更广泛的**价值系统**中：上游价值→企业→渠道价值→买方）；**异质性**（不同产业、不同企业价值链不同，反映历史/战略差异，是竞争优势潜在来源）；
- **核心启示**（波特原话）："当你和其他企业竞争时，其实是内部多项活动在进行竞争，而不是某一项活动的竞争"——竞争是整个价值链的竞争；
- **借鉴意义四条**：善于整合上下游资源；处于价值链有利位置须掌握核心优势；让消费者与价值链伙伴都满意；随环境与阶段**转移价值创造重心**（集中到最能产生超额价值的活动上）。

## 局限与应用要点

- **局限**：主要面向企业内部业务流程分析，对**外部产业价值链**涉及少（可能导致资源利用低效率）；
- 分析的关键四问：① 降成本同时维持价值（收入）不变？② 提价值同时保持成本不变？③ 降低工序投入同时保持成本收入不变？④ 能否①②③同时实现？
- 注意问题：决策者与情报人员**通力合作**识别价值活动；价值链具有**针对性 + 动态性**（不同企业/不同时期不同）；避免**时空断层**（不能只阶段性、片面性开展）。

## 案例锚点（原文）

- 某复印机生产企业价值链；**中国石油业价值链**（基本活动：油田建设与生产/油气储运/炼化产品销售/服务；辅助活动：基础设施与人力/技术开发与采购；结论：销售环节将成为价值链关键控制环节；战略联盟与外包取舍）。

## 关联模型

- 扩展：**价值链咨询模型**（决策层/管理层/运营层三层结构）；
- 配套：`核心竞争力分析`（找关键增值活动）、`波特五力分析`、`SWOT分析`
