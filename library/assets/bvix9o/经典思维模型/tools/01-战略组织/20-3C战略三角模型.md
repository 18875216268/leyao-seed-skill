# 3C 战略三角模型

> 编号 #20 ｜ 篇：一·战略组织 ｜ 源：`TOOL` P0349–P0362 ｜ 同源：`PPT`（P1-24 / P2-42，页码锚点见 index.md）
> 又称：战略三角（大前研一《战略家的思想》） ｜ 类型：营销战略管理模型

**一句话**：任何经营战略都必须同时考虑**公司自身（Corporation）+ 顾客（Customer）+ 竞争者（Competition）**三角；战略的本质 = **用自身实力更好地满足顾客需求，并有效区别于竞争对手**。

## 什么时候用

- 营销战略/竞争战略的制定与评估（三角是否整合在同一个战略内）；
- 业务定位诊断（相对竞争优势评估）；
- 战略经营单位（SBU）的定义与检验。

**不适用**：无竞争的市场（"如果没有竞争对手，就没有必要制定战略"——大前研一）；纯执行层问题。

## 核心思想（大前研一）

- "经营战略就是如何实现竞争优势"；"制定战略的唯一目的就是使公司尽可能有效地比竞争对手占有持久的优势"；
- 只有将公司、顾客与竞争者**整合在同一个战略内**，可持续的竞争优势才有可能；
- 战略家的任务：在决定经营成功的关键因素上取得相对竞争优势，同时使**公司力量与某一确定市场的需求相配合**——这种协调总是**相对的**（竞对能提供更优配合，公司就处于不利）；若与顾客打交道的方式与竞对雷同，消费者无以分辨 → 价格战 → 两败俱伤。

## 三角三面（工具内容）

**① 公司战略**（最大化竞争优势——尤其是功能性领域）：
- **选择性和程序化**：不必在所有功能领域领先——在某一核心功能取得决定性优势，其他平庸领域也将被带动提升；
- **自制或购买**（例：劳动力成本上升时组装业务是否转包 → 影响成本结构与需求波动应对能力）；
- **提高成本效益三方式**：a) 比竞对更高效地减少成本费用；b) **简单化、优化选择**（"摘樱桃"——削减受理的订单/提供的产品/执行的功能，成本下降比收入增长更快）；c) 关键功能与其他业务甚至其他公司**共享**。

**② 顾客战略**（顾客是所有战略的基础——首要考虑顾客利益而非股东）：
- **顾客群体划分三法**：a) 按**消费目的**（咖啡：提神 vs 休闲交际）；b) 按**覆盖面**（源于营销成本与市场面平衡研究——营销收益递减 → 优化市场面，依据居住地域或分销渠道）；c) **市场细分后进一步聚焦**（竞对可能采用类似手段 → 市场分割战略功效递减 → 聚焦一小部分核心客户，重审他们真正需要的产品与服务）；
- **消费者组合变化**：人口结构/渠道/规模变化不断改变消费者组合 → 市场划分须因时制宜 → 重新配置企业资源。

**③ 竞争者战略**：
- 从整体上盯住竞对的关键战略要素（研发能力、供应/制造/销售/服务资源、其他利润来源），并**设身处地理解对方战略规划者的地位与假设**；
- 差异化实现路径（在采购/设计/制造/销售/服务等功能领域）：
  - **品牌形象差异化**（索尼、本田销售领先源于广告投入更大且组织更谨慎细致；"产品功能与分销模式趋同时，品牌形象也许是差异化的唯一源泉"；但瑞士腕表业的不幸提示品牌形象的危险性——须长期有效监控）；
  - **利润和成本结构差异化**（新产品销售与附加服务追求最大利润；在固定成本与变动成本配置比率上做文章——**固定成本低的公司在市场低迷时能轻易调低价格**，扩大份额，对高固定成本企业杀伤力大）；
  - **轻量级拳击战术**（中小企业别在广告/研发等固定成本领域与巨头硬拼；把市场激励计划建立在**渐进比例**而非绝对数值上——经销商为获取额外回报加大销售，而市场三巨头无法提供这样的额外回报）；
  - **Hito-Kane-Mono（人、财、物）平衡**：三者达成平衡、无冗余浪费才能实现流线型管理（现金存量超出需求=浪费；管理人太多而资金不足=浪费）；**配置顺序：物 → 人 → 财**——先依现有"物"（厂房设备/技术工艺/流程）配置"人"，一旦"人"产生远见卓识的商业构想，"物"和"财"再按需求配置到具体项目。

## 相关因素清单（11 问）

- **公司**：有什么资源？组织形式？生产系统？经验曲线？
- **竞争者**：市场占有率？市场地位？经营策略？有无成本优势？还有什么市场优势？
- **客户**：市场如何分割？购买标准是什么？

## 分析步骤与路径

- **步骤**（顺序重要）：**顾客第一 → 企业第二 → 竞争及合作对象第三**——① 在对顾客有充分认识的前提下考虑企业自身设计；② 再把目光转向其他经营者（竞对与潜在伙伴等同看待），凡对己有积极意义的部分虚心吸取（最该学的是"观察市场角度的灵活性"）。
- **分析路径四问**：**和谁竞争**（现在主要竞对/潜在竞对/其近期活动/未来计划）；**在哪竞争**（全球/全国份额分配、竞对市场在哪、细分市场划分依据、各层级优势）；**靠什么竞争**（行业核心能力的体现、各主体是否具备、最强者的优势在哪、他人能否形成）；**如何竞争**（产品与市场定位、业绩来源、未来定位与优势发挥/不足弥补）。

## 应用影响（三条）

- **战略经营单位（SBU）**：须能理解三个基本元素并代表其做决策；定义测试三问——① 是否充分理解顾客需求（细分后不同需求都得到满足）？② 经营单位是否已配备得能轻易满足各种需求？③ 竞争者是否有更优市场策略？——若不能有效竞争，应重新定位；
- **业务的自由**：SBU 须① 说明顾客需求的市场总容量；② 包含所有决定性功能（采购/设计/生产/营销/分配/服务）；③ 理解竞对所有关键方面；
- **使公司适应市场变化**：成功市场策略 = 能促使公司在满足顾客需求方面**比竞对做得更好**的策略。

## 案例锚点（原文）

邮政邮件业务 3C 分析（公司侧：公共服务 + 收益性目标、宅急送广域性、Hub & Spoke 运输网；客户侧：主客户从个人变企业、包裹服务满意度下降、优先宅急送；竞争侧：国内宅急送企业成长与新增、外国邮政全球化战略与民营化）。
