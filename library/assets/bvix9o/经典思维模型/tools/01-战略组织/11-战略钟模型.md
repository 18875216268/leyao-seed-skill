# 战略钟模型

> 编号 #11 ｜ 篇：一·战略组织 ｜ 源：`TOOL` P0200–P0209
> 又称：Bowman's Strategy Clock（克利夫·鲍曼） ｜ 类型：竞争战略选择工具

**一句话**：综合波特的通用战略，把"**价格 × 可感知附加值**"画成 8 条射线（似钟形）——8 条战略路径 = 5 类可行 + 3 类失败，用于选择与评估竞争战略。

## 什么时候用

- **竞争战略选择**（定价与附加值如何组合）；
- 评估企业当前战略路径的风险（是否落在失败路径）；
- 行业 / 对手的战略定位对比。

**不适用**：非市场竞争场景；对顾客价值认知不清时。

## 两个基本概念（先弄清）

- **价格**（纵轴分界：高于 / 低于一般水平）；
- **理解附加值（perceived added value）**：假设各家产品适用性类似，顾客选某家的原因 = ① 价格更低 或 ② 顾客估计其价值更高。

## 八条路径（5 类 · 8 种）

**① 基于价格的战略**
- **路径 1 低价 / 低附加值**（"便宜但货不好"）≈ 成本领先 + 集中（**集中的低成本战略**）——看似无吸引力但可成功：存在价格敏感细分市场（买不起或不愿买更好质量），该市场反过来赋予其生命力；
- **路径 2 低价**（质量不变、价格更低）≈ 成本领先——基础是**竞对难以模仿的低成本优势**（否则易被模仿 → 价格战 → 行业利润萎缩）；可专注竞对认为没有竞争力的市场以避免过度竞争。

**② 混合战略**
- **路径 3 混合**（可感知附加值 + 低价格）= 成本领先 + 差异化结合——成功两点：① 企业整体成本低、能维持较高利润率；② 成功进入市场后必须有**明确的后续战略**；优点：销量远超竞对则收入仍可观；常用于进入已有竞争者的市场。

**③ 差异化战略（广义）**
- **路径 4 差异化**（相同或略高价格 + 可感受附加值）≈ 波特差异化——有形（外观/质量/功能独特性）+ 无形（服务质量/客户服务/品牌文化）；四要点：① 以核心能力为基础、竞对难以模仿；② 识别真正的顾客、时刻关注需求偏好变化（传统经验/想当然会致失败）；③ 正确分析竞对（广范围竞争→关注普遍接受的差异化基础；细分市场竞争→集中差异化；警惕全球化下地理扩张削弱差异化基础）；④ **动态差异化**（需求在变 + 竞对会模仿 → 不断强化并适时改变）；
- **路径 5 集中差异化**（特别高价格 + 更高可感知价值）——特定细分市场内经营；需在"跨市场广泛差异化"与"集中经营"间抉择；适用于有特殊需求的细分市场、暂无竞对进入、企业实力一般。

**④ 失败的战略（路径 6/7/8）**
- **路径 6 提价 + 标准价值**（提高价格但不提供可感知附加值）——与成本领先相悖，买方市场下不可维持（除非受法律保护或强经济壁垒阻止新竞争者）；
- **路径 7 提价 + 降值**——比路径 6 更危险，与成本领先和差异化都背道而驰（将企业推向失败与灭亡）；
- **路径 8 标准价格 + 标准价值**（保持价格同时降低价值）——对差异化战略的否定，也非常危险；
- 采用 6/7/8 的企业一般是**垄断经营地位**（前提是市场无竞对提供类似产品），否则竞对很容易夺得份额。

## 战略与风险对照（原文表）

| 战略 | 风险 / 说明 |
|---|---|
| 1 低价/低附加值 | 可能占据特定细分市场（如 ALDI 廉价超市） |
| 2 低价格 | 有价格战风险；需做成本领先者 |
| 3 混合 | 低成本状况；对低价格和差别化的再投资 |
| 4 差别化 | (a) 没有溢价：用户接受附加价值、企业获份额利益；(b) 有溢价：所得附加值足以承受溢价 |
| 5 集中差别化 | 对特定细分市场均有附加值、保证有溢价 |
| 6 提价/标准价值 | 若竞争者不跟随则有高收入；有丧失市场占有率的风险 |
| 7 提价降值 | 只有垄断情况下可行 |
| 8 标准价格/标准价值 | 丧失市场占有率 |

## 分析步骤（五步）

1. 清楚认识顾客的需要及价值取向（可限定细分市场或更宽范围）；
2. 考虑哪条路径最适合组织；
3. 用**完全不同于竞争者的活动组合**满足顾客需要，并在各活动之间建立一系列联系；
4. 通过这些重要活动及其成本优势与经验，提高效率或降低成本；
5. 保证组织战略方向和方法与一般战略一致。

## 关联模型
