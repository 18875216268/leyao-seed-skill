# PIMS 分析法

> 编号 #15 ｜ 篇：一·战略组织 ｜ 源：`TOOL` P0274–P0288
> 全称：Profit Impact of Market Strategies（市场战略对利润的影响）；又称：战略与绩效分析 / PIMS 数据库分析 ｜ 类型：战略评价与基准分析工具

**一句话**：用**跨企业战略数据库**（数千个 SBU 的财务与战略信息）做回归分析，找出"什么样的竞争环境 + 什么样的战略 → 什么样的经济效果"的**市场法则**，据此校正自身竞争优势与战略。

## 什么时候用

- **战略评价与基准对比**：先取行业/市场平均利润及影响因素，再把本企业状况与之比较，供资源分配决策；
- 判断"给定经营条件下，什么利润水平才算正常/可接受"；
- 评估战略调整（提高份额？加投资？上质量？）对 ROI 与现金流的预期影响。

**不适用**：无行业基准数据可用时（PIMS 的价值来自跨企业数据库）；快节奏战术决策。

## 背景（可信度来源）

1960 年 GE 内部启动（研究市场份额对业绩的影响）→ 1972 年哈佛商学院与市场科学研究所加入、数据库扩展到多公司 → 1975 年成立"战略规划研究所"持续运营；200+ 公司参与（多为财富 500）；数据库曾有近 3000 个战略业务单位（SBU）的财务与战略信息——被誉"世界上最广泛的战略信息数据库"。

## 数据五类（每 SBU 100+ 项）

① 经营单位环境特性（长/短期市场增长率、售价通胀率、顾客数量规模、购买频率与数量）；② 竞争地位（市场占有率/相对占有率、相对质量/价格、职工报酬水平、营销努力、市场细分模式、新产品开发频度）；③ 生产过程结构（投资强度、纵向一体化程度、产能利用、设备生产率、劳动生产率、库存水平）；④ 可支配预算分配（R&D/广告促销/销售开支）；⑤ 业绩（投资收益率、现金流量）。

## 九个关键战略因素（对 ROI 与现金流的影响方向 · 核心结论）

1. **投资强度**（投资额/销售额，更准确是投资额/附加价值）：越高 → ROI 与现金流越低；资本密集单位可缓解：集中细分市场 / 扩大产品线宽度 / 提高设备利用率 / 开发柔性设备 / 租赁而非购买；
2. **劳动生产率**（人均附加价值）：正影响（越高业绩越好）；
3. **市场竞争地位**（相对市场占有率）：正影响（规模经济 + 经验效益 + 对供应商/购买商议价能力）；**高份额 + 低投资强度 = 现金充沛；低份额 + 高投资强度 = 现金枯竭**；
4. **市场增长率**：利润总额↑、对 ROI 无影响、对现金流**不利**（需资金维持地位）——印证 `BCG矩阵法`：金牛产现金最多，狗类和幼童类现金为负；
5. **产品或服务质量**：与业绩正相关；且质量与市场占有率**强正相关、互相加强**（高份额 + 高质量 = 最强竞争地位）；
6. **革新或差异化**：**视竞争地位而定**——地位强 → 研发/新品/营销强化有利；地位弱 → 同样措施反而对利润不利；
7. **纵向一体化**：成熟期或稳定市场提高一体化 → 有利；迅速增长或衰退期提高 → 不利；
8. **成本因素**：影响复杂——取决于企业能否在内部吸收成本上升或转嫁给客户；
9. **现时的战略努力方向**：改变任一因素，会以该因素对业绩影响的**相反方向**作用于未来（提高市占率会消耗现金）。

**另一个重要发现**：产品的特点（钢铁/机电/化工）与业绩**没有关系**——起决定作用的是经营单位的特点（地位、投资强度等）。

## 应用：两套衡量标准（原文表格）

- **市场特性衡量标准**：市场增长率（实际市场容量平均变动率）、市场演进阶段（寿命/生命周期）、通货膨胀率（售价平均变动率）、产品/服务标准化程度、供应商集中程度（3 家最大供应商采购占比）、产品对顾客的重要性（交易规模/占顾客总购物比）、行业进出口占比、雇员工会化程度；
- **竞争地位衡量标准**（地位标准 + 变化标准成对）：竞争地位（MS 及排序 / 变动）、产品服务策略（相对质量指数、新品销售占比 / 变动）、定价策略（相对价格指数 / 变动）、营销计划（营销费用占销售额比 / 变动）、投资策略（投资/增值、设备净值占比、劳动生产率、存货占比 / 各项变动）、垂直一体化（增值/销售额、相对一体化 / 变动）、研究与开发（R&D 占销售额比 / 变动）。

## 关联模型

- 验证/呼应：`BCG矩阵法`（份额-增长-现金流，PIMS 数据是其支撑）、`GE矩阵`（多因素）
- 配套：`EFE矩阵`/`IFE矩阵`（内外因素评分）、`竞争态势矩阵`（相对地位）
