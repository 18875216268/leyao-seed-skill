# IE 矩阵（内部-外部矩阵）

> 编号 #6 ｜ 篇：一·战略组织 ｜ 源：`TOOL` P0116–P0126
> 全称：Internal-External Matrix ｜ 类型：业务组合决策矩阵（配套 EFE / IFE 评价矩阵）

**一句话**：在 GE 矩阵基础上发展——横轴 **IFE 总加权分**（企业内部强弱）、纵轴 **EFE 总加权分**（外部环境高低），各分三档成 9 方格，再划三战略区间（增长建立 / 坚持保持 / 收获剥离）。

## 什么时候用

- 多业务公司**组合分析**（也可评价**预期发展业务**，确定未来业务组合）
- 需要把"外部因素评价（EFE）+ 内部因素评价（IFE）"的量化总分**直接落到战略区间**时
- **动态分析**：大公司常同时建 BCG 与 IE 矩阵——先反映现时情况，再用预测/计划值矩阵反映未来（"之前-之后"式分析，预演战略决策对业务组合的影响）

**不适用**：单一业务；尚未做 EFE/IFE 评分时（须先做两矩阵）。

## 矩阵结构

- 横轴 **IFE 总加权评分**（内部）：1.0–1.99 劣势地位 / 2.0–2.99 中等 / 3.0–4.0 优势地位；
- 纵轴 **EFE 总加权评分**（外部）：1.0–1.99 面临较严重外部威胁 / 2.0–2.99 中等 / 3.0–3.99 能较好地把外部威胁不利影响减到最小；
- 三区间与策略：
  - **1 / 2 / 4（增长建立）**：加强型（市场渗透 / 市场开发 / 产品开发）或一体化（前向 / 后向 / 横向）或投资扩展；
  - **3 / 5 / 7（坚持保持）**：选择 / 盈利战略（如市场渗透、产品开发）；
  - **6 / 8 / 9（收获剥离）**：收获 / 放弃；
- 竞争力强的企业应使业务组合处于矩阵**第 1 格或其附近**。

## 配套工具 ①：EFE 矩阵（外部因素评价）

- 用途：归纳评价经济、社会、文化、人口、环境、政治、政府、法律、技术、竞争等信息；
- 步骤：① 列 **10–20 个外部关键因素**（先机会后威胁；尽量具体，用百分比/比率/对比数字）→ ② 赋权（0.0–1.0，总和 = 1；机会常高于威胁，但威胁特别严重时也可高权重）→ ③ 按**现行战略**对因素的有效反应评分（1–4：4 很好 / 3 超平均 / 2 平均 / 1 很差）→ ④ 权重 × 评分 → ⑤ 加总；
- 判读：总分 1.0–4.0、平均 2.5；**高于 2.5 = 企业能对外部影响因素做出反应**；4.0 = 出色利用机会并把威胁降到最小；1.0 = 不能利用机会或回避威胁；
- 记忆点：**权重以产业为基准，评分以公司为基准**。

## 配套工具 ②：IFE 矩阵（内部因素评价）

- 用途：总结评价各职能领域的优势与弱点，为确定领域间关系提供基础；
- 步骤：① 列 **10–20 个内部关键因素**（先优势后弱点；尽量用百分比/比率/对比数字）→ ② 赋权（总和 = 1；对绩效影响大的因素权重高——**无论它是优势还是弱点**）→ ③ 评分（1 重要弱点 / 2 次要弱点 / 3 次要优势 / 4 重要优势；规则：**优势必须 3–4、弱点必须 1–2**）→ ④ 权重 × 评分 → ⑤ 加总；
- 判读：平均 2.5；大大低于 2.5 = 内部弱势；大大高于 = 内部强势。

## 与 BCG 的联系与区别（原文）

- **联系**：都用矩阵对业务分类；都从内部 + 外部两方面评价；都是组合矩阵分析法（可定组合战略与各业务战略）；
- **区别**：IE 从**综合角度**分析（需要更多内部/外部信息）；轴线划分不同——BCG 分高低两档（4 象限），IE 分高中低三档（9 象限 → 3 战略区间）。

## 关联模型

- 同族：`GE矩阵`（IE 由其发展而来）、`BCG矩阵法`、`定向政策矩阵`
- 配套输入：`SWOT分析`、`PEST分析`、`价值链分析`（因素评价素材）
