# 职业锚

> 编号 #49 ｜ 篇：三·人力资源 ｜ 源：`TOOL` P0870–P0891
> 又称：职业系留点（埃德加·施恩 Edgar Schein，MIT 斯隆商学院） ｜ 类型：职业生涯规划工具

**一句话**：当一个人不得不做出选择时**无论如何都不会放弃**的那种职业中至关重要的东西或价值观——职业锚 = 自我意向的习得部分，强调**个人能力、动机和价值观三方面的相互作用与整合**（职业测评运用最广泛、最有效的工具之一）。

## 什么时候用

- 职业生涯规划与发展（国外许多大公司作为员工职业发展规划的主要参考）；
- 组织激励设计（按职业锚类型差异化激励）；
- 外派/转岗/晋升决策（判断什么机会对某人是"真机会"）。

**不适用**：没有工作经验、不了解具体工作、职业锚尚未形成或不清晰的员工。

## 来源与定义

- 施恩领导的专门研究小组（MIT 斯隆商学院）：1961-1963 年 **44 名 MBA 毕业生**自愿接受**长达 12 年**的职业生涯研究（1973 年返回面谈调查）→ 1978 年《职业动力论》率先勾勒个人与组织相互作用的基本图式；
- 施恩："设计这个概念是为了解释，当我们在更多的生活经验的基础上发展了更深入的自我洞察时，我们的生命中成长的更加稳定的部分"；
- 定义：**职业锚（职业系留点）**——锚是使船只停泊定位用的铁制器具；职业锚"实际就是人们选择和发展自己的职业时所围绕的中心"——当一个人不得不做出选择时，他**无论如何都不会放弃**的职业中的那种至关重要的东西或价值观；由习得的实际工作经验所决定，与经验中自省的动机、价值观、才干相符合，达到自我满足和补偿的一种稳定的职业定位；
- **发展**：最初五种（自主型/创业型/管理能力型/技术职能型/安全型）→ 学者加入研究又发现三种（安全稳定型/生活型/服务型）→ 90 年代施恩改为**八种类型**并推出测试量表——八种可概括所有职业锚类型。

## 四个特征

① **产生于职业生涯早期或转型初期**（以工作经验为基础——只有取得一定工作经验后，方能选定稳定的长期职业贡献区；某种程度上是实际工作经验决定的，不是完全取决于才干和动机）；
② **强调能力、动机和价值观三方面的相互作用与整合**（不是只重视某一方面——人们不断重新审视自我、明确需要与价值观、改善增强才干 → 整合 → 自我满足和补偿）；
③ **不可能根据各种测试提前预测**（是个人同工作环境互动作用的产物——由于实际工作的偶然性，只有在工作实践中经过多次确认和强化才能找到职业定位）；
④ **不是固定不变的**（随职业发展 + 生物生命周期/社会生命周期/家庭生命周期成长变化，中后期可能重新选定——是不断探索过程中产生的**动态结果**）。

## 八种类型与激励重点

| 类型 | 核心特征 | 激励重点 |
|---|---|---|
| **技术／职能型** | 成长在于技术职能区技能不断提高；成功取决于该区专家的肯定认可、承担更多挑战性作业；力求向上但只坚持在能力区内提升；**一般不喜欢全面管理工作**（强烈抵制）、不拒绝某方面职能管理 | 加大工作范围/给资源与责任/经费技术支持/委员会或专家组方式参与高层决策/更多培训/赞助休假/鼓励专业会议；薪资反映技术专业水平；晋升着重**技术或专业等级**而非职位；当成专家、要本专业领域专家的肯定 |
| **管理型** | 愿担负**单纯管理责任且越大越好**；倾心全面管理、掌握更大权力；以提升、等级和收入为成功标准；具分析+人际关系+感情能力的特别合成；对组织依赖（"高水平组织人"） | 给予**更大管理责任的职位** + 上司认可（地位象征：头衔/大办公室/轿车特权有用）；"金手铐"作用显著（对加薪/奖金/股票期权非常在意）；靠结果和绩效晋升 |
| **自主／独立型** | 以自主为**第一需要**、最大限度摆脱组织约束；宁愿放弃提升或工作扩展机会也不放弃自由独立；在工作中愉快、有职业认同感、把成果与自己的努力相连；与其他锚有交叉（自主需要更强烈） | 最喜欢**直接的表扬与认可**——勋章/证明书/推荐信/奖品/证书比晋升头衔甚至金钱更具吸引力；厌恶"金手铐"式薪酬；晋升必须意味着更大自主权 |
| **安全／稳定型** | 追求职业稳定安全（职业安全 + 情感安全稳定两类）；按组织要求行事（维持工作安全、体面收入、有效退休方案、津贴）；更易接受组织；一般不愿离开给定组织、仰赖组织识别其需要与能力 | 安排安全、稳定、有保障的职位；**直接加薪、改善收益比内在激励更有效**；基于工作年限的、**可预测的稳定薪水增长** + 保险与养老金方案；承诺"忠诚 + 稳定绩效 → 稳定连续雇佣"起积极作用 |
| **创造／创业型** | 要求自主权、管理能力并能施展才干，但**主要动机是创造**（不是自主权）；强大驱动力是发明创造、奠基立业、建立完全属于自己的杰作；坚忍不拔百折不回 | 金钱是"完成了某件大事业的有形标志"；公开表彰；最渴望的奖励 = **不断打造属于自己的事业的机会**；鼓励创新、相信他是天才、赋予新挑战、分享成功经验获得公众认可 |
| **服务型** | 一直追寻机会帮助他人、改善安全（如通过新产品消除疾病）——**变换公司也不接受不允许实现这种价值的工作变换或提升** | 提供为心中理想打拼的机会；钱不是根本——**基于贡献的、公平的、方式简单的薪酬**；认可贡献、给更多权力自由体现价值；上级同事的认可支持 |
| **纯挑战型** | 参加工作的原因是工作允许**战胜各种不可能**——新奇、变化、困难是终极目标；喜欢解决看似无解的问题、战胜强硬对手；容易的事马上令其厌烦 | 分配**更有挑战性的任务**；高目标 + 设置竞争 + 晋升到更大挑战岗位；**与工作难度、挑战性和完成情况相匹配的薪酬体系** |
| **生活型** | 希望将生活的各个主要方面**整合为一个整体**（个人/家庭/职业平衡）；需要足够弹性的工作环境；可牺牲职业某些方面（如放弃提升）换取平衡；成功定义比职业成功更广泛 | **一张弹性的工作安排表是最有效的奖励**；充裕闲暇、弹性工作空间、尊重平衡需要；表现出色时给"最大化非工作时间的机会"——奖励自行支配余下时间 |

**启示**：辨识员工职业锚的目的是为不同锚型的人**疏通能实现其职业目标的渠道**、进行**不同职业性质的激励**——使其更有满足感、愉快高效工作。

## 职业锚的功能（四条）

① **使组织获得正确的反馈**（职业锚清楚反映员工的职业追求与抱负——是员工经搜索所确定的长期职业贡献区）；② **为员工设置可行有效的职业渠道**（针对性地设置可行、有效、顺畅的职业渠道）；③ **增长员工工作经验**（长期从事某项职业中增长经验 + 技能增强 → 直接产生效率效益）；④ **奠定中后期工作的基础**（抛锚过程 = 自我认知过程 = 职业工作与自我观相结合的过程）。

## 开发步骤（组织视角三步）

① **提供建立职业锚的机会**（对新员工大胆使用、敢于分配**挑战性工作**——"独立完成某一具体工作任务/主持某项工作成为临时负责人/担当重要关键任务/承担技术性较强工作"；初次工作的挑战性使员工容易热爱职业）；② **为员工寻觅适合的职位**（帮助正确了解认识评价自我 → 用于职业指导；自我评价**六方法**（哈佛商学院研究）：写自传/考察志趣/研究价值观/24 小时日记/**与别人面谈**/生活方式描述 → 归纳一般结论 → 形成全面客观真实的自我评价）；③ **为员工提供建立职业锚的渠道**（五工作：对每个员工职业综合把握/职业岗位梳理与广泛工作分析确定职业需求/员工个人目标与组织需求相匹配/为每个员工设置职业锚渠道并制定实施计划/实施计划方案）。

**如何开发和管理（补充）**：让每位员工通过测试预测明确职业锚很困难（认识需长期实践、环境变化改变需求、测定方法科学性难掌握）→ 由企业提供机会条件来帮助员工明确：① 注重培育**积极优秀的企业文化**（文化力引导职业锚朝健康方向发展）；② **建立岗位描述书**（岗位职责、所需知识结构、能力结构、相关知识——使员工了解发展机会与必备条件；柔性化组织中加岗位负责人和岗位起始日期保证效果）。

## 职业锚在经理人职业管理中的作用（四条）

① **识别职业抱负模式和职业成功标准**——经理人职业锚**动态演进**：早期职业锚为**技术/功能能力型**（专业知识是走向管理岗位的基础）→ 职业中期进入**双重职业锚阶段**（技术/功能 + 管理能力型兼备，成长为领域内技术专家并承担专业管理工作）→ **企业家 = 经理人的高级阶段、职业锚演变为创造型**（承担富有挑战性的非程序化工作、创新者和经济带头人）；注意事项：尽可能快确定职业锚/准确定位/遵循阶段论特点及时调整；
② **增强职业能力和工作经验**（经理人九类职业能力：人际导向能力/元能力（细节敏感、学习、解决问题、应变、自我发展）/任务导向能力（谈判协商、决策、解决冲突、收集信息、容忍不确定性）/工作技能类/知识类/品质类/情感类/性格类/逻辑能力）；
③ **奠定职业中后期发展的基础**（早期职业锚是中后期职业工作的基础；正反馈 → 成就感 → 职业锚更稳定 → 良性发展轨道）；
④ **实现经理人和组织的共同发展**（组织获得正确信息反馈 → 设置合理顺畅的职业通道与职业阶梯；经理人职业需要得到满足 → 深化组织情感认同与职业归属）。

## 案例锚点（原文 · 某公司外派工作职业锚分析）

八位 IT 工程师对应八种职业锚的接受逻辑：A（技术型——外派若支持技能提高就适合）/ B（管理型——外派作为通向管理岗位的铺路石）/ C（自主型——新工作若保留自主权就接受）/ D（安全稳定型——前提是"确保其安全不会受到危害"）/ E（创造型——若可进一步开发创造力毫不犹豫接受）/ F（服务型——若允许继续帮助他人就接受）/ J（纯挑战型——外派能提供足以吸引她的挑战）/ H（生活型——"能够在家乡工作对其意义巨大"，除非环境满意度不低于当前才考虑）。
**结论**："管理型"与"纯挑战型"的员工最有可能在外派工作中发挥所长；"安全稳定型"和"生活型"的员工则未必适合外派工作的挑战。
