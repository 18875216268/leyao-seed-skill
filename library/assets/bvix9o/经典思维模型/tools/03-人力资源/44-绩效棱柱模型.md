# 绩效棱柱模型

> 编号 #44 ｜ 篇：三·人力资源 ｜ 源：`TOOL` P0784–P0796
> 全称：Performance Prism（安迪·尼利、克里斯·亚当斯与安达信，2002） ｜ 类型：绩效测量与管理框架

**一句话**：以**利益相关者为中心**的三维绩效框架——棱柱五个面 = 五个有内在因果关系的绩效要素：**利益相关者的满意 → 组织战略 → 业务流程 → 组织能力 → 利益相关者的贡献**（第五面回馈第一面）。

## 什么时候用

- 绩效评价体系设计（比 BSC 更全面地覆盖利益相关者）；
- 战略与绩效的整合梳理（战略、流程、能力是否对齐）；
- 多利益相关者关系管理（投资者/顾客/员工/供应商/监管/社区）。

**不适用**：只想考核单一维度（如纯财务）的场景；无法识别关键利益相关者的小组织（先做利益相关者分析）。

## 概念与逻辑

- 英国克兰菲尔德学院教授安迪·尼利与克里斯·亚当斯、安达信咨询公司 2002 年《绩效棱柱——测量和管理企业的成功方法》联合开发；
- **与 BSC 的区别**：BSC 只关系一两个利益相关主体（股东、顾客）；绩效棱柱**关心所有重要的利益相关主体**——在从他们那里得到**贡献**的同时，还关注他们的**满意**（创新之处：既强调利益相关主体的取向、又测量其对组织所做的贡献）；
- **建立逻辑**：公司要长远成功 → 首先清楚知道重要利益相关方**是谁、想得到什么** → 据此制定战略**将价值传递给相关方** → 执行战略需要能有效**发出和执行命令的过程** → 过程中必须有**能力**保证流程顺畅 → 最后必须**获取利益相关方的贡献**，才能保持这种能力。

## 三个基本前提（支撑整个框架）

① 组织要长期生存繁荣，把注意力仅放在一两个利益相关者（股东和顾客）身上是**不可取的甚至不可行的**；
② 组织若想将真正价值传送给股东，其**战略、流程及能力必须整合**；
③ 组织与其利益相关者的关系是**互惠的**——利益相关者期望得到利益，也就应为组织贡献自己的力量。

## 五个关键要素（五问因果链）

| 要素 | 关键问题 |
|---|---|
| **利益相关者的满意** | 谁是我们的主要利益相关者？他们的愿望和要求是什么？ |
| **利益相关者的贡献** | 我们要从利益相关者那里获得什么？ |
| **战略** | 用什么战略满足利益相关者需求、同时满足我们自己的要求？ |
| **流程** | 需要什么流程才能执行战略？ |
| **能力** | 需要什么能力来运作这些流程（人员、技术、经验和基础组织的结合体）？ |

**微妙而重要的折射**：利益相关者对公司的要求 ⇄ 公司对利益相关者的要求——"**交换品是什么？**"（通常：来自投资者的资金和信用、来自顾客的忠诚和利润、来自员工的想法和技术、来自供应商的原料和服务）。

## 计量指标设置

- 按**利益相关者**设置（一般分：投资者 / 顾客和中间商 / 供应商 / 雇员 / 定规者 / 社区，各组可自定义）；每个利益相关者从"**满意 + 贡献**"两侧，到**战略、流程、能力**逐层设置指标；
- **战略层面计量的四重含义**：① 有恰当指标/标准追踪战略是否执行；② 指标能强有力沟通战略；③ 指标能鼓舞激励战略实施（通过管理者补偿）；④ 计量数据能被分析以评价战略或预算执行效果；
- **能力定义**：由人力资源、技术水平、制度建设、公司文化、知识资产及物质基础等共同体现的"公司为其利益相关方创造价值的能力"（竞争性标杆制度有助发现能力差距）；
- **第一面（满意）示例**：股东要求回报和成长性；债权人要求利息与本金及时足额偿付；员工需要技能培训、关心、发展和薪金；客户强调快捷优质价廉；供应商注重信用协调盈利；监管方要求合法真实公平；
- **第五面（贡献）示例**：股东债权人持续提供资金支持；员工发挥技能创造力、培育团队理念；客户协调互信沟通提供现金流入；供应商及时递送优质价格有竞争力的产品；监管方制定"游戏"规则、提供建议；
- **满意层面指标示例**：股东（投资回报率、股价、经济附加值、市盈率、净资产收益率）/ 债权人（资产负债率、流动比率、速动比率、利息保障倍数）/ 雇员（满意度）/ 客户（满意度、投诉率）/ 合作伙伴（投诉次数）/ 监管方（违规事件次数及性质）；
- 指标**不局限于财务也不刻意非财务补充**——财务/非财务、历史/前瞻、核心/辅助、内部/外部、数量/描述性等都可引入；须权衡**信息可获得性、相关性与重要性、精确性与简洁性、可控制性**，最终得出精简高效的指标体系。

## 主要特点与缺点

- **特点 4 条**：① **结构上**——三维框架/棱柱的不同折射面可清晰反映隐藏的复杂事物（传统一维框架只提出绩效某一方面）；② **起点上**——不像 BSC 以战略为起点；战略不是最终目的、只是"如何达到期望的路线"——绩效棱柱认为**战略应服务于利益相关者的满意和贡献**；③ **理论基础**——**利益相关者价值理论**（而非股东价值；公司所有者不再单独决定什么重要）；④ **指标设置**——从长期和短期两个角度、用多维标准测量每个利益相关者的五个方面（比传统系统全面揭示业绩动因，比 BSC 的评价指标具体）；
- **缺点 5 条**：① 非财务指标难计量、精确度不够；② 财务与非财务指标的权衡搭配困难；③ 管理者补偿大多依财务绩效制定、可能破坏与非财务绩效的应有联系；④ 指标过多可能分散管理者注意力甚至无所适从；⑤ 过分强调实际与标准对比调整，易陷入自我封闭循环、不利于产生新改进机制。

## 应用步骤（四步）

① **明确与企业相关的利益相关者**：识别其要求、需求和贡献并使表述具体化；运用调查法对公司各部门负责人调查，汇集"为提高业绩应做好的各项工作"→ 按利益相关者分类 → 为每个利益相关者确定战略计划、处理流程和能力；区分利益相关者子类并建立相应评价指标；
② **与相关各方沟通联系**：利用刊物/信件/公告栏/标语使各方了解公司战略、流程、能力和业绩衡量指标；听取员工建议；与大股东会谈了解财务业绩期望；与重要顾客会谈了解产品期望；
③ **确定各项评价指标**：综合意见修改初步体系，直至五个方面指标之间达到平衡（全面反映需求与贡献）；
④ **指标体系的实施与控制**：选择信息系统、建立数据库并建立联系；把企业目标和战略评价指标向基层分解贯彻落实；确定每年每季每月具体数字并与计划预算结合；把报酬奖励制度与绩效棱柱挂钩；周期性考察实施情况、采用员工意见修正指标。

## 案例锚点（原文 · 以投资者为例）

- **投资者想从组织获得什么**：利润——资本增值；奖金——给忠实投资者的红利；数据——用于考察流程和评估未来前景与风险的数据；忠实——对管理团队始终如一实现承诺的信任；
- **组织想从投资者获得什么**：资本——足够营运资金运行创造价值；信用——有权使用足够借款便利（如银行贷款）；风险——投资者提供资金或信用所应承担的风险；支持——持续的投资者忠诚（以及关于发展方向的建议）；
- **可实现这些愿望的战略**：内在增长（现有业务中增长）/ 合并和收购（购买实现加速增长）/ 成本缩减（裁减员工或购买成本）/ 资产出售（出售业务或资本资产）/ 资本投资（购买设备基础设施房地产）/ 最佳的资金成本（成本最佳的融资战略——资产净值或负债法）；
- **相关流程**：开发新产品和服务 / 为其产品和服务创造需求 / 有效率有力地满足需求（不断改进质量时使运营成本最优化）/ 计划和管理企业（制定维护战略意图计划程序项目以减少实施风险）；
- **需开发培养的能力（13 项）**：新产品和服务线 / 市场目标和定位 / 业务单元绩效管理 / 品牌管理 / 产品服务定价管理 / 核心能力投资 / 主管人员领导能力 / 投资者关系 / 财务管理 / 风险管理 / 合并后整合 / 商业联盟管理 / 社会责任；
- **测量指标示例**：满意——股东回报总额、每股收益、业务单元利润率、实际业绩与分析师预测对比、行业 EBITDA、价值附加值、每股财产净价值、流动现金流；贡献——金融机构投资者所拥有的资产净值、投资者分析家建议的定额、流动能力、利息费用水平、存货周转率、信用机构负债水平、投资者提出的改进建议；战略——市场增长（区域）、市场占有率增长、产品收益率、研发费用水平、资本支出水平、资产占用；流程——来自新引进产品和服务的销售额、来自新市场和新部门的销售额、内部财务管理方案、预算和预测流程、主要流程改进计划成本收益、投资者关系成本；能力——在开发线上的产品服务数量和潜在销售额、品牌评估、在核心能力上的投资水平、产品 SKU 水平收益率、收支平衡的产品销售额。
