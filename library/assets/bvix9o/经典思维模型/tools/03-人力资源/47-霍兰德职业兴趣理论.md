# 霍兰德职业兴趣理论

> 编号 #47 ｜ 篇：三·人力资源 ｜ 源：`TOOL` P0827–P0844
> 全称：Holland's Theory of Vocational Interests（约翰·霍兰德 1959） ｜ 类型：职业兴趣测验/人职匹配工具

**一句话**：人格可分为**现实型 R / 研究型 I / 艺术型 A / 社会型 S / 企业型 E / 常规型 C** 六类，**兴趣就是人格**——人格与职业环境匹配是职业满意度与成就感的基础（通用的职业兴趣测验工具）。

## 什么时候用

- 招聘选拔的人职匹配（选人标准首先人格与兴趣、其次知识技能）；
- 职业指导与职业规划（大学生/缺乏职业经验者）；
- 解决"顾客满意度 vs 主管评价"类矛盾（一线岗位职业性向管理）。

**不适用**：作为唯一选拔依据（影响职业选择的因素是多方面的——还须参照社会职业需求与现实可能性）；给员工贴类型标签（个体常是多种兴趣综合，取前三位组合看待）。

## 理论与来源

- 霍兰德（约翰·霍普金斯大学心理学教授）1959 年提出：**人的人格类型、兴趣与职业密切相关**——兴趣是活动的巨大动力，有职业兴趣能提高积极性、愉快从事并有益于提高效率；
- **来源**：兴趣测验史（桑代克 1912 探讨兴趣与能力关系 → 詹穆士 1915 兴趣问卷 → 斯特朗 1927 职业兴趣调查表 → 库德 1939 爱好调查表）；霍兰德 1953 编制职业偏好量表 → 1969 自我指导探索 → 1970 提出"**人格特质与工作环境相匹配**"理论——在此之前的职业兴趣测试与个体分析是**孤立的**，霍兰德将二者有机结合；
- **理论基础**：帕森斯特质因素论（**人职匹配原则**——在主客观条件与职业岗位相对照匹配）；霍兰德的两大理论源头：① 人格心理学概念（职业生涯选择=个人人格的反应与延伸；**兴趣就是人格**、兴趣量表结果可代表人格特质）；② 本人的职业咨询经验与辅导模式；
- **工具**：先编制**职业偏好量表 VPI** → 修订完善成**自我导向搜索测验量表 SDS**；成为众多职业指导理论中**应用最广**的一种；美国劳工部最新职业分析沿用此理论。

## 六大类型（人格倾向 + 典型职业）

| 类型 | 人格倾向 | 典型职业 |
|---|---|---|
| **现实型 R** | 喜欢有规则的具体劳动和需要基本操作技能的工作；**缺乏社交能力**、不善交际、不喜欢和人打交道的活动 | 技能性职业（一般劳工、技工、修理工）+ 技术性职业（摄影师、机械装配工） |
| **研究型 I** | 聪明、理性、精确、批评；喜欢**抽象的、分析的、独立的定向任务**类研究性职业；**缺乏领导才能** | 科学研究人员、工程师、电脑编程人员、医生、系统分析员 |
| **艺术型 A** | 想象、冲动、直觉、理想化、有创意、不重实际；**不善于事务工作** | 艺术（演员、导演、设计师、雕刻家、建筑师、摄影家、广告制作人）/音乐（歌唱家、作曲家、指挥）/文学（小说家、诗人、剧作家） |
| **社会型 S** | 合作、友善、善社交、善言谈、洞察力强；喜欢社会交往、关心社会问题、有教导别人的能力 | 教育工作者、社会工作者 |
| **企业型 E** | 冒险、有野心、独断、乐观、自信、精力充沛；喜欢领导及企业性质的职业 | 项目经理、销售人员、营销管理人员、政府官员、企业领导 |
| **常规型 C** | 顺从、谨慎、保守、实际、稳重；喜欢有系统、有条理的工作任务 | 办公室人员、秘书、会计、打字员、行政助理、图书馆管理员、出纳 |

**核心假设**：人格与职业环境的匹配是形成**职业满意度、成就感的基础**。

## 内在关系（六边形模型）

六类型并非并列、边界并不清晰——用**六边形**标示关系，分三类：
- **相邻关系**（六边形相邻角，如 RI/IR/IA/AS/SE/EC/RC…）：共同点较多——如现实型 R 与研究型 I 都不偏好人际交往、职业环境都少机会接触人；
- **相隔关系**（隔一个角，如 RA/RE/IC/IS/AR…）：共同点较相邻关系少；
- **相对关系**（对角线位置，如 RS/IE/AC/CA）：**共同点少**——一个人同时对两种相对职业环境都有浓厚兴趣的情况较为少见；
- 规律：**两种类型职业相关系数越大、适应程度越高**；统一在一个点上=劳动者类型与职业类型高度相关=人员配置最适宜、最好的职业选择；与实际型相关性较强的是常规型和研究型、很弱的是社会型；
- **现实应用**：个体常是多种兴趣类型的综合体（单一类型显著突出不多）——评价时取得分**前三位**组成兴趣组型（如 RCA、AIS）；职业选择时人会不断妥协（参照社会职业需求与现实可能性）——但**不应进入与自我兴趣完全不同的职业环境**（否则难以适应、工作痛苦）。

## 测验工具（VPI 与 SDS）

- **VPI 七个部分**：① 心目中的理想职业；② 感兴趣的活动；③ 擅长或胜任的活动；④ 喜欢的职业（②③④每部分按六类型各 10 题、是否选择计 1 分）；⑤ 能力类型简评（六能力 1-7 自评：机械操作/科学研究/艺术创作/解释表达/商业洽谈/事务执行；体育/数学/音乐/交际/领导/办公技能）；⑥ 统计确定职业倾向；⑦ 职业价值观（9 因素：工资福利/工作环境/人际关系/工作稳定/受教育机会/社会地位/压力少/发挥特长/社会贡献——选最重要与最不重要各两项）；
- **SDS**（在 VPI 基础上发展）：4 部分——活动 Activities / 能力 Competence / 职业 Occupation / 自我评定 Self-estimation；**不需按人群制定常模**——先算个体内部六类型在 4 部分的得分 → 相加得各自总分 → 从高到低排列 → 第 1 位字母=典型职业兴趣特征、**前 3 位字母组成职业码**（如 RCI）→ 查职业群（RAI=画家、IAR=物理学家）。

## 在人力资源管理中的应用（四条 + 两原则）

应用出发点：**每个人最大的成长空间在于其人格与兴趣最能发挥作用的领域**——人们倾向选择有利于技术和能力发挥、能表达态度、实现价值并扮演满意角色的环境：
① **选人标准首先是人格与兴趣、其次才是知识和技能**（人格与兴趣不可改变，知识技能可通过培训获得）；
② **绩效管理不能强求每个人都用同一种方法或同一个程序**；
③ **培训时间和经费主要用于帮助员工了解自己的兴趣和强化其兴趣**，而不是花大量时间克服弱点；
④ **提拔和使用应根据其人格与兴趣及其价值观安排不同的升迁阶梯**，不是一味地提拔到管理岗位。
**两条选拔安置原则**：依前三位类型组合安排工作；坚持不安排员工进入与自我兴趣完全相左的职业环境（即测评得分**最低**的职业类型）。

## 价值分析（三条）

- **对学科**：明确提出职业兴趣的**人格观**（使认识发生质的变化）；把职业环境研究与职业兴趣个体差异研究有机结合；兴趣测试与能力测试的结合促进职业指导实践；**霍兰德职业代码词典**（The Dictionary of Holland Occupational Codes）为 **12099 种职业**赋予了霍兰德人格类型代码——按兴趣类型搜寻合适职业有广泛应用前景；
- **对企业招募**：职业兴趣个体差异相当大且明显（职业划分越细差异越明显 + 个体生理心理教育背景不同）——现代人力资源管理基本原则是"合适的人放在合适岗位上"：人与职位匹配包括"知识能力技能匹配"与"**性格兴趣匹配**"（后者更重要）；职业兴趣测评可考查申请者是否适合本企业职业环境——减少招聘盲目性；
- **对个人职业选择与成功**：职业兴趣是职业选择中最重要的因素、强大的精神力量——匹配时潜在能力得到最彻底发挥、业绩更显著；帮助明确主观性向、避免盲目行为；对大学生和缺乏职业经验者尤其有价值。

## 案例锚点（原文 · 应用霍兰德解决顾客满意度问题）

广州某外资 IT 公司：频繁收到顾客对一线员工的投诉 → HR 调查发现怪现象——**受主管好评的顾客评分低、顾客评分高的主管评分低** → 用霍兰德测试 + 一对一访谈：
- 顾客高评分的 **121 位**员工中：**社会型占 96%、企业型占 89%**；
- 主管高评分的 **130 位**员工中：**常规型占 98%**（社会型员工有主见特长、喜欢服务他人、易受顾客好评；常规型尊重权威、习惯被指挥、踏实忠诚、上级喜欢）；
- 另一个发现：**招聘经理倾向聘用与自己同类型的人**（研究型的李经理招的员工研究型占 99%；社会型的张经理招的社会型占 93%）。
**改革建议三条**：① 摒弃主管考评制度、代之以较客观的**顾客满意度评分**绩效管理制度；② 招聘一线员工标准改为**社会型或企业型**；③ 招聘程序改革（先由人力资源中心测试筛选出社会型/企业型候选人 → 推荐给部门经理 → 部门经理确定最终人选）。
**效果**：半年后社会型和企业型一线员工比例增加 **26%**、平均顾客评分提高 **21%**。
