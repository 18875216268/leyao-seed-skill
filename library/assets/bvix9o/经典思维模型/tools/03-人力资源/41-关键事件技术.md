# 关键事件技术（CIT）

> 编号 #41 ｜ 篇：三·人力资源 ｜ 源：`TOOL` P0735–P0750
> 全称：Critical Incident Technique（弗拉纳根 1954） ｜ 类型：工作分析与绩效工具

**一句话**：通过收集"**导致成功或失败的关键事件**"（故事/轶事）并按内容分析法归类——识别工作绩效的关键性因素（业绩好的员工在关键事件上表现出色、业绩差的正好相反）。

## 什么时候用

- **绩效评估程序**（积累工作成败的关键事件资料，作为人员品质与特性判断基础）；
- 胜任特征分析与诊断（尤其适合）；
- 岗位分析的**补充**（不能独立使用）。

**不适用**：需要完整工作描述时（CIT 无法描述工作背景职责、任务、最低任职资格轮廓）；关注"平均绩效"的场景（CIT 恰恰遗漏平均绩效——对中等绩效员工难以涉及）。

## 来源与定义

- 弗拉纳根（John Flanagan）与匹兹堡大学学生 1954 年在对**空军**研究基础上提出（1949《人事评价的一种新途径》详尽阐述）；**通用汽车最早使用**；
- **关键** = "对整个活动目的而言发挥了重大作用、不论消极或积极"；**事件** = "任何可见的人类活动，自身能够充分完成并允许行为人做出推断和预测"——CIT 关注**曾经导致任何成功或失败的事件**；
- **理论基础**：每种工作中都有一些关键事件——业绩好的员工在这些事件上表现出色、业绩差的员工正好相反；
- 这些事件以描绘成功与不成功工作行为的**故事、轶事**形式被收集，再浓缩成一个能抓住故事本质的**行为陈述**；
- 定位：工作分析的**补充方法**——不好独立使用，需结合访谈法和问卷调查法，否则关键事件有失偏颇。

## 操作步骤（七步）

1. 要求对某工作十分熟悉的人向岗位分析人员描述近 **6~12 个月**中最能代表有效和无效工作行为的关键工作事件；
2. 让任职者写下 **5 个**在该工作中他们最擅长的事件，或描述一个表现最出色的人的工作行为；
3. 让任职者描述这些事件或行为的**起因、行为后果以及是否在控制之下**等信息；
4. 从**发生次数多少、重要性、操作需要的能力范围**三方面评定每一关键事件；
5. 按性质划分关键事件：先由 **3~4 名任职者**任意归类，再由岗位分析员**综合、命名并定义**；
6. 让**另外 3 名任职者**对归类进行检核（定义是否简明、归类是否清晰准确）；
7. 创建**关键事件类目与频率表**。

**特点提醒**：收集与归类非常耗时、难以体现平均绩效的工作行为——**比较适合于进行胜任特征分析和诊断**。

## 信息收集（问卷开发 + 数据收集）

**问卷开发要点**：
- 使用开放式、半结构化问卷；正式收集前经过**焦点小组访谈、预调查**（确认填答者是否准确理解问题、问题是否围绕关注的关键事件）；
- 问卷**第一个问题**：让填答者回想**最近一次（通常 6 个月之内）**引发某种行为/心理的关键事件——四个目的：允许自选相关事件 / 防止只描述富有戏剧性、印象深刻的事件 / 最近的事件能被很好记忆 / 让填答者整理思绪清晰回忆；
- **主体部分**：一系列探求性问题——要求以描述性语言**客观、详细**讲述整个事件过程，**不加主观分析和评论**；弗拉纳根："如果回答包括详实和精确的细节，通常表明信息是准确的。含混的回答往往意味着事件没有被很好记忆"——**信息的详实与否代表数据质量的高低**。

**数据收集（访谈 vs 问卷）**：
- 访谈能获取更丰满详细的信息，但时间精力成本高；有效性取决于**访谈员水平和能力**（缺乏经验可能产生偏误）——需对访谈人员训练；
- **最好方式**：被访人员在访问人员面前**当面将关键事件记录在标准化表格上**（保留单独访问的优势：私人接触、解释、随时解答问题；避免多人访谈的劣势：访问人员之间偏见、记录聆听的选择性、记录编辑偏差）；
- 选择何种方式：在保证信息可靠客观详实基础上，权衡时间、成本、人员。

## 应用要求与范围

- **对关键事件的四项要求**：① 必须包括**问题情景、工作目标、实际行为、工作结果**四要素；② 必须是**绩效关联事件**（能区分有效与无效绩效）；③ 包含一个或若干**工作胜任力单元**（能激活、诱发胜任力）；④ 是工作和组织情景中的**复杂性、两难性或多难性事件**（可为结构化或非结构化）；
- **应用程序 3 步**：从主管/员工/其他熟悉职位的人收集职位行为事件 → 描述"特别好"或"特别坏"的职位绩效 → 大量收集基础上分类归纳出该职位的主要特征和具体要求；
- **应用范围**：主要应用在**绩效评估程序**上——积累大量关于从事特定工作的人员工作成败的关键性事件资料，作为了解与工作成效有关的人员品质和特性的基础。

## 案例锚点（原文 · 打字员）

职务：打字员；维度：**工作准确、整洁的能力**；8 个关键事件（正向示例：查出信件报告中不正确的地方并改正、书写每侧对齐如印刷版的稿件、检查纠正邮寄资料中的错误地址；负向示例：按常规将图表信件错误归档、粗心颠倒关键信息、因不怀疑有误而常不查字典、产生打字错误和弯曲的边以至于必须重打 50~100 页）。

## 注意事项 · 优点 · 局限性

- **注意事项 3 条**：调查期限不宜过短；关键事件数量应足够说明问题（条目不能太少）；**正反两方面事件要兼顾**、不得偏顾一方；
- **优点**：研究焦点集中在**职务行为**上——行为可观察、可测量；可确定行为的任何可能的利益和作用；
- **局限（三条）**：① **费时**（大量时间收集、概括、分类）；② **不对工作提供完整描述**（无法描述工作背景职责、工作任务、最低任职资格轮廓）；③ **遗漏平均绩效水平**——关键事件定义的是显著有效或无效的事件，而"最重要的一点是要描述'平均'的职务绩效"——中等绩效员工难以涉及 → 全面的职务分析工作不能完成。

## 相关工具：行为事件访谈法（BEI）

- 麦克米兰结合**关键事件法 + 主题统觉测验**提出；**目前建模过程中得到公认且最有效的方法**；
- 做法：让被访谈者列出管理工作中遇到的关键事件（**正面、负面事件各两到三项**）→ 详细描述当时的想法、总结成败原因 → 内容分析确定其表现出来的**胜任特征** → 对比**卓越成就者与表现平平者**的胜任特征差异 → 建立该任务角色的**胜任力模型**；
- 价值：提供"一个人在实际情况中怎么做、说了什么、怎么想、感觉如何"的信息；是"**时间压缩的观察**"（高效获得几个月几年内发生的事情）；
- **访谈前准备 5 项**：访谈提纲设计（如何表达访谈要求（强调"工作情境中发生的、最近两三年的、典型的、自己认为最成功的"——注意随对象变化，如应届生不适用）/ 如何追问细节（围绕 **STAR 四要素**设计））；了解被访谈者基本信息；安排安静不受打扰环境；事先告知所需时间；检查录音设备（备一套备用）；
- **步骤 5 步**：自我介绍与解释（消除紧张、说明录音必要性与保密性）→ 了解工作学习经验（不是背岗位职责）→ **深入挖掘行为事件**（让受访者详尽描述 **5~6 个典型工作事件 = 2~3 个最成功 + 2~3 个挫折经历**——技术中最关键一步；可让受访者给故事起小标题）→ 求证所需特质 → 结束语（表达感谢——利于后续澄清）；
- **STAR 四问**（访谈重点在过去**确实的情境**中采取的措施与行动，不是假设性答复）：S（situation）"那是一个怎样的情境？什么因素导致？有谁参与？" / T（Task）"面临的主要任务是什么？要达到什么目标？" / A（Action）"当时心中的想法、感觉和想要采取的行动是什么？"（了解对情境的认知、对他人的看法、感受、内心想做什么及激励因素）/ R（result）"最后的结果是什么？过程中又发生了什么？"；
- **STAR 技术关键点 6 条**：从正向事件开始；遵循事件本身的时间顺序；探究相关时间、地点和心情（有助回忆）；强化受访者多说有用素材；了解访谈过程可能引发情绪反应；一次只描述一个情况（探究思想上的起因 S 和行为过程 A）；
- **注意 8 条**：避免理论化或泛泛陈述（礼貌打断）；询问意图后跟进"您实际上做了什么"；避免绝对化抽象化（**一般不用"为什么"**——用"当时是什么情况促使您这样做"）；避免现在式未来式问法；避免假设性问题（"您当时做了些什么？"）；避免一般性问题（不用"通常"）；避免引导型问题或直跳结论；不揣测诱导；
- **时长标准**：一般 **1~2 小时**；麦克里兰要求不少于 **65 页**英文双倍行距文字记录；王继承中国实证研究——录音整理字数须达 **1 万字以上**（约 1.5 小时以上）数据才较稳定；
- **难点与对策（四类受访者）**：① **过分健谈**（自信的销售/管理者/领导者；内容适合媒体采访不符合 BEI 要求）→ 果断直接打断、拉回主题、可预埋伏笔（"今天访谈和记者访谈不一样，希望您讲亲自处理的、自己感到最成功的三件事"）；② **过分羞怯或紧张**（职位较低的技术人员；沟通机会少、可讲事件少）→ 轻松话题缓和气氛 + 重复总结引导 + 鼓励性语言与非语言（点头微笑目光接触身体前倾）、温和轻柔音调；③ **支配性过强**（反客为主、控制局面——自负或习惯专制或掩饰不足）→ 礼貌但坚决扭转被动（"对不起，我所关心的是……"）——能否直面权威直接影响访谈有效性（尤其面对职位高、资深、年长者）；④ **情绪化或非常敏感**（突然哭泣）→ 不表现吃惊无奈、表示理解关怀、倒水递纸巾帮助平复、必要时让其单独待会儿；
- **注意问题 3 条**：强化培训提高素质（需社会学/心理学/人才学/管理学/行为科学知识 + 多次练习）；注意使用范围（比较适用于直接与考察对象谈话；谈话人非本人时可用第三人称）；应与其他方法结合使用。

## 相关工具：行为锚定等级评价法（BARS）

- 史密斯与肯德尔 1963 年提出——**关键事件法与等级评价的结合**（将同一职务工作可能发生的各种典型行为评分度量、建立锚定评分表，据以对实际行为测定评级）；
- **应用步骤 5 步**：① 岗位分析获取关键事件（描述代表优良与劣等绩效的关键事件）→ ② 建立评价等级（一般分 **5~9 级**；关键事件归并为若干绩效指标并给出确切定义）→ ③ 关键事件重新分配（另一组管理人员归入最合适的绩效要素与指标、确定最终位置）→ ④ 关键事件评定（第二组人员将指标中包含的重要事件由优到差、从高到低排列）→ ⑤ 建立最终的工作绩效评价体系；
- **优点**：向员工提供公司对其绩效的**期望水平和反馈意见**；良好的连贯性和较高的信度；考评标准比较明确；
- **缺点**：设计锚定标准比较复杂；考核复杂工作（尤其行为与效果联系不太清楚的工作）时，管理者容易着眼于**评定结果**而非依据锚定事件考核；
- **案例**：超市服务员——五个绩效维度（热情待客 / 服务意识 / 人际关系技能 / 装袋能力 / 观察能力），每维度 7 个分级、每级给出具体真实行为（如热情待客：7 分"一贯报以热情友好招呼并主动提供引导帮助"→ 1 分"从不打招呼也不主动提供引导帮助"）→ 五维度得分相加得量化分值。
