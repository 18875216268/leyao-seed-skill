# 职位分析问卷法（PAQ）

> 编号 #40 ｜ 篇：三·人力资源 ｜ 源：`TOOL` P0722–P0734
> 全称：Position Analysis Questionnaire（麦考密克等 1972，普渡大学） ｜ 类型：工作分析工具

**一句话**：用**结构化问卷**（194 个问题、6 大类别工作元素、6 项评分标准、5 个基本尺度）对职位做定量化描述——"最普遍和流行的人员导向职务分析系统"，使不同职位间可以量化比较、确定相对报酬。

## 什么时候用

- 职位分析与职位间比较（确定相对报酬、划分工作簇等级）；
- 建立职位能力模型、薪酬标准制定与人员甄选；
- 跨组织工作比较（标准化格式、不需修改即可通用）。

**不适用**：编写工作描述或工作再设计（PAQ 太抽象——需用其他技术）；分析管理职位（→ 用 MPDQ）；任职者学历不足以理解问卷（应由受训专业分析员填写）。

## 概念与设计初衷

- 1972 年麦考密克（E.J.McCormick）、珍纳尔和米查姆提出，**结构严密的工作分析问卷**；
- 设计初衷：开发一种**通用的、以统计分析为基础**的方法来建立某职位的能力模型，同时运用统计推理进行职位间比较以确定相对报酬；现已拓展到职业生涯规划、培训等领域（建立企业职位信息库）；
- **结构**：六个部分、**194 个问题**（其中 **187 个**用于分析完成工作过程中员工活动特征，称为**工作元素**；另 **7 项**涉及薪酬问题）；对每一工作元素用六标准之一衡量、采用**五分刻度**描述——量化结果决定职务在五方面的性质：沟通、决策、社会责任、熟练工作的绩效、体能活动及相关条件。

## 六个工作元素类别（含元素数）

| 类别 | 内容 | 例子 | 元素数 |
|---|---|---|---|
| 信息输入 | 从何处得到信息、如何得到 | 如何获得文字和视觉信息 | 35 |
| 思考过程 | 如何推理、决策、规划 | 解决问题的推理难度 | 14 |
| 工作产出 | 需要哪些体力活动、工具仪器设备 | 使用键盘式仪器、装配线 | 49 |
| 人际关系 | 与哪些有关人员有关系 | 指导他人或与公众、顾客接触 | 36 |
| 工作环境 | 自然环境与社会环境 | 高温环境或与内部人员冲突环境 | 19 |
| 其他特征 | 其他活动、条件或特征 | 工作时间安排、报酬方法、职务要求 | 41 |

## 评分标准与基本领域

- **六个评分标准**：信息使用度 / 耗费时间 / 适用性 / 对工作的重要程度 / 发生的可能性 / 特殊计分——将每个活动领域中 6 个方面的分析数据相加，**每个工作获得 5 个分值**，使工作之间可以量化比较；
- **五个基本领域**（5 个基本尺度）：① 是否负有决策/沟通/社会方面的责任；② 是否执行熟练的技能性活动；③ 是否伴随有相应的身体活动；④ 是否操纵器具/设备；⑤ 是否需要对信息进行加工；
- **13 个总体维度**（问卷共测量可归为 13 个总体维度的 32 个维度）：决策与沟通（一般责任）/ 事务性活动 / 技术性活动 / 植物性活动 / 常规性工作时间表 / 例行的重复性工作活动 / 环境知觉性 / 一般身体活动 / 监督协调与人事活动 / 公共关系与顾客关系 / 令人不悦的伤害性高强度环境 / 非典型工作时间表 等；
- **与能力测试的关联**：某些工作维度上的分数与**通用能力系列测试（GATB）**辅助测试得分相联系——只要知道某工作在工作维度上的分数，就能为确定完成该工作所需**能力类型**提供指导。

## 使用方法（工具应用）

1. **计分**：职位分析人员依据 6 个计分标准对每个工作元素衡量、给出评分；
2. **核查**：用 6 个评估因素对所需分析的职务一一核查——核查每项因素时对照其细分的各项要求，按 PAQ 给出的计分标准确定职务在职务要素上的得分；
3. **量化为剖面**：PAQ 将工作按 **7 个基本领域**排序，提供量化的分数顺序或顺序轮廓——根据 5 个基本尺度得出工作的**数量性剖面**分数 → 职位间可相互比较、划分工作簇等级；
4. **管理应用**：管理者运用 PAQ 结果对工作对比（确定哪种工作更富挑战性）→ 据此确定**奖金或工资等级**。

## 优点与局限

- **优点**：同时考虑**员工与工作**两个变量因素，将各工作所需的基础技能与基础行为以标准化方式罗列（为人事调查、薪酬标准制定提供依据）；大多数工作皆可由 5 个基本尺度描绘（可将工作分为不同等级）；可得出每一（类）工作的技能数值与等级（用于工作评估及人员甄选）；**不需修改即可用于不同组织、不同工作**——使跨组织工作比较容易、工作分析更准确合理；
- **局限（三条）**：① 填写者须具备**大学毕业生阅读水平**（学历不足者无法使用——最好由经过培训的专业工作分析人员填写，而非任职者或上级）；② 通用化、标准化格式导致**工作特征抽象化**——不能很好描述构成实际工作的特定、具体任务活动；③ **费时、成本高、程序繁琐**——不是编写工作描述及工作再设计的理想手段。

## 案例锚点（原文 · X 公司职位分析问卷结构）

四大板块：**① 基本资料**（职位名称/岗位/部门/定员与人员来源/直接上下级/填表日期）；**② 工作描述**（工作目标（主要+其他）；工作任务（主要/日常/临时三类 + 占年度时间百分比 + 发生频次）；**权限**（目前拥有权限+所缺权限——决策权/建议权/裁决权/人事权/指挥权等 13 种）；协作关系（部门内/部门间/外部——经常性与临时性））；**③ 任职资格**（教育水平/专业/新毕业生胜任时间/有经验者所需年限/经验/培训（课目、内容、方式、最低时间、绩效）/知识（通晓/熟悉/具备/了解四水平）/熟练程度/技能技巧）；**④ 其他**（工具设备（现有+未配备）/工作环境（现状+期望）/工作时间特征（午休/加班/上下班变化/外勤/出差）/所需记录文档/考核指标（现行+建议）/不合理处与改进建议）。

## 相关工具：管理职位描述问卷法（MPDQ）

- 托诺与平托 1976 年设计（针对管理工作特殊性）、1984 年定型；与 PAQ 相近但**以工作为中心**、专为管理职位设计；
- **三大特点**：能区别对待组织内不同**职能**的管理工作；能区别处理不同**层次**的管理工作；可为不同组织、不同职能间管理工作的分析与比较提供依据；
- **结构**：208 个项目、分 13 个类别，归纳为 **13 个基本工作因素**（产品市场与财务计划 / 与其他单位及工人相互协调 / 内部事务控制 / 产品和服务责任 / 公众和顾客关系 / 高级咨询 / 行为主动性 / 财务计划的批准 / 职能服务 / 监督 / 复杂性与压力 / 高级财务职责 / 广泛的人力资源职责）；
- **使用**：第一步评定重要性（0~4 记分，考虑重要性程度和发生次数）；第二步评论（写下应补充的其他工作）；
- **应用范围**：分析评价新管理岗位（决定薪酬水平与在薪酬结构中地位）；选拔管理人员、发现和建立晋升制度、安排培训项目、建立薪酬等级、工作归类；
- **优点**：考虑两个特殊问题——管理者常使**工作内容适应自己的管理风格**（而非适应工作；面谈时总谈"自己做的"忘了"应该做的"）；管理工作**非程序化**、随时间变化——弥补 PAQ 难以分析管理职位的不足；
- **缺点**：分析技术、专业等其他职位时不够具体；受工作及技术限制灵活性差；耗时太长、工作效率较低。
