# 胜任素质模型

> 编号 #48 ｜ 篇：三·人力资源 ｜ 源：`TOOL` P0845–P0869
> 全称：Competency Model（麦克里兰 1973 开创） ｜ 类型：人力资源战略工具

**一句话**：从组织战略出发，辨别**优秀员工与一般员工**在深层次特征上的差异（知识/技能/社会角色/自我认知/特质/动机），建立岗位胜任特征模型——**人力资源战略和组织整体战略紧密结合**的重要工具。

## 什么时候用

- 选拔关键岗位人才（尤其高层技术/管理岗位——在基本条件相似时预测效度远超技能/智力/学业分数）；
- 培训体系设计（针对性培养关键胜任特征）、绩效管理（过程指标）、职业生涯规划；
- 战略转型期的人力升级（"拥有一支高素质员工是战略成功的关键"）。

**不适用**：中小企业（样本量太小——干部经理仅一二十人不够建模，可借鉴咨询公司数据库）；无战略与文化基础的盲目照搬。

## 概念与起源

- **定义（斯班瑟 1993）**：胜任素质 = 能和参照效标（优秀的绩效或合格绩效）有**因果关系**的个体的**深层次特征**——三层含义：**深层次特征**（潜在特征保持相当长时间、可预示不同情境下的行为与思考方式——深层：动机/特质/自我形象/态度价值观；浅层：知识技能）、**因果关系**（意图→行为→结果）、**效标参考**（能按标准预测效标群体的工作优劣——不能预测有意义差异的不能称为胜任素质）；
- **六大层面**：知识（职业领域信息）/ 技能（掌握运用专门技术的能力）/ 社会角色（对社会规范的认知理解）/ 自我认知（对自己身份的知觉评价）/ 特质（特征或典型行为方式）/ 动机（决定外显行为的内在稳定想法）；
- **起源**：50 年代初美国国务院选拔外交官效果不理想（"许多表面优秀的人才实际表现令人失望"）→ 麦克里兰应邀设计预测实际业绩的选拔方法——**抛弃对人才条件的预设前提，从第一手材料出发**，比较优秀与一般外交官的具体行为特征，识别真正区分业绩的个人条件；1973 年发表《测量胜任特征而非智力》标志**胜任素质运动的开端**；
- **发展**：麦克里兰 70 年代初创 MCXR 公司（国际公认的胜任素质方法权威机构）；
- **两条基本原则**：① **能否显著区分工作业绩是判断一项胜任素质的唯一标准**（优秀与一般员工在所确认的胜任素质上必须有明显的、可客观衡量的差别）；② 判断必须以**客观数据**为依据（任何主观判断、理论假设、过去经验都需要客观数据支持）。

## 基本内容（三圆交集 + 建模原理）

**员工最佳胜任特征 = 三圆交集**：
- A **个人的胜任力**（个人能做什么和为什么这么做）；
- B **岗位工作要求**（个人在工作中被期望做什么）；
- C **组织环境**（个人在组织管理中可以做什么）；
- 交集部分 = 员工最有效的工作行为或潜能发挥的**最佳领域**；个人胜任能力 ≥ 三圆交集时员工才可能胜任岗位工作。

**建模基本原理**：辨别优秀员工与一般员工在知识、技能、社会角色、自我认知、特质、动机等方面的**差异** → 收集分析数据 → 科学整合 → 建立岗位胜任特征模型构架 → 产生可操作的人力资源管理体系。

## 应用步骤（六步 · 标准流程）

① **选定研究职位**（分析业务与行业特点，明晰战略、文化、核心价值观——重点放在核心能力和关键职位；方式：组织结构图分析、战略计划执行记录、高层访谈）；
② **定义绩效标准**（工作分析 + 专家小组讨论（优秀领导者+HR 管理层+研究人员）——提炼鉴别优秀与一般的标准；客观指标难获取时可用"**上级提名**"（较主观但简便可行））；
③ **选取分析效标样本**（从绩效优秀和普通员工中随机抽取；将绩优标准分解细化为具体任务要项）；
④ **获取效标样本数据**（**行为事件访谈法（BEI）为主** + 专家小组/问卷/全方位评价/专家数据库/观察法；BEI 要求被访者列出成功、不成功或负面事件**各三项**，详述起因/过程/结果/时间/人物/范围/影响 + 当时想法感想；访谈 1~3 小时、录音整理；**访谈者事先不知道访谈对象属于优秀组或一般组**（避免先入为主）；
⑤ **建立胜任特征模型**（对访谈报告内容分析，记录各胜任特征出现频次；比较优秀组与普通组的频次与相关程度，找共性与差异；按主题归类；**按频次集中程度估计各类特征组权重**）；
⑥ **验证胜任特征模型**（与人力资源各项工作衔接 + 沟通培训推广 → 反馈 → 验证评估（**回归验证法**较有效）→ 改进完善；验证问题：素质要项是否真为驱动高绩效的关键因素、界定划分是否准确、是否有遗漏）。

**案例（原文）**：为某大型电器营销公司销售经理建模——随机挑 45 名经理做 BEI（访谈三部分：基本资料/三成功+三不成功事件/综合评价）+ 管理素质测评与管理知识测评验证 → 归纳胜任特征频次表 → 建模 → 开发营销经理培训体系（帮助找"短木板"）+ 为选拔招聘提供依据。

## 在人力资源各板块的应用

- **工作分析**：基于胜任特征的分析——研究**绩效优异的员工**，结合其特征和行为定义岗位职责内容，**具有更强的工作绩效预测性**；
- **招聘与选拔**：挑选具备胜任素质和能取得优异绩效的人（不只"能做这些工作的人"）——人职匹配不仅在知识技能、还须重视**内隐特征匹配**；实施要素：经验证的胜任素质模型 + 系统面试问题库 + 经验丰富面试官 + 详细规范的结果记录；
- **员工培训**：针对特定职位的关键胜任特征培养（加强结构性、程序性知识培训）；实施要点：胜任能力定义须包含**行为范例**（避免误解）+ **良好的后续跟踪机制**（无后续支持很可能回到原来状态）；
- **绩效管理**：BSC/KPI 界定绩效**结果指标**，素质模型容易界定绩效**过程指标**——评估从三方面：目标完成、任务绩效提高、胜任力发展（平衡员工贡献与素质发展、短期与长期）；管理体系三内容：绩效目标建立在认同信任基础上（管理沟通形成绩效承诺）/ 管理者给予更多授权指导支持（满足员工事业发展期望）/ 不仅个人绩效、注意人际技能和团队协作（合理设计工作群体）；
- **职业生涯规划**：评价员工胜任力潜能 → 帮助了解个人特质与工作行为特点及发展需要 → 设计符合个人特征的职业发展规划（实现个人目标与组织战略协同）。

## 运用条件（九项）与运用障碍

- **条件**：① **组织战略的指导**（自上而下分解：企业使命 → 核心战略胜任素质 → 业务发展需要的胜任素质 → 职位需要的胜任素质——置于"**人员—职位—组织**"匹配框架）；② **组织文化的包容性**（胜任素质特征往往互相矛盾——如协调说服 vs 诚实踏实、敢于挑战 vs 组织忠诚，取舍取决于文化导向）；③ **组织结构与管理方式的转变**（从金字塔命令传递转向团队自主管理）；④ **高层领导的支持**（有目共睹——自己也用反馈工具、管理风格采用新核心行为）；⑤ **高素质人力资源管理人员的实施**（技术门槛较高：BEI/信息编码/建模依赖操作者胜任素质）；⑥ **组织薪酬体系的重新设计**（"无边界工作"→ 工作说明书只规定任务性质与任职者素质 → 薪酬转为以胜任素质为基础的**宽带薪酬**）；⑦ **组织培训和职业指导的配合**（岗位发展路线 + 人员发展路线）；⑧ **时间和资源要求**（"基础工程"——高层要有充分心理准备）；⑨ **适当样本量**（中小企业的数量不够）；另需注意**参照效标的选择**（有些岗位优秀/一般/较差员工难区分）；
- **障碍**：工具本身有待理论体系完善与实践检验；**文化适应性**（中国高不确定性规避、高情景依赖、高权利距离——与宽带薪酬/授权赋能团队冲突）；实施成本与效益对比；**参与人员的知识与技能**（多数 HR 从业者尚未掌握、短训难达标——成为无法普遍建立的直接原因）。

## 应用建议（五条）

① 建立新的人力资源管理理念（能力模型强调战略目标/核心能力/业绩/素质特征/行为特征结合 + 标杆分析）；② **重点突破**（不必对所有职位建模——先确定核心人力资源和关键职位）；③ **因企而异、不可照抄照搬**（公司战略文化导向分析不足是能力模型失效的重要原因）；④ **建立模型后并非一劳永逸**（要素变化 + 内涵变化 → 持续修正）；⑤ **HR 管理者素质必须达到专业级别**。

## 工具作用与优缺点

- **工具作用**：解决**职位与人之间的动态匹配**——两条思路对比：基于职位的人力资源管理（传统路径，方法流程完整但"过分关注工作本身，使工作分析、人员选拔、绩效考核、团队激励难以有机整合"）vs 基于胜任素质模型（关注人的内在素质与绩效的联系）——后者在很多方面优于前者、从方法上构成一定威胁；胜任素质模型为工作分析、招聘、考核、培训、激励提供依据——"**现代人力资源管理的新基点**"；
- **优点**：不受被访谈者经验影响（以胜任特征**出现频次**计）；应用于招聘时操作性与规范性较强、记录频次和等级有较多探察点（获得较稳定的平均等级分数）；
- **局限**：应用刚起步；构建后**开发测量各项胜任特征的量表与工具**值得探讨（量表准确性直接影响招聘参照标准）；**较为费时费力**——应侧重企业生产经营活动**价值链中的重要岗位**（降低关键岗位用人不当的损失）。

## 相关工具：IPMA 人力资源素质模型

- 美国国际人力资源管理协会 1999 年开发（综合国际上近 10 年研究成果 + 参考 AT&T 公司和全美公共管理协会的模式）；
- **四角色 + 22 项胜任素质**：**人力资源管理专家**（1 种素质——了解人力资源法规政策流程方法）、**变革推动者**（**15 种**）、**业务伙伴**（**12 种**）、**领导者**（**8 种**）——有的素质同时反映在多种角色中；
- **变革推动者**：在人员面对变革的心理四阶段（**否定—抵制—接纳—投入**）中发挥作用——不强制实施、减少畏惧、沟通保持纵横畅通、谈判技巧把冲突方注意力转移到共同利益（双赢）；
- **业务伙伴**：HR 与业务经理共同对战略目标承担责任——从被动提供服务转为主动参与管理、扮演合作型咨询顾问；
- **领导者**：凭借人格魅力与专业知识发挥影响力——不是发号施令而是协作共事、不是操纵控制而是影响力使员工达成共识；
- **与传统人事管理的十大不同**：视人力为成本 vs 第一资源；被动反应型 vs 主动开发型；强调人与事配合 vs 人际和谐协调；执行层 vs 决策层；以事为中心 vs 以人为中心；管好现有人员 vs 科学预测规划；用好显能 vs 开发潜能；个体静态管理 vs 整体动态管理；方法机械单一 vs 灵活多样；非生产部门 vs 生产与效益部门；
- **理论意义**：标志着人力资源管理领域的**根本性范式变革**——"以前人事经理管人、业务经理管业务、人事经理对业务绩效基本不负责；IPMA 模型界定下，人事经理必须与业务经理一起共同管理员工，并对企业业务绩效负责"。
