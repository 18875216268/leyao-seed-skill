# 3P 模型

> 编号 #39 ｜ 篇：三·人力资源 ｜ 源：`TOOL` P0704–P0721
> 全称：岗位分析 Position · 绩效考核 Performance · 薪酬设计 Payment ｜ 类型：人力资源管理系统框架

**一句话**：以**绩效考核（Performance）**为中心、把**岗位分析（Position）**和**薪酬设计（Payment）**结合起来的全方位交叉融合的绩效考核体系——岗位分析提供考核内容方法、考核结果决定绩效工资、薪酬反哺考核持久高效。

## 什么时候用

- 中小企业**从无到有**建立人力资源管理系统；
- 大中型企业从传统人事行政管理向现代人力资源管理**转轨**；
- 诊断"考核流于形式 / 干好干坏一个样 / 加薪不涨绩效"的系统性成因。

**不适用**：已进入战略人力资源管理阶段的成熟体系（3P 缺战略统领——应升级 4P/5P 或战略人力资源框架）；虚拟团队等新型组织（需改造后使用，见案例）。

## 三要素详解

**① 岗位分析（Position）**——企业员工要完成的各项任务和职责的集合，实现战略目标的客观要求；三个过程：
- **工作分析**（确立完成各项工作所需技能、责任和知识的系统工程）：回答六问——做什么 What / 何时 When / 何地 Where / 如何 How / 为什么 Why / 需要哪些条件 Which；
- **建立工作说明和工作规范**：工作说明 = 提供工作任务、责任和职责的文件；工作规范 = 完成工作必备的知识、技能、能力等基本素质的文件；
- **工作评价**（决定一项工作与其他工作**相对价值**的系统过程）：四项作用——确认组织工作结构 / 使工作联系公平有序 / 开发工作价值等级制度（据此建立工资支付结构）/ 在企业内部工作与工资方面取得一致；**是决定报酬内部公平的首要方法**。

**② 绩效考核（Performance）**——定期考察和评价个人或小组工作业绩的**正式制度**（最棘手任务之一、应优先考虑）；首要目的=提高业绩；作用：组织人力资源优劣剖析 / 招聘甄选预测 / 培训与发展需要判断 / **为增加报酬提供合理决策基础（加薪公平化的保证）** / 内部员工关系决策（提升、降级、调动）。

**③ 薪酬管理（Payment）**——工资水平、结构、制度、形式、待遇的管理系统；首要是**报酬公平**：内部薪酬公平（工作评价为首要方法）vs 外部公平（劳动力市场竞争力）——**焦点难点：既吸引人才又降低成本**。

## 内在关系（模型精髓）

**绩效 × 岗位（三维分析）**：每一岗位从**稳定性 / 程序性 / 独立性**三方面考察 → 三维分析图：
- **C 点 = 流水线装配工**（稳定性和程序性高、独立性低）→ 只需较低且专门化的知识技能 → 考核含较多可量化指标（上下班时间、操作熟练程度、次品率）→ 用**标准比较法或相对比较法**；
- **A 点 = 高层管理人员**（稳定性和程序性低、独立性高）→ 需丰富知识经验、创新精神与应变能力 → 考核侧重能力、素质、股东满意度、股票市场表现 → 用**非结构法**；
- **B 点 = 中层管理人员**（居中）→ **目标考核法**（事先确定目标作为评价标准）；市场销售工作（一定程序性、较高独立性）→ 除销售额外还考核合同数目、客户档案管理、项目进度、用户满意度。

**绩效 × 薪酬（价值闭环）**：绩效考核的实质是**价值评价**——价值评价要发挥牵引和激发作用，必须解决好**价值分配**问题；很多企业实践证明：**提高薪酬并不带来绩效提高，反而大幅增加成本**（干好干坏一个样 → 积极性下降）；薪酬 = **固定部分**（依岗位：岗位分析确定稳定性/独立性/程序性 → 分配权重 → **要素计点法**得出岗位评价分数 → 确定企业内相对价值 → 划分工资级别、福利标准、股权分配）+ **动态部分**（依岗位绩效高低浮动——业绩出色动态薪酬高、相同岗位间薪酬因绩效不同差别大 → 量化标尺 + 增加公正性）。

## 作用与局限

- **作用**：明确各岗位职责和应达目标、重新界定具体可操作的考核指标、薪酬结构围绕工作复杂程度与岗位绩效确定 → 有效激发积极性创造性；抓住人力资源管理核心技术、**易于操作实践、降低管理成本**；对中小企业从无到有建立体系、大中型企业转轨具有开拓性作用；
- **局限（三条·原文）**：① **理念上仍把人力资源归结为人工成本**——过于重视技术操作细节和短期人工成本降低，忽略人力资源管理在**企业战略、员工发展、组织创新**方面的作用；② **以岗位为基点、忽视了"人"**——按岗找人、把人改造得适应岗位 → 得不到员工参与与认同（人既是政策实施者参与者也是承受者）；③ **较少考虑与战略的关系**——三个模块按先后顺序排列、没有用战略统领，横向关系过于简单化、漏掉员工培训和职业生涯规划等关键环节。
  > 战略人力资源管理要求：**纵向与企业战略相匹配 + 横向各模块相互匹配**（模块间不是时序关系、而是匹配关系，须在战略统领下协调整合）。

## 案例锚点（原文 · 虚拟团队应用）

虚拟团队特点：组织结构虚拟、以信息网络为载体整合资源、由分散作业的**知识型员工**组成、任务导向（目标实现即自行解散）→ 3P 应用四策略：
① **科学岗位分析法**（5W1H 原则：工作内容与要求 What / 责任者 Who / 职务及环境条件 Where / 时间 When / 怎么做 How / 为什么 Why）组建和谐的虚拟团队；
② **完整绩效考核体系**——综合使用 360 度绩效评价法 + 平衡计分卡 + 目标管理法 + KPI（明确以任务和关系为导向的绩效目标），构建高绩效虚拟团队；
③ **公平的薪酬福利机制**——知识型员工最希望自我价值实现（马斯洛最上层）；其态度不是"所得多少"而是"付出与所得是否匹配"——须遵循**公平性、竞争性、激励性、经济性、合法性**五原则，激活虚拟团队内能；
④ **"以人为本"的团队文化**——虚拟团队生命周期短（任务完成即解散），需整合 3P 模型中"以人为本"的文化内核贯穿全生命周期（三大核心技术 + 加强成员间联系沟通 → 团队归属感）。

## 相关工具：从 3P 到 4P、5P（演进谱系）

- **人力资源管理 4P 模型**（战略导向，对操作导向 3P 的丰富与发展）：**"一个中心、两个基本点、四大匹配"**——一个中心=围绕**企业战略**（立足竞争能力提高与竞争优势获取）；两个基本点=以"人"为单元的子系统 + 以"岗位"为单元的子系统（双螺旋形式存在）；四大匹配=人与人 / 人与岗位 / 岗位与岗位 / 人与企业。四大管理：
  - **素质管理**（素质测评 → 素质管理：素质获取（测评甄选）/ 素质保持（激励体系）/ 素质增进（培训与职业生涯规划）/ 素质使用——目标：员工从"**终身雇用**"转向"**终身可以雇用**"）；
  - **岗位管理**（比岗位分析内涵更丰富：岗位设置 / 岗位轮换（与职业生涯结合）/ 岗位价值（战略导向评价、动态调整）/ 上岗下岗管理——**动态变化**：综合确定"把人改造适应岗位"还是"把岗位改造适应人"）；
  - **绩效管理**（绩效计划与期望 → 实施与支持 → 考核与评估 → 反馈与发展 的**闭环**；五内容：计划 / 实施 / 考评 / 增进 / 结果运用）；
  - **薪酬管理**（从交易式工资分配 → **共赢式薪酬管理**；五内容：目标 / 水平（内部一致性+外部竞争性+动态调整）/ 体系（工资+期权期股+个人成长与就业能力）/ 结构（薪酬宽带）/ 制度（公开透明、预算审计控制））；
- **人力资源管理 5P 模型**：**Position 职务设计 / People 人员选拔 / Performance 绩效评估 / Payment 薪酬设计 / Positive attitude 员工工作积极性**——**顺序模型**（职务设计为基础 → 因岗设人选人 → 绩效评估承上启下（既评价前两者又是薪酬依据、公开公平的评估是提高积极性的前提）→ 薪酬设计（正负强化）→ 工作积极性（企业文化软环境决定企业骨架和谐稳定））；
- **3P 与 5P 比较**：提出原因——3P 源于现代企业管理理论细化微观化具体化要求（岗位分析/绩效考核/工资分配紧密结合、结果导向）；5P 源于我国学习西方技术后需构建**符合中国国情**的人力资源管理体系；内容——3P：Position（职务分析）+ Performance（考核与工资）+ Payment（工资分配）；5P：职务设计 + 人员选拔 + 绩效评估 + 薪酬设计 + 工作积极性；性质——3P 是"现代人力资源管理的核心技术"；5P 是"新型的人力资源管理体系"。
