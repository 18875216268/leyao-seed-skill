# 盖洛普 Q12 测评法

> 编号 #43 ｜ 篇：三·人力资源 ｜ 源：`TOOL` P0768–P0783
> 全称：Gallup Q12（盖洛普公司） ｜ 类型：员工敬业度测评工具

**一句话**：用 **12 个问题**测量员工敬业度与基层工作环境（"最经典的员工敬业度测评工具"）——12 个软性问题与保留率、利润、效率、顾客满意度**四个硬指标**紧密相关；**用 12 个问题识别最优秀的部门经理与最差的部门经理**。

## 什么时候用

- 员工敬业度测评与基层管理诊断（以部门/班组为单位）；
- 管理改进闭环（测完必须行动——"重在行动"）；
- 优秀部门识别与经验推广（得分高的部门往往经营业绩优良）。

**不适用**：把问卷当"满意度调查"测完就完（传统调查收效甚微正因忽视行动）；高层战略问题诊断（Q12 面向基层——问题均在基层管理者与员工**控制之下**、易于改进）。

## 来源与数据基础

- 盖洛普 **60 年**研究企业成功要素相互关系 → 建立**盖洛普路径**：
  **股票增长 ← 实际利润增长 ← 营业额持续增长 ← 忠实顾客群 ← 愿意为他们服务的敬业员工 ← 优秀经理的管理 ← 公司知人善用**。前三个财务指标发生时已成过去（**后滞指标**）；只有"发现优势→忠实客户"的**前导指标**达到先进水平，才能改进后三个阶段的关键业绩；
- **Q12 数据基础**：12 个不同行业、24 家公司、**2500 多个经营部门**、**105,000 名**不同公司与文化的员工态度分析 → 发现 12 个关键问题最能反映**员工保留、利润、效率和顾客满意度**四个硬指标；
- 核心思想："**对内没有测量就没有管理**"；"要把人管好，首先要把人看好、把人用对——给他创造环境、发挥他的优势，这是管人的根本"（用中国话说是让每个员工产生"主人翁责任感"——盖洛普称作**敬业度**）；
- 出处：白金汉与科夫曼 1999《首先，打破一切常规》；盖洛普自身每年全员接受两次 Q12 检验。

## 作用特点（七条）

① 简明扼要、突出重点、易于操作；② **全员参与、面向基层**（企业文化建设的关键在于**一线经理**；Q12 以部门/班组为单位，问题均在基层可控范围内）；③ **与企业业绩挂钩**（可通过元分析等与员工保留率、顾客满意度、生产效率、利润率、安全等指标相联系）；④ **具有可比性**（庞大数据库与全球业内外对比）；⑤ **重在行动**（编制"盖洛普工作环境质量得分表"+ 统一教材培训各级经理 + 反馈与改进方案）；⑥ **推广先进**（区分优秀部门/班组并总结经验向全公司推广）；⑦ 问卷统一、便于跟踪（定期评测持续监测）。
> 最大特点：**从测量和行动两个方面为基层管理工作指出方向**——作为评测指标了解员工状态与工作环境；作为管理指标指出一线经理应关注的 **12 个工作维度**。

## 12 个问题与解读

| # | 问题 | 解读要点 |
|---|---|---|
| Q1 | 我知道公司对我的**要求** | 要求=衡量进步的里程碑 |
| Q2 | 我有做好工作所需的**材料和设备** | 支持员工的首要行为、发挥潜力的前提 |
| Q3 | 我每天都有机会做我最**擅长**的事 | 天生优势与工作吻合则出类拔萃——知人善任是当今经理最重要挑战 |
| Q4 | 过去七天里我因工作出色**受到表扬** | 认可与表扬是建设良好工作环境的砖和瓦 |
| Q5 | 主管或同事**关心我的个人情况** | "离职的员工不是要离开公司，而是要离开他们的经理和主管"——关心增加信任 |
| Q6 | 有人**鼓励我的发展** | "终生受雇"已过时、新重点是"终生就业机会" |
| Q7 | 我的**意见受到重视** | 被称为员工的"**内部股价**"——测量价值感、增强信心 |
| Q8 | 公司的**使命/目标**使我觉得工作很重要 | 价值联系 → 归属感与目标感 |
| Q9 | 同事们致力于**高质量的工作** | 精益求精是影响团队业绩的关键因素 |
| Q10 | 工作单位有一个**最要好的朋友** | 忠诚度同样存在于**员工之间**——员工关系深度对去留产生决定性影响 |
| Q11 | 过去六个月内有人和我**谈及我的进步** | 员工需从经理处获得反馈来发挥才干 |
| Q12 | 过去一年里我有机会**学习和成长** | 学习成长是人类的天然需要 |

（答案一般设 4 选项：非常满意/比较满意/较不满意/不满意；案例版为 5 选项。）

## 逻辑关系（登山四营地）

- **大本营——我的获取**（Q1-2）：新职位时的最基本需求（要求是什么、能挣多少钱、办公条件）——"我能得到什么"；
- **一号营地——我的奉献**（Q3-6）：视角变化——"我干得好吗？别人认为我很优秀吗？"——关心**个人贡献和别人看法**（Q3 是否胜任、Q4 别人是否看重业绩、Q5 是否看重价值、Q6 是否投资发展；焦点=自尊心和价值）；
- **二号营地——我的归属**（Q7-10）：环顾四周"我属于这里吗？"——真正想知道自己是否适应周围环境；
- **三号营地——共同成长**（Q11-12）："我们如何共同成长？"——**惟有经历前三个阶段才能卓有成效地革新**（正确期待+专长信心+周围接受新点子）；
- **山顶——风景独好**：12 个都能肯定回答即登顶，但"想长期呆在山顶不容易"（土地会变动、强风袭来）。
- **管理者启示**：关键是满足员工在"大本营"和"一号营地"阶段的要求——**如果员工较低层面的需求长期得不到解决，企业此后为他们做的所有事情都将毫无意义**；反之成功满足后，团队建设与革新等问题迎刃而解。

## 敬业度效应与高敬业团队特征

- **效应数据**：员工敬业度高的公司 vs 低：保留率提升 **13%**、生产效率提高 **5%**、顾客满意度增加 **52%**、利润率高出 **44%**；敬业度上升 5 个单位 → 顾客满意度上升 1.3 个单位 → 收益增长水平上升 0.5%；
- **高敬业度班组四特征**：**56%** 更可能拥有高出业界平均值的顾客忠诚度；**33%** 更可能创造高出平均值的利润；**50%** 更可能实现高出平均值的生产率；**44%** 更可能拥有高出平均值的员工保留率。

## 实现 Q12 的六个方法

① **明确岗位职责和岗位目标**（注意：陈旧、与实际不符的职责目标比没有更可怕——人力资源部门要及时调整）；② **做好设备和办公用品管理**（问题往往不是数量不足而是管理不善——专人负责+登记管理）；③ **加强管理沟通**（了解员工、多沟通特别是管理沟通、听取建议、让员工自我评价）；④ **建立意见反馈机制**（设"第三方"收集整理意见直达最高层——书面正式、纳入规章制度；也是对各级管理人员的监督）；⑤ **进行书面工作评价**（每半年一次、诚恳分析优缺点——员工感到公司时时关心成长）；⑥ **完善职务升迁体系**（**专业职务和行政职务并重**——如开发人员既可走管理方向（组长→经理→总监）、也可走技术方向（程序员→高级→资深→主任程序员））。

## 案例锚点（原文 · XX 酒店）

四星级商务酒店（500+ 员工、248 套客房）；327 份问卷收回 320。12 问数据示例：Q1 工作要求"54% 非常清楚+39% 比较清楚"；**Q3 做最擅长的事仅 2% 总是+17% 经常、42% 较少或几乎没有**（短板）；Q4 表扬"44% 有时、26% 极少"（短板）；Q9 同事高质量工作"8% 极其努力+53% 努力"；Q10 有最好朋友 84%（亮点）；Q13 开放问答揭示：情绪管理差伤害自尊心、工作超负荷、人员配置不够、工资低于同行等。
**改进措施三组**：① **沟通**（员工参与管理（总经理接待日/下放部分决策）+ 重视与"跳槽"员工交流（比现有员工更能直接详实指出问题）+ 人本管理（"家外之家"——宿舍餐厅文体活动））；② **薪酬与激励**（多种晋升途径——前台/后台两类不同晋升制度，优秀服务人员可升职位级别或技能职称而不必脱离一线）+ 合理薪酬体系（直接/间接/非物质报酬，最突出问题是非物质报酬）；③ **职业生涯管理**（定期工作变动（轮岗防厌烦+节约人力成本+提高协调）+ 重视培训与职业发展（参与式启发式培训、帮助制定个人职业发展计划））。

## 关联模型

- 上游：`服务利润链`（员工满意→顾客满意的因果链——Q12 是"内部服务质量"的具体化测量）、`满意镜`
- 配套：`360度绩效考核`（评价侧）、`贝尔宾团队角色理论`（团队建设侧）、`CS战略`（内外顾客一体）
