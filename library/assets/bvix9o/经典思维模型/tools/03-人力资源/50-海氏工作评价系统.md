# 海氏工作评价系统

> 编号 #50 ｜ 篇：三·人力资源 ｜ 源：`TOOL` P0892–P0911
> 又称：指导图表—形状构成法 Guide Chart-profile（爱德华·海 & 戴尔·珀维斯 1951） ｜ 类型：岗位评估工具

**一句话**：把付酬因素抽象为**三大因素**（技能水平 KH / 解决问题能力 PS / 风险责任 AC），用三套"指导图表"评分并按"**形状构成**"加权——解决不同部门的不同岗位之间**相对价值量化**的难题（世界 500 强中 1/3 以上使用）。

## 什么时候用

- 岗位价值评估与薪酬等级设计（公平定薪的基础）；
- 适用范围：**管理类工作岗位 + 专业技术类工作岗位**；
- 配套薪酬改革（克服奖酬不公——"海氏系统法"案例企业取得显著绩效）。

**不适用**：操作类岗位为主的企业（海氏为管理与专业技术岗设计）；无岗位说明书基础的组织（测评无从依据）；不愿投入培训与试测时间的组织（方法抽象难掌握）。

## 三大评价因素（付酬因素）

- **知识与技能 KH**（要使工作绩效达到可接受水平所必需的专门知识及相应实际运作技能的总和）——三个子因素：
  - **专业理论知识**（8 级：基本的 → 初等业务的 → 中等业务的 → 高等业务的 → 基本专门技术的 → 熟练专门技术的 → 精通专门技术的 → 权威专门技术的）；
  - **管理诀窍**（5 级：起码的 → 有关的 → 多样的 → **广博的** → 全面的）；
  - **人际技能**（3 级：基本的 / 重要的 / 关键的）；
  - 三成分组合分值构成技能水平相对价值——数值差异遵循心理测量学的 **15% 韦伯分级定律**；
- **解决问题能力 PS**（发现问题、分清主次、诊断原因、拟定备选对策、权衡评价并决策的能力）——两个维度：
  - **思维环境**（环境对任职者思维的限制程度；8 级：高度常规性的 → 常规性的 → 半常规性的 → 标准化的 → 明确规定的 → 广泛规定的 → 一般规定的 → **抽象规定的**）；
  - **思维难度**（对创造性思维的要求；5 级：重复性的 → 模式化的 → 中间型的 → 适应性的 → **无先例的**）；
  - 规律：**层次越低问题越简单越常规、独立创造性要求越低**；PS 分值以"智能的百分比"表示（如 33%、66%）；
- **承担的职务责任 AC**（行动对工作最终后果可能造成的影响及责任大小）——三个成分：
  - **行动的自由度**（9 级：有规定的 → 受控制的 → 标准化的 → 一般性规范的 → 有指导的 → 方向性指导的 → 广泛性指引的 → 战略性指引的 → 一般性无指引的）；
  - **职务对后果形成的作用**（4 级：**后勤**性作用（提供信息或偶然性服务）→ **咨询**性作用（出主意提供建议）→ **分摊**性作用（合作共同行动责任分摊）→ **主要**作用（本人承担主要责任）；并区分间接影响/直接影响）；
  - **职务责任**（可能造成的经济性正负后果；4 级：微小的 / 少量的 / 中级的 / 大量的——每级有相应金额下限，数额视企业情况而定）。

## 理论基础（职务状态构成 · 三种形态）

- 三大因素对应"输入—转换—输出"：**智力水平代表输入、解决问题能力代表转换过程、岗位责任大小是输出**；
- **技能水平 × 解决问题能力 = 人力资本存量使用性价值**（员工人力资本实际使用后的绩效水平）；**风险责任 = 人力资本增量创新性价值**（利用主观能动性创新所获绩效）；
- 公式：Wi = α[fi(技能水平, 管理诀窍, 人际技能) × 解决问题能力] + β[fi(行动自由度, 行为后果, 风险责任)]（α+β=1）；
- **三种形状**（α、β 权重对比）：
  - **"平路"型**（α=β——技能与解决问题能力同责任并重；如财务人员、技工）；
  - **"下山"型**（α>β——风险责任不及技能与解决问题能力重要；如专业技术岗位、营销人员）；
  - **"上山"型**（α<β——风险责任比技能与解决问题能力重要；如经理、中高层管理人员）。

## 评价体系（两部分）

**① 岗位分值评价**：评价前两项准备（全面了解评价因素与指导图表；结合工作分析深入了解各岗工作内容/能力要求/绩效标准）；流程：**引入指导图 → 工作分析回顾 → 技能因素分析 → 问题解决能力因素分析 → 承担的职务责任因素分析 → 求总分值**；分析顺序：先纵向子因素 → 再横向子因素 → 最后内嵌子因素（等级用 "+/—" 号区别大小值：A+ 大值、A— 小值、A 中间值）。

**② 评价结果检验**（海氏方法更重要的价值——提供工作质量控制的方法）：
- **职位特征概览**：技能指导图与问题解决能力指导图之间有极强联系——**技能因素层次越高、相应的职位就需要相对较强的问题解决能力**；若出现"技能分值较低而问题解决能力分值较高"的特例 = 出现偏差、需重新评价；
- **职位权重比较**：随职位降低，**技能分值占总分比重越来越大**、责任与问题解决能力分值占比逐渐降低（问题解决与责任分值占比与职位价值**正相关**）——不是高层素质不重要，而是高层更需要"解决问题和承担责任"的能力；评价结果必须反映此规律，否则评价过程有错需修正。

## 运用步骤（六步）

① **选择标杆岗位**（全部岗位测评耗费大、易敷衍——先归类再每类选标杆；三标准：**够用**（过多不精简、过少不能代表规律）、**好用**（用岗位分类法/定性排序法找"价值较难比较"的岗位）、**中用**（能代表所有岗位））；
② **准备标杆岗位的岗位说明书**（测评的基础——没有详细说明书测评者只能凭主观印象打分；最好让所有测评者参与工作分析或其讨论）；
③ **成立岗位测评小组**（四要求：客观公正的品格 / 熟悉测评方法流程技巧（不参加培训不得入选）/ 在公司工作时间较长、对岗位情况全面了解 / 在群众中有威信；构成上**不能全部由中高层组成、必须适当考虑基层员工**）；
④ **培训测评小组成员**（对设计原理、逻辑关系、评分过程与方法非常熟悉；培训后选若干标杆岗位对比打分、一名测评者做演示直到全部清楚）；
⑤ **对标杆岗位试测评**（先部分测试、统计分析满意后再正式——避免一开始就正式导致结果不理想时遭质疑）；
⑥ **正式测评打分并建立岗位等级**（统计平均分 → 算每位评分者与平均分的**离差、剔除离差较大的分数** → 排序 → 按级差分档分级 → 非标杆岗位与标杆岗位对比套入等级）。

## 存在问题（5 条）与解决策略

- **问题**：① 岗位说明书信息不详致结果不准（描述简单/缺关键信息）；② 小组成员不熟悉标杆岗位 + 未掌握方法（"海氏系统也称**专家测评法**"——凭主观感觉打分则结果毫无意义）；③ 成员主观原因（部门与个人利益驱动——涉己岗位打高分）；④ 等级划分时**边缘分数岗位**的界定直接影响公正公平；⑤ 系统本身抽象（难理解、培训时间长）；
- **策略**：岗位说明书——让编写者理解重要性 + 专业人员指导 + 审核修改；熟悉度——成立小组时选熟悉所有标杆岗位者（最好参与全部工作分析），无法参与则测评前详细介绍说明书；培训——选有丰富实践经验的咨询师/培训师、通俗语言解释、培训后试打分统一标准、**先测评一部分岗位检验合理性再全面展开**；人为因素——严格甄选测评人员 + 适当增加人数降低误差 + **剔除 3 西格玛区域外的分数** + 对结果画**散点图**检验趋势合理性；边缘岗位——研究说明书/依经验考察实际情况/与高层讨论确定。

## 案例锚点（原文 · 某公司三岗位评价）

| 岗位 | 技能水平 KH | 解决问题能力 | 职务责任 | 形态与权重 | 评价总分 |
|---|---|---|---|---|---|
| **作业班长** | 知识 4 级（高等业务）+ 管理 1 级（起码）+ 人际关键 → **175** | 思维环境 4 级（标准化）+ 难度 3 级（中间型）→ 智能的 **33%** | 自由度 3 级 + 主要作用 + 微小责任 → **76** | 平路型（50%+50%） | [175×(1+33%)]×50% + 76×50% = **154** |
| **高级工程师** | 知识 7 级（精通专门技术）+ 管理 1 级 + 人际 1 级 → **350** | 思维环境 6 级（广泛规定）+ 难度 5 级（无先例）→ 智能的 **66%** | 自由度 4 级 + 主要/分摊 + 略有的责任 → **100** | 下山型（70%+30%） | [350×(1+66%)]×70% + 100×30% = **437** |
| **销售部主任** | 知识 6 级（熟练专门技术）+ 管理 4 级（广博）+ 人际关键 → **800** | 思维环境 7 级（一般规定）+ 难度 4 级（适应性）→ 智能的 **57%** | 自由度 7 级（广泛性指引）+ 主要作用 + 中等责任 → **528** | 上山型（40%+60%） | [800×(1+57%)]×40% + 528×60% = **819** |

**结论**："用海氏法评价出的分数，比直觉性的主观评估要精确和合理得多"——三岗位相对价值 **154 : 437 : 819**，科学公平直观地反映各岗在智能、解决问题、职务责任上的差别；企业据此克服奖酬不公，管理层认同接受，激发工作热情、生产与效益增长。

## 关联模型

- 配套：`3P模型`（岗位分析—岗位评价环节）、`宽带薪酬`（评价结果是薪酬区间基础）、`职位分析问卷法`（岗位信息收集）
- 同族：岗位评估其他方法（排序法/分类法/因素计点法——海氏是因素计点法的高级形态）
