# 平衡计分卡（BSC）

> 编号 #36 ｜ 篇：三·人力资源 ｜ 源：`TOOL` P0633–P0657
> 全称：Balanced Scorecard（卡普兰 & 诺顿，1990/1992） ｜ 类型：战略绩效管理工具

**一句话**：把愿景与战略转化为**财务 / 顾客 / 内部流程 / 学习与成长**四个维度的目标与指标（每个层面 = 目标 + 指标 + 目标值 + 行动方案）——**化战略为行动**的战略管理体系。

## 什么时候用

- 战略绩效体系建设（战略落地、指标分解到部门/个人）；
- 绩效评价改革（克服单一财务指标的短期性）；
- 战略沟通工具（让全员理解战略）→ 配合**战略地图**（可视化因果关系）使用。

**不适用**：管理基础差的企业（须先提高管理水平再循序渐进引入）；把 BSC 当"打分表格"用的场景（见误区）。

## 起源与地位

卡普兰（哈佛）与诺顿 1990 年主持诺兰诺顿学院一年期研究项目（AMD、苹果、杜邦、GE 等 **12 家公司**）——起因：**财务绩效指标对现代企业组织无效、影响创造价值的能力**；1992 年成果发表于《哈佛商业评论》；1996《平衡计分卡：化战略为行动》、2001《战略导向型组织》；被 HBR 列为"20 世纪最具影响力的 75 个理念之一"（1997 年称"75 年来最具影响力的战略管理工具之一"）；《财富》1000 强近半数采用。

## 四个维度（结构）

| 维度 | 回答的问题 | 要点与指标 |
|---|---|---|
| **财务** | "怎样满足股东？" | **出发点和归宿**——其他 3 个方面的改善都必须反映在财务指标上（否则"做得再好也无济于事"）；指标：销售额、利润额、资产利用率 |
| **顾客** | "顾客如何看待我们？" | 从时间（交货周期）、质量、服务和成本关注市场份额与需求满足；指标：送货准时率、客户满意度、产品退货率、新客户获得、产品服务质量 |
| **内部业务流程** | "我们必须擅长什么？" | 三类指标：**创新**（新品开发时间、新品销售占比、开发费用/营业利润比）；**生产经营绩效**（生产时间、经营周转时间、质量、成本）；**售后服务绩效**（故障反应与处理时间、售后一次成功率、客户付款时间） |
| **学习与成长** | "我们能否继续提高并创造价值？" | 企业未来成功的基础：**员工能力**（满意度、保持率、工作效率、培训次数）；**信息能力**（信息覆盖率、系统反映时间）；**激励授权协作**（建议数量、采纳数量、协作程度） |

**因果关系链**（不是罗列）：先有员工创新学习 → 内部管理优化 → 更好服务顾客 → 顾客认可消费 → 企业价值实现（投资收益）→ 新循环——"平衡计分卡的四个维度并不是罗列"（卡普兰）。

## "平衡"什么（五个平衡）

① **财务指标与非财务指标**的平衡；② **长期目标与短期目标**的平衡（从战略开始逐步分解到短期——解决"战略规划可操作性差"）；③ **结果性指标与过程性指标**的平衡；④ **企业组织内部群体与外部群体**的平衡（股东客户=外部；员工与内部流程=内部）；⑤ **领先指标与滞后指标**的平衡（财务是滞后指标、只能反映上一年度；领先指标关注使企业更关注过程）。

## 实施（原则 · 步骤 · 条件）

- **五原则**：① 将战略转化成**可执行的语言**（四维度指标就是战略的执行语言、用战略图表示）；② 企业运作与战略**协同**（消除组织壁垒、综合绩效大于个别绩效之和）；③ 使战略成为**每个员工的日常工作**（自上而下层层战略沟通 + 目标设定到个人/团队 + 与激励机制结合）；④ 使战略成为一个**连续的过程**（持续反馈修正、与时俱进）；⑤ 通过**高层领导**促进企业变革（极为重大的变革、需高层重视与支持）；
- **实施步骤（卡普兰诺顿 8 步）**：① 筹备 → ② 第一次访谈 → ③ 第一次主管讨论会 → ④ 第二次访谈 → ⑤ 第二次主管讨论会 → ⑥ 第三次主管讨论会 → ⑦ 实施 → ⑧ 定期检讨（先成立"平衡计分卡推行小组"）；
- **实践五步**：愿景与战略建立与倡导（成立 BSC 小组/委员会，建立四方面具体目标）→ 绩效指标体系设计与建立（自上而下从内到外交流、吸收各层次建议）→ 加强内部沟通与教育（刊物/信件/公告栏/会议）→ 确定每年每季每月具体数字并与计划预算结合（注意因果关系、驱动关系与连接关系）→ 指标体系完善与提高（检讨科学性/补充不全面处/取消或改进不合理指标）；
- **适用条件（四类企业）**：① **面临竞争压力较大**（且竞争已被感知——否则"如同给牛车安上飞机用的轮胎"）；② **以目标、战略为导向**；③ 具有**协商式或民主式领导体制**（要求"四轮驱动"：前轮=员工积极参与、后轮=管理者管理；BSC 还有**改变企业文化**的作用）；④ **成本管理水平较高**（顾客层面要求算出"一位顾客带来的利润"——需**作业成本法 ABC**）。

## 运用误区（五条）

① 严格按 4 个维度分解实施（卡普兰从未说只能 4 个维度——**应根据自身特点设计**）；② 认为仅适用组织绩效而非个人（应通过分级 BSC 把最基层到最高层员工连接起来——"摆在每个人面前的是一张行动计划书"）；③ 把它仅当绩效衡量工具（**更是战略管理体系**——自上而下的战略目标任务分解与管理过程）；④ 指标越多越好（指标过多导致信息过载、主次不分、因果关系不清）；⑤ 没有正确认识成本与效益关系（**先出现成本后产生收益、有时间差**——急功近利会半途而废）。

## 意义与缺点

- **意义**：为战略绩效与战略管理提供强支持（四方面关键成功因素 → 各级业务单元乃至各岗位 KPI → 与战略目标紧密相连）；改进传统绩效评价不足（更系统、更公平）；促进凝聚力与员工参与热情；
- **缺点（五条）**：① 实施难度大（要求明确战略 + 高层分解沟通能力 + 中高层指标创新能力——管理基础差的企业不可直接引入）；② 指标体系建立困难（非财务指标难收集、需长期探索）；③ 指标数量过多、因果关系难真实明确（卡普兰建议**合适 20-25 个**：财务 5 / 客户 5 / 内部流程 8-10 / 学习与成长 5；因果关系链"需要几个月甚至几年"才能证明、短期只能主观定性判断）；④ 权重分配困难（不同层面之间 + 同一层面不同指标之间、无客观标准、有主观色彩）。

## 案例锚点（原文 · 中外运敦豪）

1998 年起先推行**作业成本法 ABC**（了解成本结构、支撑成本基准与定价）→ 2002"服务年"（2800 员工服务意识提升艰巨）引入 BSC（配合组织结构 + 管理目标与奖励系统结合）：
- 远景战略 = "**Market leader**"（国际快递最高服务）；四部分平衡：内部与外部 / 短期与长期 / 结果与动机 / 数量与质量；
- 指标：**财务 40%**（收入与预算比较、经营利润与预算比较、应收回收天数、超 90 天应收）；**效率 30%**（收入/FTE/日、件量/FTE/日、重量/FTE/日、顾客保有率、新增客户、员工流动率）；**服务质量 30%**（客户服务水平、操作业绩、客户满意度）→ 这些即 KPI（通过指标控制流程、"重在过程而不仅仅结果"）；
- 落地：总部"平衡计分卡小组" + 培训顾问设计课程 → 培训 39 个分公司内部培训师 → 再培训员工（内部讲师贴近员工）；
- 成果：业务年均增长 **40%**、营业额跃升 **60 倍**、中国市场占有率 **37%**；
- **案例点评（借鉴）**：四出色点（当战略管理体系用/按中国国情与三区域特点调整指标值再向 39 个分公司扩散/统一评估体制形成"共同语言"/与浮动薪资联系）；三不足（架构不完整——缺"内部流程"与"学习与成长"层面、财务层面指标缺失、指标分类归属待优化——如"顾客保有率、新增客户"应归客户层面、"员工流动率"属学习与成长层面）。

## 相关工具：战略地图（2004《战略地图——化无形资产为有形成果》）

- 由来：卡普兰诺顿发现"BSC 只建立战略框架、缺乏对战略具体而系统的描述"→ 战略地图 = 用**因果关系图**描述战略；
- **两增加**：① **颗粒层**（每个层面下可分解为很多要素）；② **动态层面**（结合战略规划过程绘制）；
- 核心因果链：**学习与成长**（人力/信息/组织资本等无形资产）→ **内部流程**（创新与建立战略优势效率）→ **客户**（把特定价值带给市场）→ **财务**（实现股东价值）；
- **六步流程**：① 确定股东价值差距（财务层面——确定目标值/分配价值差距（符合实际且具挑战性））→ ② 调整客户价值主张（客户层面——**四种主张：总成本最低 / 产品创新和领导 / 全面客户解决方案 / 系统锁定**）→ ③ 确定实现成果的时间表 → ④ 确定战略主题（内部流程层面——**四个关键流程：运营管理 / 客户管理 / 创新 / 社会**）→ ⑤ 提升战略准备度（学习与成长层面——**三类无形资产：人力资本 / 信息资本 / 组织资本**）→ ⑥ 确定战略行动方案并安排预算；
- **有效性两要素**：**KPI 数量及分布比例**（成功企业约 20 个左右；分布：财务 ≈20% / 客户 ≈20% / 内部流程 ≈40% / 学习与成长 ≈20%）；**KPI 性质比例**（非财务性 >80%；定量高于定性；长指标高于短指标；成长性高于维持性）。
