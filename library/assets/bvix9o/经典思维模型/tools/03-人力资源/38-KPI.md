# KPI 关键绩效指标

> 编号 #38 ｜ 篇：三·人力资源 ｜ 源：`TOOL` P0680–P0703
> 全称：Key Performance Indicator ｜ 类型：绩效管理工具

**一句话**：把企业宏观战略目标**层层分解**为可操作的战术目标与量化指标（企业级 → 部门级 → 岗位级），抓住**20% 的关键行为**（二八原理），使战略转化为内部管理过程与活动。

## 什么时候用

- 绩效管理体系设计（战略落地到部门/个人）；
- 部门职责梳理与考核指标设计；
- 判断"考核为什么失效"（指标是否抓关键、是否可控）。

**不适用**：无法分解战略的岗位（强行量化会陷入形式主义）；跨部门指标硬压给基层（见"控制力"原则）。

## 概念与理论基础

- **定义**：企业宏观战略目标决策经过层层分解后产生的**可操作性的战术目标**，是宏观战略决策执行效果的**监测指针**；通过对组织内部流程**输入端、输出端的关键参数**进行设置、取样、计算、分析，衡量流程绩效的目标式量化管理指标；
- **理论基础 = 二八原理**（帕累托）：每个部门和员工 **80% 的工作任务由 20% 的关键行为完成**——抓住 20% 的关键就抓住了主体 → 考核必须围绕关键绩效指标展开。

## 四大特点

① **来自对公司战略目标的分解**（三层含义：KPI 衡量内容取决于战略目标、脱离则努力方向分歧；是对战略目标的细化与发展（战略=长期指导概括、KPI=当年可衡量）；随战略调整而修正）；
② **对绩效构成中可控部分的衡量**（剔除他人或环境影响——例：销售量 = 市场总规模（不可控）× 市场份额，**市场份额更适合做 KPI**）；
③ **对重点经营活动的衡量**，而不是对所有操作过程的反映；
④ **组织上下认同的**（不是上级强压、也不是自行制定，是双方共同参与达成的一致意见——"与其说自上而下下达，不如说自下而上承诺"）。

## 设计原则（5 + SMART）

**五原则**：① 目标导向（依企业/部门/岗位目标确定）；② 注重工作质量（质量是竞争力核心又难衡量、须专门建指标控制）；③ 可操作性（明确含义 + 信息收集渠道 + 简单明了易被执行）；④ 目标的平衡性（相关部门协同制定；**"指标不在于全面、科学，而在于聚焦、有效"**）；⑤ **具有控制力**（被考核者须对 KPI 达成有控制能力——不能控制的指标不能作为其衡量指标；**跨部门指标不能作为基层员工考核指标**，应归部门主管或更高层）。

**SMART**：具体 Specific / 可度量 Measurable / 可实现 Attainable / 现实 Realistic / 有时限 Time-based。

## 建立要点（流程性 · 计划性 · 系统性）

1. 明确企业战略目标 → 企业会议上用**头脑风暴 + 鱼骨图**找业务重点（=企业价值评估重点）→ 找出**企业级 KPI**；
2. 各部门主管依企业级 KPI 建立**部门级 KPI**（分析绩效驱动因素（技术、组织、人）→ 确定工作流程 → 分解出部门级指标）；
3. 主管与员工将 KPI 进一步细分为**更细的 KPI 及各职位业绩衡量指标**（此过程本身就是统一全员朝战略目标努力的过程）；
4. 设定**评价标准**——区分：**指标**解决"评价什么"（从哪些方面衡量）；**标准**解决"被评价者怎样做、做多少"（各指标该达到什么水平）；
5. **审核**：多个评价者评同一指标结果是否一致？指标总和能否解释被评估者 **80% 以上**工作目标？跟踪监控是否可操作？

**指标提取总纲**："**十字对焦、职责修正**"——纵向战略目标分解 × 横向结合业务流程。五步流程：① 分解战略目标、建立子目标与主要业务流程的联系（鱼骨图）→ ② 确定各支持性业务流程目标（九宫图细化）→ ③ 确认业务流程与职能部门联系（九宫图）→ ④ **部门级 KPI 提取** → ⑤ 目标、流程、职能、职位目标的统一（分解到职位）。

## 设计基本思路（四种手段）

- **鱼骨图分析法**：确定业务重点 → 确定业务标准（定义成功关键要素）→ 确定关键业绩指标 → 层层分解（公司→部门→职位）；
- **工作量化的灵活处理**：人力资源/行政/财务等难量化岗位——从**工作要求、时间节点**上量化（"被时间所界定的工作任务或工作目标也是定量指标"）；
- **PDCA 循环**：专业人员设计 → 上报领导班子审议 → 修订 → 交各职能部门讨论 → 集中再修订 → 批准下发（前 5 项实际会有几个来回）；
- **考核支持环境**（四条）：绩效导向的企业文化（韦尔奇："我们的活力曲线之所以能有效发挥作用，是因为我们花了十年的时间建立起一种绩效文化"）；各级主管肩负绩效管理任务（专业人员只是技术支撑）；绩效沟通制度化；**考核结果与价值分配挂钩**（挂钩越紧密系统才真发挥作用）。

## 实施评估七步

① 分析确定**企业**关键绩效（总纲、方向性指导性——制定不合理将导致后续可操作性差）→ ② 分析确定**部门**关键绩效（具体性、操作性）→ ③ 分析确定**岗位**关键绩效（细分到业绩衡量指标）→ ④ 制定关键绩效的**具体标准**（最好全员参与；量化指标标准是"范围"——超出上限=卓越、低于下限=绩效不足；非量化指标从**客户角度**设问："客户期望做到什么程度？"）→ ⑤ 使每位员工了解标准 → ⑥ 定期评估（用数据和事实识别业绩；**每年 1~2 次**为宜）→ ⑦ 及时反馈结果（不仅作加薪升职依据，更在于改进业绩，否则流于形式）。

## 常见问题与支援体系

- **常见问题 5 条**：① 知识型员工贡献无形、不知产出为何；② 知道衡量方面却不知如何衡量（如"创造性"）；③ 指标设计抓不住关键（面面俱到）；④ 团队考核困难（团队 + 个体 + 跨部门冲突）；⑤ 不注重 KPI 体系审核（指标与组织目标不一致）；
- **支援体系 4 条**：绩效导向文化 / 各级管理者承担绩效管理（人力资源部提供专业咨询）/ 绩效沟通制度化 / 激励与约束体系（价值分配挂钩 + 投诉机制 + 考核档次比例控制 + 上级审核负责的二级考核体制）。

## 应用启示（四条）

① **科学合理的指标设计是有效推进的最重要基础**（指标以职能部门为单位各设计各的 → 相互推卸责任 → 企业陷入混乱低效率；**职能部门之间的空白地带往往是企业绩效改进的最大空间**；四条标准：准确反映目标 / 可量化 / 能激励良好业绩 / 并非越多越好——"量化正确的事情，并且是我们有限的精力能够做好的事情"）；② **KPI 没有固定模式**（不同企业、不同时期不同）；③ 注重协商性、支持性和过程管理（**KPI 管理协议**：上下级充分交流协商后确认标准及上级对下级的授权与资源支持；客观情况重大变化时适时调整；重视日常数据收集与全程跟踪辅导）；④ 循序渐进、把握主脉（**宜粗不宜细**（抓住关键的少数）/ 不拘于形式 / 不在小节上纠缠，允许有完善过程）。

## 优点与局限

- **优点 5 条**：目标明确抓住关键；原理简单明了易理解接受；高度参与性（下级成主动参与者、满足自尊、激发创新积极性）；**自我控制**（使员工控制自己的成就——"把外部控制代之以更严格的、要求更高的、更有效的内部控制"）；鲜明的培养性（总结反馈中共同探讨培训需求）；
- **局限**：对部门考核时指标倾向定位在**部门绩效结果**上——忽视部门间相互配合以及与组织战略的关系 → 职能部门强调自己专业地位贡献 → **部门的努力变成一种离心的力量**。

## 案例锚点（原文 · ABC 公司）

2006 年四大战略目标（组织机构变革 / 经营业绩稳步增长 / 降低经营风险 / 提升组织运营能力）→ **关键成功要素分解**（如"经营业绩"要素：销售收入稳定增长 / 投资收稳定实现 / 利润稳定增长 / 成本费用有效控制 / 新业务开拓 / 原有业务挖掘 / 管理投资项目 / 清理不良投资 / 发展公共关系与客户关系）→ **目标分解表**（战略子目标 × 关键因素 × 可能的关键业绩指标 × 责任部门 × 考核频度）→ **关键业绩目标评价**：五项标准各 5 分打分（**重要性 / 可衡量性 / 可控性 / 考核频度**），入围经验值：重要性达 5 分、可衡量性与可控性 ≥3 分（含）；**关键业绩目标个数经验值**：班组 ≤3 · 车间 3~5 · 部门 5~8 · 公司 ≤10 → 整理成册存档 → 制定年度经济责任书 → 转入考核任务书。

## 相关工具：五星图模型（360 度的几何化延伸）

- **绩效考核五星图**：五个考评渠道——上级 S / 同事 C / 下级 J / 外部专家 E / 被考评者本人 I（自评调整得分为 Im）分处正五边形五个顶点；按分值大小排序赋予 a~e 点（Im 先赋 e 点、其余四个使内轴轴长依次递减）；
- **绩效分析五星图**（斯蒂芬·罗宾斯）：**绩效 = f(能力 S、激励 I、机会 O、环境 C、行为 B)**——五个变量缺一不可；**绩效潜质 P0 = Sabcde**（图中面积 = 绩效增长空间；**具有优秀潜质的员工不是各项分值很高的员工，而是总分中等偏上、但在能力与行为方面表现不凡的员工**——因为改变系统因素（环境机会激励）比改变个人因素（行为能力）容易得多、代价小）；优秀绩效三典型模式：**内力推动型**（素质能力出色 + 恰当激励）/ **外力牵引型**（能力不特别突出但迫于团队整体压力产生优秀行为）/ **全力维持型**（五方面都高——已达该岗位绩效极点，应针对性绩效沟通）。
